## 2 读数（全部日线可算，`lib/sentiment.py`）

| 记号 | 定义 |
|---|---|
| ZT / DT | 收盘涨停 / 跌停家数（剔除上市 5 日内新股；ST 按 5%，无历史 ST 名单 → 推断，见 §5） |
| ZB / ZBR | 盘中触及涨停但收盘未封 / ZB÷(ZT+ZB) |
| H / LB | 最高连板 / 连板（≥2）家数 |
| P1 / P2 | 昨日涨停（非一字）/ 昨日连板 股今日等权涨幅 |
| HIr / HId | 昨日 ≥3 板股今日平均涨幅 / 其中跌停占比 |
| BR / AMT | 涨家数÷(涨+跌) / 两市成交额（亿） |
| EW | 全市场每日中位涨跌幅累乘（大盘代理；未用官方指数） |
| 前视（只检验用）FA / FAo / FAc | 首板尝试（今日首次触及涨停、昨日未涨停、非一字）按**涨停价**买入的次日开盘 / 收盘收益，含炸板 = 无幸存者偏差的「打首板」 |

所有阈值用 **250 日分位**，不用绝对数（2012 年约 2400 只、2026 年约 5200 只，涨跌幅制度也变过；依纪律「历史数值不可外推」）。

## 4 证伪结果（`python3 validate.py` → `docs/02-检验.md`，2010-01 ~ 2026-09，4067 个交易日）

**基线**：每天等权买入全部首板尝试（涨停价、含炸板）、次日收盘卖，平均每笔 **−0.64%**，次日开盘 −0.89%。机械打首板是负期望，游资的钱来自选股和执行（见 T6），不是来自「打板」这个动作本身。

| 检验 | 结论 | 数字 |
|---|---|---|
| T1 状态是否区分次日表现 | **区分，但方向是「动量」不是「逆向」** | S1 冰点候选 −1.66%（最差）；S1c 冰点确认 **+0.31%**（唯一为正）；S4 高潮 −0.30%；S6 −0.80%；S5 −0.71% |
| T2 负向闸门 vs 随机停手（同天数、20 日块） | **S1 停手、WEAK_MKT 停手有信息量**；**S6 停手没有** | S1：差 +1.15pp，随机分位 100；WEAK_MKT：+0.42pp，100；S6：+0.17pp，68；反面臂（停 S3+S4）分位 0 |
| T4 样本外（2010-17 拟合 / 2018- 检验） | S1、WEAK_MKT 两段都在 100 分位，**同号**；S6 两段 46 / 75（不稳） | — |
| T3 锚点回放 | 2015 股灾、2016 熔断、2018-10、2020-02、2024-02 均主要落在 S1/S1c；**2019-05 涅盘自述的退潮段落在 S5 分歧，不是 S6** | 补入崩溃日规则之前，2020-02-03（3083 跌停）被判成 S3 —— 这是规则缺陷，按养家 YJ-05 补，不是对着锚点调参 |
| T5 游资真实持仓段按入场日状态（17 人合并） | 与 T1 同向：S1 入场最差、S1c 最好 | S1 胜率 45% / PF 1.48；S1c 61% / **6.79**；S4 63% / 3.42 |
| T6 选股力（首板段次日开盘溢价 − 同日全市场首板尝试） | **三人都显著** | 北京炒家 +1.50pp（t=4.1，n=122）；善行天助 +1.79pp（t=3.5，n=89）；赵老哥 +1.30pp（t=4.6，n=101） |

**被证伪 / 不支持的说法**
- 「冰点买入」：冰点**当天**（S1）是最差的入场日。支持的是涅盘的版本：**等次日高位股反包确认（S1c）再上**。
- 「高潮不接力」（NP-17、BY-05）：对首板而言，S4 次日是第三好的状态（−0.30%，好于全样本 −0.64%）。说法也许对高位连板成立，对首板不成立。
- 现行 S6「退潮」定义：停手效果与随机无异。退潮是游资共识最强的概念之一，但「P2 连续两日为负 + 高位大跌」这个可编码版本没抓住它。

## 5 已知缺陷

1. **ST 推断**：无历史 ST 名单，用「60 日内有过恰好 ±5% 收盘、且 20 日内 |涨跌幅| ≤5.3%」推断；低波动大盘股恰好收 ±5% 时会误判。影响涨停 / 跌停计数在个位数量级。
2. **EW 不是官方指数**：中位涨跌幅累乘，偏向小盘。
3. **S5 太宽**：占 33.5% 的交易日（任何「最高板断板 + 炸板高或连板负」都算）。
4. **2009-2010 的 250 日分位**样本不足，T 检验从 2010-01 起。
5. **北交所 30%、科创 20%**按规则处理，但这两个板的涨停占比近年上升，会抬高 ZT 的结构性水平（分位口径部分抵消）。
6. 行情源：TickFlow 不复权 + 前复权比值推昨收；舍入噪声已压掉（|比值−1| < 0.2% 视为非除权）。

## 6 与本项目纪律的对照

- **只负向剔除**：状态机只给仓位**上限**。T2 支持把 **S1（崩溃 / 冰点候选）** 和 **WEAK_MKT** 当作 A 股情绪类负向闸门的候选。
- **在 A 股个股趋势池（私有 SuperTrend + EMA60 类引擎）上已检验，无增量**（`docs/03-趋势池闸门检验.md`，2026-10-07；引擎不在本仓库，只留结论）：S1 不新开仓 Δ Calmar ≈ 0（只有 2.7% 的新建仓落在 S1 日，策略自己已避开）；WEAK_MKT 不新开仓所有窗口都变差；WEAK_MKT 清仓拟合期 +0.24、检验期 −0.05 / 近 5 年 −0.44（过拟合）。**不接生产**，面板只作信息。与 vol-gate 同型：ST 的入场/退出已内含这部分信息。
- 「说做冲突」是这个面板最实在的价值：涅盘 2017 年自评「情绪差」的日子买入额反而更大（约 95 万 vs 48 万），「我自己没空仓，手痒」。阶段判定交给机器，纪律写进执行层。

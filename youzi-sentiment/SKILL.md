# 游资情绪周期面板（youzi-sentiment）

思路蒸馏，**只出分析，不改生产仓位、不下单**。人物、语录、规则出处在姊妹 skill `youzi`。

先读 `docs/01-蒸馏笔记.md`：出处与证据等级（§1）、读数定义（§2）、状态机与每个阈值的出处（§3）、证伪结果（§4）、已知缺陷（§5）、与本项目纪律的对照（§6）。最新检验数字在 `docs/02-检验.md`（自动生成）。

## 命令

```bash
cd ~/distills/youzi-sentiment
PY=~/Baidu-Pan/游资心法+讲座全集1/distill/.venv/bin/python   # 有 pandas/pyarrow 的环境即可

$PY panel.py                         # 增量更新行情（约 1-2 分钟）→ 最近 10 个交易日读数 + 状态 + 上限
$PY panel.py --no-update --days 20
$PY panel.py --no-update --date 2024-02-05   # 回看某天
$PY panel.py --json
$PY validate.py                      # 重跑全部证伪检验 → docs/02-检验.md
```

数据缓存 `~/.trade-strategy/distill/youzi/market/`：`daily.parquet`（全市场不复权日线）、`stock_basic.csv`（股票池含退市股）、`sentiment_daily.parquet`（读数）、`sentiment_states.parquet`（状态）。首次全量：`$PY -c "import sys;sys.path.insert(0,'lib');import market;market.update(full=True)"`（约 30 分钟）。A 股收盘后 TickFlow 才更新当日。

## 怎么回答

1. **问「今天情绪怎么样」**：跑 `panel.py`，报状态 + 关键读数（涨停/跌停/炸板率/最高板/P1/高位股），并附该状态的历史次日表现（面板最后一行）。注明数据日期。
2. **说状态时带上检验结论，不要只报标签**：
   - S1（崩溃 / 冰点候选）：历史上最差的入场日（打首板次日 −1.66%）。不是「冰点买」的信号，要等 S1c。
   - S1c（冰点确认 = 冰点次日高位股反包）：唯一次日为正的状态（+0.31%），游资真实持仓 PF 6.79。
   - S4 高潮：对首板来说次日并不差（−0.30%，好于全样本）。「高潮不接力」只对高位连板也许成立，**未检验**。
   - S6 退潮：**现行定义检验失败**（停手效果与随机无异），只作参考，不要当硬结论讲。
   - WEAK_MKT：负向闸门有信息量（样本外同号）。
3. **仓位上限只是上限**，按纪律「只负向剔除，不做正向加权」：可以说「情绪状态建议不新开超短仓」，不要说「状态好所以加仓」。
4. **用户想拿它管趋势池**：**已在 A 股个股趋势池上检验，无增量**（`docs/03-趋势池闸门检验.md`，私有引擎，只留结论：S1 不新开仓 Δ Calmar≈0，只有 2.7% 新建仓落在 S1 日；WEAK_MKT 挡入场所有窗口变差；清仓版拟合好检验差）。答「不建议接入」，面板只作信息。
5. **问某个游资怎么看情绪 / 某条规则出处**：转 `youzi` skill。
6. **新闻、社区情绪只作线索**（全局纪律）；这里的「情绪」是涨停板结构读数，不是舆情。

## 已知限制

ST 无历史名单（推断）、大盘用全市场中位数累乘代理、S5 过宽（占 1/3 交易日）、阈值多为「待校准」——详见 docs/01 §5、§7。

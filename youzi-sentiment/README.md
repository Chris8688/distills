# 游资情绪周期 · 面板与证伪

[游资心法蒸馏](../youzi/README.md)的姊妹目录：把涅盘重升、炒股养家、不颜不语、Asking、独股一箭等人的「情绪周期」说法写成可计算的读数和阶段状态机，在 2010 ~ 2026 全市场日线上证伪。

> 不构成任何投资建议。

## 结论

- **基线**：机械打首板（全部首板尝试按涨停价买、含炸板、次日收盘卖）平均 −0.64%/笔。
- **S1（崩溃 / 冰点候选）与 WEAK_MKT（弱市）停手有信息量**：随机停手 100 分位，2010-17 / 2018- 两段同号。
- **「冰点当天买」被证伪**：S1 次日 −1.66%，是最差的入场日；等次日高位股反包确认（S1c）后是唯一为正的状态（+0.31%，游资真实持仓 PF 6.79）。
- **「高潮不接力」对首板不成立**（S4 次日 −0.30%，好于全样本）；可编码的 S6「退潮」定义与随机无异。
- **接到 A 股趋势池当入场阀无增量**（私有引擎，只留结论，见 [docs/03](docs/03-趋势池闸门检验.md)）。

详见 [docs/01-蒸馏笔记.md](docs/01-蒸馏笔记.md)（读数定义、状态机与阈值出处、已知缺陷）与 [docs/02-检验.md](docs/02-检验.md)（自动生成）。

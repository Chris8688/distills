# 游资心法 · 投资思路蒸馏 · 最终报告

> 71 位 A 股游资的心法、语录和 22 人的真实交割单，规则逐条带出处；能量化的拿全市场日线证伪。
> 结论：日线规则复现不了名家的超额，机械打首板是负期望；可参考的是执行纪律和市场层的负向闸门。
> 不构成任何投资建议。

## 一、结论

1. **机械打首板是负期望**：2010-2026 全部首板尝试按涨停价买、次日收盘卖，平均 **−0.64%/笔**。
2. **名家的首板确实有选股力**：次日开盘溢价减去同日全市场首板，北京炒家 +1.50pp（t=4.1）、善行天助 +1.79pp（t=3.5）、赵老哥 +1.30pp（t=4.6）。
3. **但这份选股力日线规则复现不了**：48 条日线可算的选股规则，能解释名家超额的比例 ≈ **0%**。超额的 53-92% 来自「买到的板当天能封住」（他们封住率 76-85%，同日全体约 57%），其余是封住组内的再挑选，都是盘中判断。
4. **样本外显著的单条规则，多数方向与游资说法相反**：「接近前高 / 箱体突破 / 均线多头 / 10 日涨幅大」的首板次日更差，「低位 / MA20 下行」更好 —— 首板层面是均值回归，不是动量。机械组合超同日全体 +0.21pp（t 3.2），但绝对收益 −0.43%/日、扣成本 −0.63%，**不能实盘**。
5. **情绪周期有一部分信息量**：S1（崩溃 / 冰点候选）与 WEAK_MKT（弱市）停手，在打首板上落在随机停手的 100 分位、样本外同号；「冰点当天买」被证伪（S1 是最差的入场日），要等次日高位股反包确认（S1c，唯一次日为正的状态）。「高潮不接力」对首板不成立；可编码的「退潮」定义与随机无异。
6. **接到趋势策略上没有增量**：S1 / WEAK_MKT 当趋势池的入场阀，Δ Calmar ≈ 0 或变差；清仓版拟合好、检验差。情绪状态预测的是次日溢价，趋势策略持有数周，时间尺度不匹配。
7. **说的和做的经常不一致**：说了「停手 / 降仓」的基本没做到（平仓到下次建仓间隔中位 0 天，亏后规模不减）；真正被所有人遵守的只有机械的「隔日卖、次日低开就走」。

## 二、来源与方法

- **语料**：百度网盘《游资心法 + 讲座全集》，1799 个文件（去重后 1209 个，14 GB）：心法合集、论坛帖子、交割单截图 / PDF、券商导出的原始成交、音视频课程。PDF 多为倒卖课程站整理（带 98kecheng 水印）。**原始语料不进 git。**
- **整理**（`pipeline/`）：按人物登记表归属、去重、软链 → pdftotext / textutil / Apple Vision 本地 OCR（6696 页）→ 约 485 万汉字可检索文本 → 《58位大佬心法》按章切给各人 → 原始成交与 OCR 交割单解析成持仓段，接全市场日线分类买点（打板 / 半路 / 平盘 / 低吸 / 竞价，首板 / 二板…）。
- **证据分级**：A = 原始成交 xls/csv（7 人）；B = 交割单 OCR，逐行「价×量=额」+ 当日高低价双重校验（8 人，另有几位段数 <30）；C = 只有文字。规则标「原文 / 二手 / 实盘反推」，二手（58 位合集、图文解读）单独标。
- **蒸馏**：逐人 `蒸馏笔记.md` + `rules.yaml`（共 840 条规则，带原文短引和页码出处），按流派写 6 份对照表。
- **检验**：
  - 选股规则：2010-01 ~ 2026-09 每日全部首板尝试 266,832 个，拟合 2010-2017 / 检验 2018-，按日聚类 t，50 个随机特征做对照臂；名家归因用他们的真实首板段。
  - 情绪周期：4067 个交易日的读数 + 状态机，负向闸门对 20 日块随机停手（1000 次）+ 反面臂 + 样本外 + 锚点回放（2015 股灾、2016 熔断、2018-10、2019-05、2020-02、2024-02）。

## 三、语料的问题

1. **幸存者偏差**：出了名才有合集和交割单；「N 个月 N 倍」是营销口号，不当证据。
2. **归属错误**（已查实）：养家「情绪周期六阶段」出自约 2019 年署他名的传记，他 2010-13 年原帖里「冰点」「首板」0 次；徐翔《心性之刀》是闽发论坛旧文，只有前员工的《七堂课》可信；赵老哥「二板定龙头」首见于 2013 年他人帖子；孤独牛背的「控制回撤篇」是多人征文去了 ID 后整章归给他；林疯狂「低吸强势股」标签出自论坛评论者，他本人和数据都是半路。
3. **晒单挑过**：乔帮主自述 6 轮「几个月 3-4 倍再回撤 30-50%」，晒出的段 PF 20.6。
4. **OCR 错字**：引文已修正明显错字，以语义为准。

## 四、流派速览

| 流派 | 代表（★ = 有成交校验） | 能编码的核心 | 不能编码的（真正的 alpha） |
|---|---|---|---|
| 首板打板 | ★北京炒家、创世纪888888 | 首板识别、当日封住与否、次日开盘溢价定去留、日内炸板 2 个熔断 | 回封 / 换手 / 封单 / 题材预判（2021 年后被量化打板侵蚀） |
| 龙头接力 | ★赵老哥、★令胡冲、★退学炒股、作手新一、陈小群 | 隔日认错、弱转强、回撤线控仓、昨日涨停均跌 >2% 不开新仓 | 「龙头」定义；持有派都没有交割单 |
| 情绪周期 | 涅盘重升、炒股养家、不颜不语、Asking、独股一箭 | 涨停结构读数 + 阶段状态机（见 [youzi-sentiment](../youzi-sentiment/)） | 主流识别、断板后次高位 vs 补涨 |
| 半路 | ★水哥割股、★林疯狂、字母哥 | 买价分布（买在涨停幅度 60-80% 段是唯一亏钱区间）、当日封板定胜负 | 分时异动形态 |
| 低吸 / 弱市 | ★乔帮主、★rxybgb、明王、瑞鹤仙 | 强势股盘中急跌、弱市仓位状态机 | 「回调到位」的判断 |
| 仓位风控 | ★龙飞虎、相城采莲路、挑战12345、职业炒手 | 账户回撤分档节流、试错仓 → 确认仓、浮亏不补仓、大赚后降风险 | — |

**跨人物的实盘事实**（A 级 7 人）：胜率都在 43-56%，PF 1.7-3.2，没有模式差异；同一人同一模式月度 PF 能从 <1 跳到 >7（**模式差异 < 行情差异**）；封板是所有「向上买」的分水岭（打板封住 PF 4.95 / 炸板 0.56）；板位越高越差（首板 PF 3.0 → 三板+ 0.9）；利润在右尾（持有 ≥3 天的段占 3-26%，贡献 41-103% 净利）；低吸的利润几乎全部来自「买入当天收涨停」的段。

|---|---|---|
| 炒股养家 | 「板上买票占我操作的一半」 | 2010 交割单首笔打板 7.8%，但贡献净利 115% |
| 赵老哥 | 「二板定龙头」 | 打板段 83% 是首板，首板贡献 68% 净利 |

## 五、仍可参考的部分

1. **「次日不延续就走、延续就拿」**：所有有成交数据的人都遵守，1 天段 PF 0.35-2.1、多日段 3-84。和趋势策略「截断亏损、让利润奔跑」同构。
2. **风控要写死在执行层**：口头风控（退潮停手、回撤降仓）几乎没落到仓位上，真正起作用的是机械的次日出场。
3. **市场层负向闸门**：S1 与 WEAK_MKT 在超短上有信息量，只能用来「不新开超短仓」，不能做正向加仓。
4. **反例**：新疆坚果哥（融资仓位均值 169%，2022 年亏 94%）、余哥（不跌停不出局）、浓汤野人（满仓加仓、浮亏 60% 是常态）。

## 六、局限

- 名家超额里日线解释不了的部分（盘中封板判断、题材地位、封单）没有数据，**没法检验也没法排除**。
- 选股检验假设每个首板尝试都按涨停价成交，封得死的板实际更难排到，真实执行只会更差。
- B 级交割单有漏页漏行，看各人 profile 的「卖出配对率」；融资字段没进统计；音视频（养家 60 集音频、92科比 直播等）未转写。
- 他们的 PF 来自 2009-2024 不同行情段的幸存者样本，不能拿来给模式排名。
- 趋势池闸门检验用的是私有引擎（SuperTrend + EMA60 类），**不在本仓库，只保留文字结论**。

## 七、复现

```bash
cd ~/distills/youzi
python3 rules.py --person 北京炒家             # 某人全部规则；--school / --category / --codable / --conflict / --grep
PY=<有 pandas + pyarrow 的 python>
$PY profile.py 交割单.xls --name 我             # 任意券商交割单 → 同口径画像 + 对标 15 位游资
$PY selection.py                                # 首板选股规则检验 → docs/02（需先跑 youzi-sentiment 的全市场行情缓存）
python3 build_data.py                           # 语料库更新后重汇总 data/ 与 docs/people、docs/schools
```

语料库与整理流水线见 [pipeline/README.md](pipeline/README.md)；情绪面板见 [youzi-sentiment](../youzi-sentiment/)。

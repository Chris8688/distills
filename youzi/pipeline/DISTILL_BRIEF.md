### `rules.yaml`
```yaml
person: <名>
rules:
  - id: <名缩写>-01
    category: 环境|选股|买点|卖点|仓位|止损|空仓|心态
    rule: 一句话规则（你的归纳）
    quote: 原文短引（≤60 字，修正明显 OCR 错字）
    source: text/<文件>.md#page-N
    evidence: 原文|二手|实盘反推
    codable: true|false
    signal: 若 codable，用日线/涨停池可算的伪定义（如「T-1 涨停家数 < 30 且 连板高度 ≤ 3 → 冰点」「首笔买价 = 涨停价 且 T-1 未涨停 → 首板打板」）
    data_check: 若有成交数据，对照结果（一致/冲突 + 数字）
```

## 纪律
- **不编造**。找不到出处的不写成规则；拿不准的标「待核」。引用必须能在 text 里 grep 到。
- **原文 > 二手 > 实盘反推**，三者分开标。实盘反推只来自 trades/ 的数字。
- 幸存者偏差、营销合集（98kecheng 水印 = 倒卖课程站）、「N 个月 N 倍」口号要在 §1 点明，不当作证据。
- 只写文件，不改 `people.yaml` / 工具脚本 / 其它人物目录。

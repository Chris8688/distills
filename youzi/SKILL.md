# 游资心法库（youzi）

思路蒸馏，**只出分析，不改生产仓位、不下单**。先读 `docs/01-蒸馏笔记.md`（跨人物综合：证据分级与语料问题 §0、实盘事实 §1、说做冲突 §2、流派速览 §3、可借鉴 §4、与纪律冲突 §5）。

## 数据在哪

- `data/people.json`：71 人的流派、58 位标签、资料等级、可蒸馏性分数与结论、成交画像关键数、逐人笔记路径
- `data/rules_index.jsonl`：840 条规则（`rules.py` 查）
- `data/benchmarks.json`：15 位有成交数据人物的同口径基准
- `docs/people/<名>/`：逐人 `蒸馏笔记.md`、`rules.yaml`、`trades/profile.md`、`entry_types.md`（语料库派生笔记的拷贝）
- `docs/schools/`：流派对照表 6 份 + 仅合集人物笔记（见 docs/01 §8）
- **语料库**（本机，不进 git，版权属原作者 / 倒卖站）：`~/Baidu-Pan/游资心法+讲座全集1/distill/`（`$YOUZI_CORPUS`）
  - `人物索引.md`：人物 × 流派 × 文件总表
  - `人物/<名>/text/*.md`（全文，`<!-- page N -->` 锚点）、`trades/`（episodes_enriched.csv 等成交明细）、`src/`（原件软链）
  - 整理流水线在 `pipeline/`（见其 README）

## 命令

```bash
cd ~/distills/youzi
python3 rules.py --person 北京炒家                 # 某人全部规则
python3 rules.py --school 情绪周期 --codable       # 某流派可编码规则
python3 rules.py --category 止损 --evidence 原文
python3 rules.py --conflict                        # 实盘与说法冲突的规则
python3 rules.py --grep 冰点
grep -rn "关键词" ~/Baidu-Pan/游资心法+讲座全集1/distill/人物/*/text/   # 全文检索

PY=~/Baidu-Pan/游资心法+讲座全集1/distill/.venv/bin/python
$PY profile.py 交割单.xls [更多文件] --name 我     # 交割单画像 + 对标游资（行情读 youzi-sentiment 的全市场缓存）
python3 build_data.py                              # 语料库更新后重汇总 data/ 与 docs/people、docs/schools
$PY selection.py                                    # 首板选股规则检验 → docs/02-选股检验.md（约 1 分钟）
```

## 怎么回答

1. **问某人的模式 / 心法**：先读 `docs/people/<名>/蒸馏笔记.md`（§0 一句话、§2 核心模式、§3 规则表、§4 说做对照、§7 评分）。引用要带出处（`text/<文件>.md#page-N`）和证据等级；**二手（58 位合集、图文解读、揭秘文章）要明说是二手**。
2. **名言真假 / 出处**：先查 docs/01 §0 的归属错误清单，再 `rules.py --grep` 和全文 grep。养家「情绪周期六阶段」、徐翔《心性之刀》、赵老哥「二板定龙头」都有归属问题。
3. **说的 vs 做的**：只在有 `trades/` 的人物上下结论（A 级可信，B 级看 profile 的「卖出配对率」），用 docs/01 §2 与该人笔记 §4 的数字；没有成交数据的标「无法检验」。
4. **某流派怎么做**：用 docs/01 §3 + 对应对照表；分清「能编码的」和「真正的 alpha（不能编码）」。
5. **给交割单**：跑 `profile.py`，报胜率 / PF / 持有分布 / 买点结构 / 封板率 / 次日低开处理，并和 benchmarks 横比。按纪律别拿横比给模式排名（「模式差异 < 行情差异」，docs/01 §1.2）。
6. **想把游资规则用到持仓**：说明冲突（docs/01 §5：情绪驱动、不看基本面、T+1）。只有市场层环境闸门与执行纪律可借鉴；要接进生产策略是持仓意图，先问用户，并先在真策略上做随机阀 + 样本外检验（`youzi-sentiment` 已做：趋势池上无增量）。
7. **问「挑票规则能不能用」**：引用 docs/02-选股检验.md —— 日线规则解释名家超额 ≈0%，超额来自盘中封板判断；机械组合扣成本为负，不能实盘。
8. **今天情绪 / 冰点退潮**：转 `youzi-sentiment`。
9. 不给买卖建议；「N 个月 N 倍」只当营销口号。

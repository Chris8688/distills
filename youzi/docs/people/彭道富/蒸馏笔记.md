# 彭道富 · 蒸馏笔记（简版）

## 0 一句话（他靠什么赚钱）
不是有实盘记录的游资，而是《龙头信仰》作者（花名"拈花成佛"）：主张在确定性行情与确定性题材里只做龙头股，但**反对追高/打板**——"做龙头是选对好股且选对好位置"；配一套刚性七条止损。

## 1 人物与语料
- 人物：四川大学 MBA，"一线投资者"，著作《龙头信仰》（`text/58位·中册·第16章.md#page-167`，二手）。
- 战绩：语料中**没有任何战绩或资金说法**，也无交割单。身份更接近作者/讲师。
- 语料：仅 `58位·中册·第16章.md`（16 条问答，98kecheng 水印），二手；内容大量为哲学/佛学化表述（"空性""守住真气"）。

## 2 核心模式
环境：只做确定性行情与题材，"市场邀请你"才交易，不在逆市中找机会（`#page-170`）→ 选股：龙头股是体系中心，"偏离龙头就是风险"，市场没有龙头就不做（`#page-169、171`）→ 买点：龙头的"恰当位置"，位置已高宁愿放弃（`#page-170~171`）→ 止损：七条刚性止损，任一触发即执行（`#page-169~170`）→ 空仓：无龙头即空仓；暴涨行情是风控最大敌人（`#page-174`）。

# 欢乐海岸 · 蒸馏笔记（简版）

## 0 一句话（他靠什么赚钱）
（二手描述）不轻易出手，一出手就是多个关联席位合计上亿资金，在当下市场最强的人气总龙头（多为 3 板以上）**分歧时大笔买入，把分歧买成一致**，然后锁仓到破位才走，靠的是「造妖 + 席位溢价」。

## 1 人物与语料
- **身份不明**：「欢乐海岸」是营业部的名字（中泰证券深圳欢乐海岸营业部），**不是某一个人**。合集列了 3 个传闻：赵丹阳、徐留胜，以及「本尊是一名女子」，都没有出处（`58位·中册·第24章#page-223~224`）。
- **语料只有一份**：`58位·中册·第24章.md`（4 页，98kecheng 水印），是编者根据龙虎榜写的风格描述，**没有本人原话**。最后一段「环境决定仓控，个股围绕龙头…」是编者自己的总结，不能算在他头上（`#page-226`）。
- 他留下的痕迹：不颜不语自述「我接他的盘就是赚钱…第二天我就给他抬轿」（`人物/不颜不语/text/58位·下册·第09章.md#page-126`），说明他在 2018 年前后被当作「席位风向标」。
- 列举的标的（四川双马、三江购物、冀东装备、华北高速、中科信息、贵州燃气、万兴科技、盘龙药业、华锋股份）大致在 2016~2018 年，**和涅盘重升实盘帖里的标的高度重合**（涅盘提到四川双马、三江购物、冀东装备、华北高速、万兴科技、盘龙药业），可以互相作为时代背景的佐证。

## 2 核心模式（全部是编者描述）
- 环境：没有描述。
- 选股：市场最强的热点总龙头，人气风向标（`#page-223`）。
- 买点：「介入的位置，一般都是高位板，多数都是 3 板以上，极少数涉及首板的」（`#page-224`）；在分歧时大笔买入，把分歧买成一致（`#page-225`）。
- 仓位：多个关联席位合计「经常都是上亿的，至少都是好几千万」（`#page-224`）。
- 卖点：停牌核查后复牌冲高时卖，或者确认跌破 5 日线时卖（`#page-225`）；出现首阴也不急着出货（`#page-225`）。
- 止损 / 空仓：没有描述。

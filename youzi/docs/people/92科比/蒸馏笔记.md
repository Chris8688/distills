# 92科比 · 蒸馏笔记

## 0 一句话（他靠什么赚钱）

以「情绪周期四阶段」为底，在三种模式之间切换：主线前排的首板/低位板套利（补涨、切换）、主升龙头的分歧低吸或反包、高低切到新题材。每只票 25%-33% 仓位，同时持 2-3 只，用题材预判决定扫板还是低吸。他的标签是「首板高手」，但 2020Q1 成交里首板打板只占约四分之一笔数；利润几乎全部来自持有 ≥2 天的延续段。

## 2 核心模式

1. **市场环境（情绪周期）**：四阶段——低位震荡（试错）→ 主升 → 高位震荡 → 主跌（《情绪周期》p1-2；58 位 p194）。判断赚钱效应「看昨日涨停表现……涨停后次日都没有溢价的就是亏钱周期」（直播精选 p2）。高位震荡阶段轻仓，不博弈穿越；主跌连杀到第二天时，尾盘可以找买点，「第三天肯定会有情绪的修复」（《情绪周期》p2）。
2. **选股（三种模式）**：
   - 主升龙头：辨识度、硬逻辑、带动性、有换手；「看好，分歧，买入」，不在乎打板还是低吸（《情绪周期》p1；144 页 p13-14）。
   - 补涨：主线赚钱效应好时，做同属性的低位首板或二板（直播精选 p1）。首板要选「流通盘不大的，股价不高的，图形可以的，没有明显庄家的」，提前加自选，「第二天关注异动，有异动就打板」（直播精选 p1）。
   - 切换：主线到高位拉不动板、或主跌之后，去做新题材的首板（直播精选 p1）。
   - 回避中位股：「切忌做中位股 3 进 4，4 进 5」（直播精选 p1）。
3. **买点**：扫板（主线日内龙、超人气龙头、国家级重磅题材，早盘前半小时）；排板（主线后排、非主线前排、环境差时）；回封（早盘秒板没有强逻辑的、中高位缩量板、首板分仓套利）（干货 p1-4）。弱转强不要竞价高开，要「开盘后快速叠量买起来的」（144 页 p14；直播精选 p5）。
4. **仓位**：「保持曲线的稳定，分仓是基础。小资金，分333，资金成长了百分之25一个，后面我准备降低到百分之20一个」（2020-06-03，日常交流贴 page 129）。反对梭哈和杠杆（58 位 p193；直播精选 p4）。
5. **卖点**：开盘前先给市场、板块、个股三个维度打分，三项里两项以上强就「多等等看」，两项以上弱就「果断及时处理」；核心看竞价和开盘定势（干货 p5）。非龙头开盘走势不好，「尽可能在-2%以内解决战斗」；龙头和前排不急着出；冲到 6 个点以上不能快速封板、行情又差的先出（干货 p6-7）。超短的纪律是隔日卖，除非隔日超预期（直播精选 p2）。
6. **止损**：「止损与否，和亏几个点没关系。是主观判断持股走势是否低于预期」（2020-05-21，page 120）。
7. **空仓**：情绪差时轻仓、空仓（2020-06-24「实在没什么好的机会，空仓收盘」page 191；2020-07-17 page 473）；「逆势硬撸，还是不可取的」（2021-07-01，page 28）。

## 5 演化与前后矛盾

- **2020 上半年（百万杯）**：多手法——首板、二板、龙头低吸、转债套利（新天转债一笔 +130 万，是 Q1 最大单笔盈利）、逆回购。
- **2020 年中**：主升龙头锁仓（王府井、省广、中芯、中免），2020-07-06「最后的资金，梭哈省广集团」（page 19）——和「反对梭哈」**冲突**。2020-07-26 宣布不再更新持仓（体量大了怕影响股价）。
- **2021-03**：抱怨首板生态被「华鑫上海分」机器人颠覆，「堪称首板选手的噩梦」（page 641）。干货里也写「目前做连板的性价比并不高……目前个人主打的是低位板套利」（干货 p1）——这时首板才成为主业，而这时首板的环境恰恰最差。
- **2021-11**：「前两个月，打板炸的怀疑人生。被迫为了适应市场环境的变化，第一次波段持股那么久……再被普及了基本面以后，坚定了信心」（page 7）；2022-01「对待有妖相的股票，看好就是一路加仓」（page 4）；2022-04「波段操作还是很满意的」。**他从超短转向了波段 + 基本面。**
- **对基本面的态度**：2020-07-20 写「基本面叠加情绪，是未来的方向」，2021-02-05 又写「所谓的逻辑和基本面，就是用了骗取更多接力筹码的吹票手段」，2021-11 又「被普及了基本面」。三处说法不一致。
- **空仓**：144 页的「8 字真言（……空仓）」是编者加的。他本人有空仓收盘的记录，但 Q1 成交中收盘无持仓只有 3 天。

## 6 与本项目纪律的对照

**可以借鉴的**
1. **情绪 × 指数四象限**（144 页 p5，编者归纳）、「昨日涨停溢价」作为赚钱效应读数——可以作为 A 股市场状态的辅助标签（只作信息、不进仓位），和用户「新闻和情绪只作线索」的纪律兼容。
2. **固定 25% 分仓 + 不加杠杆**：与 `factor-concentration` 的总敞口思想一致。
3. **利润来自延续段**：持有 ≥2 天的 24% 段贡献了 105% 的净利——同样是「截断亏损、让盈利延续」，又一个支持「不加止盈」的独立样本。
4. **晚期转型**：2021 年后他自己承认首板被量化和机器人吃掉，转向波段和基本面——正好印证用户的「适配性 / 打法不可外推，制度性环境变化才可以外推」。

**冲突 / 不可用的**
1. 核心能力「题材预判」「先于市场发现可发酵的舆论事件」是信息和主观能力，没法规则化，也和用户的「叙事打折」纪律相反（他是押叙事、不管真假：「研究真实性，不如研究题材可发酵预期」，2020-07-14）。
2. 「股票就是筹码交换的游戏，所谓的逻辑和基本面……吹票手段」与用户的基本面证伪体系对立。
3. 执行依赖盘中扫板、排板、回封，用户的日线信号系统做不到。

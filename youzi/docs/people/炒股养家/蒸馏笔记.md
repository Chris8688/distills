# 炒股养家 · 蒸馏笔记

> 规则明细见同目录 `rules.yaml`（YJ-01 ~ YJ-47）。引用锚点：OCR/pdf 文本用 `#page-N`（N 是文本里的 `<!-- page N -->` 锚点）；淘股吧帖子导出的 doc/docx 没有页码，用 `#post-发帖时间`。

## 0 一句话（他靠什么赚钱）

**靠回避系统性崩溃来保住复利，再把重仓集中押在一年少数几次"主流热点 + 新故事"的一字板/首板上。**平时用大量小单试错、隔日了结，盈亏接近打平；利润几乎全部来自少数几笔重仓。实盘反推：2010-04 至 08 月的 90 段持仓里，7 段打板贡献了净利的 115%，其余 83 段合计亏 5.2 万。

他的"情绪周期"本质上是一个**风险开关**：盯追涨者和抄底者是赚钱还是亏钱，决定仓位开多大、用哪种打法。它不是一套选股公式。

## 1 人物与语料

**人物（标出处）**
- 上海人，1990 年代末入市，前十余年在 K 线技术、价值投资之间反复，基本"坐电梯"（原文：`text/股票交易的最优化模式的个人浅见.md#post-2011-04-13T20:08`）。2008 年辞职做职业，账户从 90 多万跌到不足 40 万（原文：`text/炒股养家等一线游资_纯图版.md#page-53`，2011-08-09）。
- 资金打卡，均为原文帖子：2010-05 实盘赛账户 200 万（一年前约 50 万）；2010-11 到 400-500 万；2011-01-24 达 600 万（`text/炒股养家100万到600万前.md` 各帖）。2011 年收益他自述"大致应该是 100，120"（`text/炒股养家等一线游资_纯图版.md#page-61`）。开户本金说是"1 万"，但期间有工资投入和消费支出，"已经算不清了"（`text/炒股养家100万到600万后.md#post-2011-03-04T23:40`）。
- 职业炒手杯实盘赛：第四届"侥幸得了榜眼"（原文：`text/炒股养家-第五届职业炒手杯实盘炒股大赛.md#page-2`）；2010-07-01 至 09-30 一届从 209 万做到 300 万，+43.6%（二手：`text/炒股养家交割单图文解读1-中年悟道.md#page-2`）。
- 后来的规模只有二手说法：2015 年"好事者统计龙虎榜推算至少 10 亿以上"（`text/58位·上册·第01章.md#page-51`）；"保守估计数亿"，席位为华鑫上海茅台路、淞滨路（`text/炒股养家干货合集  共62页_纯图版.md#page-2`）。都无法核实。

## 2 核心模式

### 2.1 市场环境判断：他自己的"情绪周期"术语，以及怎么量化

先说结论：**你要的"冰点/启动/发酵/高潮/分歧/退潮"不是他的词。**在他 2010-2013 年的全部原帖里，"冰点""首板"出现 0 次，"退潮""发酵""情绪周期"只出现在约 2019 年的伪托《传记》里。他自己用的是下面三套框架，都围绕"赚钱效应 / 亏钱效应 / 崩溃 / 由弱转强"展开。

**① 测量层：两类人群的盈亏（YJ-02 / YJ-03）**
- 追涨者赚钱 → 会重复追涨、影响周围人 → 行情被推向高潮；追涨者接连失手 → 自我惩罚、减少操作 → 强势股没有接力，开始补跌。
- 抄底者赚钱 → 大盘难以大跌；抄底者也亏 → 抄底的人减少 → 稍有卖压就出现无抵抗式下跌 → 崩溃前兆。
- 具体指标：昨日涨幅前 20 名今天的表现，加上领跌品种、各个周期（如 90-120 天）的领涨领跌板块。

**② 演变层：酝酿 → 开展 → 蔓延 → 逆转（YJ-06），以及"崩溃"的定义（YJ-05）**
- 崩溃 = 几十到上百家跌停，不少品种跌 20-30% 以上。
- 由弱转强 = 市场没有跌停、跌幅榜普遍只跌 2-3 个点（YJ-10）。

**③ 操作层：弱势三段（YJ-07），以及 2011-01 版的下跌四阶段（YJ-08）**

**映射到常用六阶段**。左两列是他的概念和原文出处，右边是我们给的可算伪定义，阈值都没有回测：

| 常用名 | 他的对应概念 | 可算伪定义（日线 + 涨停池） | 仓位 / 操作（原文） |
|---|---|---|---|
| 冰点 | "崩溃"、恐慌释放；弱势中段 | 非 ST 跌停 ≥ 50 家（按 2012 年 2400 只股票的口径，需等比放大），且近 10 日跌幅 ≤ -20% 的股票占全 A ≥ 5%；另一条超跌口径见 YJ-11：指数 5 日跌 ≥ 5%、当日 ≤ -2%、偏离 MA5 ≤ -3% | 崩溃当天少量买，次日低开加仓，**左侧最多约半仓**（YJ-27："目前加到半仓"） |
| 启动 | "情绪逆转""由弱转强"；弱势末段 | 跌停 ≤ 2 家，跌幅第 20 名 ≥ -3%，E_up（昨日前 20 名今日均收益）> 0，同时出现一个热点类（当日创新高 ≥ 5 只且次日延续） | "暴利机会"，奋力出击；追涨主流里有爆发力的新故事（YJ-08 / YJ-17） |
| 发酵 / 主升 | 赚钱效应持续；热点之间滚动 | E_up 的 3 日均值 > 0，成交额分位上升 | 赢面 60% 以上的机会多，"接近每天交易"；主流可以重仓反复做（YJ-16） |
| 高潮 | "连续上涨一段后的集体涨停" | 行业 10 日涨幅 ≥ 15%，当日成分股涨停数创 20 日新高且 ≥ 5 只 | 特别小心，不追（YJ-12）；龙头开始按 YJ-32 观察卖点 |
| 分歧 / 退潮 | 弱势初段；亏钱效应出现；强势股补跌 | E_up 转负；跌幅榜前列出现近期涨停过的股票；领跌板块再创新低（YJ-13） | 低吸**止损盘**做反抽（YJ-26），已有强势股仓位减仓 |
| （崩溃前） | "酝酿崩溃情绪" | 跌幅榜里强势股占比高，且 90-120 天超跌板块再度领跌（YJ-04） | **先空仓或低仓**（"看天气要下雨就早点回家"，YJ-38） |

**两点保留**
- 他明确说阶段模型"只是辅助"，重点在多空双方的心理（YJ-09）。他自己也判断失误过：2011-06 判为"弱势末期"，结果稀土猝死，他公开致歉（`text/论反弹.md#post-2011-06-17T15:08`）。
- 伪托《传记》里的"连板高度梯队"（龙头 9 板 → 后面最多 8 板 → … → 某天没有连板 = 新周期，YJ-46）是现在最容易量化的版本，但**不是他的原话**，只能作为后人归纳。

### 2.2 选股
- 先给热点定性：主流（政策级、可以反复活跃）、次主流、支流、非主流（YJ-16）。主流热点里出现新故事是赚大钱的机会（YJ-17）。
- 热点识别：成批创新高的股票的共性；同等条件下选小盘低价（YJ-19）。
- 跟风套利：龙头超预期时，买同题材里尚处低位的品种（YJ-20）。
- 不打三种板：不符合主流的、不明原因的、累计涨幅过大的（YJ-21）。
- 权重：他说"政策面和人气面相对权重大些，技术和基本面相对次要"（`text/炒股养家100万到600万前.md` 2010-12-05 帖）。

### 2.3 买点
- 强势市场：追涨龙头或打板。投机板要求大盘好、当天最强或次强的热点，隔日卖（YJ-23）。主流题材不必等涨停，先买、确认后加仓（YJ-22）。
- 突发利好或主流新故事：盘前挂一字板重仓，这是他的"矛"（YJ-24）。
- 弱势市场：初段低吸止损盘，中段低吸崩溃盘，末段追涨强势（YJ-07）。
- 平时有大量小单试错，用来感受情绪（YJ-45）。

### 2.4 仓位
- 赢面 → 仓位对照表；满仓要求胜率 ≥ 90%、上行 30-50% / 下行 3-5%（YJ-28）。他还提到用凯利公式算仓位（YJ-29）。
- 重仓前要能看到后市 3-5 个涨停的空间（YJ-25）。重仓一年十几次（YJ-30）。
- 总仓位和全市场成交量正相关（YJ-15）。资金越大越放弃左侧和个股性机会（YJ-31）。

### 2.5 卖点
- 和买入同一套逻辑：先预判减仓，再确认卖出（YJ-35）。
- 主流龙头：从启动位置算通常有 50-100% 空间，目标价以下只做 T、不清仓（YJ-34）。
- 龙头的卖点：扩散股冲高回落、跟风股走弱、龙头不能及时上板 → 减仓；跟风股的亏钱效应递进 → 等反抽清仓（YJ-32）。

### 2.6 止损
- 口号是"永不止损"：卖出只因为不看好了，和成本无关；用"假设我现在空仓，还买不买"来判断（YJ-36）。
- 实际做法是**当天被套，次日早盘就走**（YJ-37）。所以"永不止损"指的是没有固定百分比的止损线，**不是死扛**。

### 2.7 何时空仓
- 系统性崩溃有前兆时先空仓或低仓（YJ-38）。既没有好大盘、又没有热点就休息（YJ-40）。
- 2012-05 至 07 月的阴跌里，他说"整体这段可能打平或者小亏"（`text/养家心法论股市.md#post-2012-08-19T22:53`）。

**几句名句的处理**
- **"买入机会，卖出风险"**：可以落成规则——买卖决策只看当下的上行 / 下行比较，**和持仓成本无关**（YJ-36）。可检验的推论是：退出时点不会在固定亏损百分比附近聚集。交割单与此一致。
- **"高手买入龙头，超级高手卖出龙头"**：名句本身**不可量化**。他自己的解释是"龙头理论实际并不科学，没有永远的龙头"。能落地的只有两条：卖出龙头的盘面条件（YJ-32），以及持有空间（YJ-34）。
- **"别人贪婪时我更贪婪"**：常被误读成反向操作。原文是顺着赚钱效应放大仓位、顺着亏钱效应加倍回避（YJ-41）。
- **"敢于大盘低位空仓，高位满仓"**：口号版的 YJ-15 / YJ-38，意思是仓位跟情绪和成交量走，不跟点位走。不单独量化。
- **"永不止损，永不止盈"**：要和 YJ-37 一起读。不是扛单，而是不用成本价做决策。

## 5 演化与前后矛盾

- **2008-2009**：熊市中被腰斩，2009 年闭门学习。手法来自 asking（"行情好就多做做，行情不好就多休息……选股大众情人"）和职业炒手（超跌板块反弹）（`text/炒股养家100万到600万前.md#post-2010-11-30T23:20`、`#post-2010-05-26T17:49`）。
- **2010（50 万 → 300 万）**：以超跌低吸和热点追击为主，模式"跟随市场的情况随时变化"（2010-05-25）。大量试错单，偶尔一字板重仓。
- **2010-11 ~ 2011-03（300 万 → 600 万+）**：重心转向"主流 + 新故事"（触摸屏、抗癌、新三板、美罗抗辐射）；提出"矛与盾"；7 成重仓美罗，"至卖出时与最高利润相比损失过半"。
- **2011-04**：一面说"纯 K 线技术的打板，统计胜率约 45%，大致于澳门赌场"，一面说"板上买票占本人操作的一半"。他的解释是：45% 针对的是纯技术打板，加上热点判断才行。这和 2010-12 说的"追板 8-9 成成功率"放在一起读并不矛盾。
- **2011-06 ~ 2011-12**：弱势市场，形成"弱势三段"（低吸止损 / 低吸崩溃 / 追涨强势）。
  - 2011-06 说左侧"如同鸡肋"，2011-08 却系统化地做"低吸崩溃盘"、左侧加到半仓——**这是阶段适配，不是反悔**。
  - 2011-08 拿 500 万打新股做无风险套利，显示低风险偏好。
- **2012-08**：提出"套利性机会"（龙头超预期 → 补涨），并量化了崩溃标准。不过他也承认"当前市场的操作难度要比 08 年大"，市场"整体是一个负和博弈的格局"（2012-08-30）。
- **规模效应**：百万级放弃部分左侧，千万级分仓、放弃个股性机会（2011-03-07）；2011 年已"感觉难度确实大了很多"。
- **后世包装与原话的冲突**
  - 《传记》写"《养家心法》不建议打板"，原话是"板上买票占一半"。
  - 二手解读写"吃大肉还是要靠龙头"，原话是"龙头理论实际并不科学"——不过交割单确实显示利润集中在少数龙头一字板上，两种说法在数据上可以调和。
  - "情绪周期 / 退潮 / 连板高度"这套术语是后人加上去的，他本人用的是"赚钱效应 / 亏钱效应 / 崩溃 / 由弱转强"。

## 6 与本项目纪律的对照

**可以借鉴的**
1. **成本无关的决策**（"假设空仓还买不买"）。和本项目"信号层出目标仓位、执行层按实时持仓对齐"天然同构：目标仓位本来就不看成本。这条可以当作人工干预时的检查口令。
2. **用市场广度做风险开关**（YJ-02 / 04 / 05 / 10 / 15），可以作为 A 股趋势池的 regime overlay 候选：
   - 跌停家数、昨日前 20 名的次日表现、跌幅榜宽度、成交额分位，都能用日线和涨停池算。
   - 但 波动率入场阀检验 的结论提醒过：在已经自带 ATR 自适应的 ST 策略上，加入场阀很容易没有增量。所以只能作为**待检验假设**，要跑随机阀对照，不能直接上线。
3. **"利润来自少数重仓、平时试错打平"的收益结构**，与趋势策略"靠少数大趋势覆盖多次小亏"同构。这也印证了 `cn-stock-screen` 里"最大单笔占利润"这个指标的意义。
4. **回避崩溃 > 追求进攻**（"防守才是拉开差距的核心"），对应纪律里的"卖在拐点"和"控总敞口"。
5. **制度性摩擦意识**：2011 年他多次因为"打电话 / 特停"回避创业板，说"短线收益率目前仅对国内 a 股有效"，资金上亿后收益迟滞。这和 CLAUDE.md 第 3 条"能外推的只有制度性摩擦"一致：他的 alpha 有明确的市场和容量边界。

**冲突或不可用的**
1. **执行层面**：一字板盘前排队、板上抢单、分时 T+0、隔日卖出，依赖盘中席位速度和 T+1 隔夜博弈，日线趋势引擎做不了。他自己也说"现在很多一字板已经被……包场了"（2012-08-18）。
2. **止损哲学**：他没有固定止损，靠盘感次日出局；本项目是 ATR / 规则化退出。两者在"不看成本"上一致，在"规则 vs 主观"上冲突。
3. **叙事优先 vs 基本面证伪**：他明说"政策面和人气面权重大，技术和基本面次要"，题材"是不是山寨不重要，最终市场说了算"，"故事很重要"。这正是 CLAUDE.md 四步证伪第 4 步要打折的东西。他的"主流 / 新故事"只能当**情绪线索**，不进入基本面结论。
4. **"龙头 / 跟风套利"就是同因子高 beta**：同一题材多点出击，在组合层面是加杠杆，不是分散（对应"同因子多只是杠杆不是分散"）。他自己也承认多点出击是资金大了之后的无奈。
5. **"适配性不可外推"**：他的成功高度依赖 2010-2011 年 A 股游资生态和本人的主观判断；把他的阶段判断当成可迁移的"标的属性"会犯 CLAUDE.md 第 2 条的错误。

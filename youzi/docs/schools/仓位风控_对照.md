# 仓位风控 · 可编码规则对照（触发条件 → 动作）

范围：龙飞虎(LFH)、相城采莲路(XC)、孤独牛背(GDNB)、挑战12345(TZ)、徐翔(XX)、职业炒手(ZYCS)、章盟主(ZMZ)、浓汤野人(NTYR)。另含孤独牛背控回撤合集里的其他 ID：打板赚盒饭、难觅知音、吞吴破秦（58 位合集把他们误归为孤独牛背）。

**怎么读这张表**
- 规则 id 指向各人 `rules.yaml`。
- 证据等级：原 = 本人原文；二 = 二手；传 = 来源不明或疑托名；实 = 交割单实测。
- **共识** = ≥3 个独立来源说过同一件事；**少数** = 2 个；**孤证** = 只有 1 人。同一合集里的不同 ID 算独立来源，同一人的多次表述不重复计数。
- 阈值后面标"*"的，是原文没给、为了编码补的假设，必须回测确定。

## I 可以直接写进组合层原型的最小集合（仍需回测）
1. **G1 + G8**（状态门控 + 小仓试错解除）：共识最强，但伪定义要自己定、自己测。
2. **D2**（浮亏禁止加仓，加仓只加在创新高上）：共识，和趋势系统的金字塔加仓同构，冲突最小。
3. **E1**（试错仓 → 确认仓）：共识，可直接映射到"首次信号 0.3 档 → 确认后满档"。
4. **B5**（出金，缩小风险本金）：共识，不改变策略内部仓位，与趋势系统不冲突。
5. **A1~A3**（账户回撤分档节流）：孤证 + 实测未执行。只能作为待检验假设，要和随机对照、"不节流"基线比较。在趋势系统里，它可能在 V 型反转时砍掉利润（参考 波动率入场阀检验 对"外加过滤器"的否定性结论）。

不建议迁移：B1/B2（等价于止盈）、F3/NTYR-01（满仓/加杠杆）、G2（A 股大小盘格子，跨市场无对应）、所有依赖分时或 L2 的条件（LFH-02~04、GDNB-04）。

## 1 各人对阶段的命名

| 人 | 阶段命名（原词） | 层级 | 出处 |
|---|---|---|---|
| 炒股养家 | 情绪的**上升期** → **高潮** → **退潮期**；用「赚钱效应 / 亏钱效应 / 恐慌效应」描述驱动力；下跌分初期、中期、末期 | 一层 | YJ:养家心法#p89、#p90；YJ:58上01#p58；涅盘转述养家：下跌初期强势反抽、中期超跌、末期新题材是「大周期」（NP:2019下#L5492） |
| 涅盘重升 | **大周期**（强化 / 弱化 / 震荡）× **小周期**（每天的板、日内）；**高潮 / 逼空**（中末期）；**冰点**（相对的，冰点后还可能有冰点）；**退潮期**；**情绪下降周期 = 补跌周期**；**末期** | 两层（「一个中期一个日内」NP:2019上#L5228） | NP:2019下#L3870、#L4406；NP:2019上#L4562、#L6961；NP:2020#L1894、#L2810；情绪演变的认知#page-7（逼空） |
| 不颜不语 | **混沌期 → 主升期 → 分歧期 → 退潮期**；龙头视角：**主升 → 分歧（断板）→ 补涨 → 二波**；还有「新周期」「轮动阶段」 | 一层（以龙头为锚） | BY#p127、#p144、#p145~146、#p142 |
| 独股一箭 | **强市 / 弱市**；**熊市中段**；「动于阴末阳升，止于阳极阴生」 | 大盘层 | DG:20w#page-5、DG:K线版#p103 |
| Asking | **强市 / 弱市**；**下跌通道**；**下跌末期**；**否极泰来临界点**；牛市「慢涨急跌」、熊市「慢跌急涨」 | 大盘层 | AK#p84~89、#p93 |

**同义归并**：养家的「上升期」≈ 不颜不语的「主升期」≈ 涅盘的「大周期强化 + 主流持续」；养家「退潮期」≈ 不颜不语「退潮期」≈ 涅盘「情绪下降周期 / 补跌周期」；「冰点」只有涅盘明确用了，养家和不颜不语都没写成阶段名（不颜不语的「混沌期」接近冰点后的过渡态）。Asking 和独股一箭的「弱市」是**大盘层**的概念，和情绪层正交，应该作为外层闸门。

## 3 每阶段仓位与动作对照

| 阶段 | 养家 | 涅盘重升 | 不颜不语 | Asking / 独股一箭（大盘层） |
|---|---|---|---|---|
| **冰点 / 恐慌底** | 恐慌效应下做超跌；「恐慌砸盘的机会」（YJ:58上01#p58、YJ:养家心法#p148） | 冰点是相对的，次日强势股反包才确认（NP:2019上#L6961）；强势股集体补跌后，次日还有恐慌杀跌，大概率见底（NP:2018下#L297） | 急跌到恐慌尽头会反转，撬地板（BY#p135，个案） | AK：弱市只做极度超跌反弹（AK#p86）；DG：不狠砸不入场（DG:K线版#p103） |
| **启动 / 混沌（修复）** | 反弹初期首选调整到位的前期强势股（YJ:养家心法#p148） | 没有恐慌杀跌时，看市场情绪和投机情绪，预判点、走强点逐渐给仓位（NP:2018下#L297） | 混沌期第 1 波基本不参与（BY#p127~128） | AK：下跌末期成交放大、强势板块向上 → 进场找感觉（AK#p88~89） |
| **主升 / 上升期** | 相对激进，情绪高时重仓也无妨（YJ:养家心法#p90、#p115） | 大周期好就一直保持大仓位（NP:2019下#L3870）；第一笔确定性机会就上大仓（NP:2019上#L828） | 直接做龙头，有高度就拿（BY#p130） | AK：行情好满仓滚动（AK#p89）；DG：强市七成（DG:20w#page-5，实际是满仓） |
| **高潮 / 逼空** | 「推向高潮」（YJ:养家心法#p89）；高手买龙头，超级高手卖龙头（YJ:58上01#p52） | 高潮一般不接力（NP:2020#L545）；末期大仓位只留给打板（NP:2018上#L942）；逼空是中末期的高潮（情绪演变的认知#page-7） | 「你不高潮我不走」，在题材高点卖（BY#p132） | — |
| **分歧（龙头断板）** | — | 情绪调整阶段在主流内部去弱留强（NP:2019下#L5086） | 高位不恐慌 → 次高位；高位恐慌 → 低位补涨（BY#p130）；补涨断板后回到龙头做二波（BY#p145） | HL：分歧时大笔买成一致（欢乐海岸#page-225） |
| **退潮 / 下降（补跌）周期** | 管住手，连账户都不开（YJ:养家心法#p90、#p173）；高位炸板、跌停增多、龙头回调时不出手（#p114） | 空仓，或每天只做低位板块效应点前排套利（NP:2020#L2819）；别碰情绪票，除非和指数共振出大阳线（NP:2020#L1894） | 没把握就空仓（BY#p133） | AK：下跌通道全部放弃（AK#p84）；DG：熊市中段尽量空仓（DG:K线版#p103） |

**说做落差（必须写进任何「按阶段控仓」的实现里）**：涅盘在 2017 年自记日志中，自评「情绪差」的日子买入额并没有低于「情绪好」的日子（约 95 万 vs 48 万，n=96，粗统计）；他自己也说「我自己没空仓，手痒」（NP:2017上#L942）。**阶段判定可以由机器做，执行纪律也应该交给机器**，这正是这些规则对用户最有价值的地方。

## 4 我认为最一致的「可计算情绪阶段定义」

### 4.1 输入（日频，T 日收盘后可得；涨停池 + 日线）
| 记号 | 定义 | 依据 |
|---|---|---|
| ZT | 收盘涨停家数（剔除 ST、上市 ≤5 日的新股；20%/30% 板按各自涨跌幅限制） | NP-02 |
| DT | 收盘跌停家数（同口径） | YJ#p114 |
| ZB | 盘中触及涨停但收盘未封的家数；ZBR = ZB/(ZT+ZB) | NP-02、NP-04 |
| H | 收盘最高连板数；LB = 连板（≥2）家数 | NP-02、NP-10、BY-07 |
| P1 | T-1 涨停股在 T 日的等权平均涨幅（剔除 T-1 一字、T 日停牌） | NP-04、YJ#p89 |
| P2 | T-1 连板（≥2）股在 T 日的等权平均涨幅 | NP 数据块 |
| HIr | T-1 连板 ≥3 的股票在 T 日的平均涨幅；HId = 其中跌停的占比 | 五人共识（§2） |
| BR | 上涨家数 / (上涨 + 下跌) | NP-03 |
| IDX | 中证全指或上证收盘；MA20、MA60 | AK-02、NP-05 |
| AMT | 两市成交额 | AK-03 |
| pct(x) | x 在过去 250 个交易日里的分位（0~100）。**一律用分位，不用绝对数**：2017 年约 3400 只股票、10% 涨跌幅，现在股票数和涨跌幅制度都变了，绝对阈值不可外推 | 用户纪律「制度性摩擦可外推、历史数值不可外推」 |

### 4.2 外层：大周期闸门（regime），只做负向约束
```
WEAK_MKT  = (IDX < MA20 and MA20 斜率 < 0)                         # AK-01/02、DG-10
         or (pct(AMT_ma5) < 20)                                     # AK-03/04、DG-11
BIG_CYCLE_UP   = (IDX > MA20) and (max(H, 20日) >= 5) and 主流存在   # NP-05（「5 板」为待校准）
BIG_CYCLE_DOWN = (max(H, 5日) < max(H, 前20日)) and 最高板已断       # NP-10、BY-07
               or WEAK_MKT
```
- 主流存在（代理）：过去 5 日有同一申万二级行业 / 概念，涨停数累计 ≥ 全市场涨停数的 25%（**待校准**）。

### 4.3 内层：情绪阶段状态机（每天输出一个状态）
优先级从上到下，命中即停。

| 状态 | 判定（T 日收盘） | 阈值出处 |
|---|---|---|
| **S6 退潮 / 补跌** | `P2 < 0 连续 2 日` 且 (`HIr < -5%` 或 `HId ≥ 30%`)，且 `H < 前 10 日 H 峰值` | 结构来自 NP-07、BY-02、YJ#p114；-5% / 30% **待校准**。2019-05-24 读数 P1=-1.5、P2=-3.4、ZT=40 之后，涅盘回撤 500 万（图文解读#page-45、NP:2019上#L8081），可以作为一个**正例锚点** |
| **S1 冰点候选** | `P1 < 0` 且 `pct(ZT) ≤ 20` 且 (`HIr ≤ -5%` 或 `pct(DT) ≥ 80`) | NP-09、NP-27；涅盘 2017 年自评「情绪差」的日子，ZT 中位 17、跌幅>5% 家数中位 33、BR 中位 0.41（2017 日志，自记统计） |
| **S1→S2 冰点确认** | 冰点候选的次日 `P1 > 0` 且 `HIr > 0`（高位股反包）；否则顺延为新的候选，因为「冰点后可能还有冰点」 | NP-09（NP:2019上#L6961、#L6289） |
| **S2 启动 / 混沌** | 冰点确认后，`MA3(P1)` 上升，`pct(ZT)` 从 ≤20 回升到 ≥40，H 仍 ≤ 前一周期峰值 | NP-04；YJ#p148；BY 混沌期 |
| **S4 高潮** | `pct(ZT) ≥ 90` 且 `BR ≥ 0.7` 且 `pct(P1) ≥ 80` | NP-17、YJ#p89、BY-05；BR 0.7 参考 2017 日志 BR 的 p90=0.81（**待校准**） |
| **S5 分歧** | 当前最高板断板（T-1 为最高板、T 日未涨停），或 `ZBR ≥ 0.4` 且 `P2 < 0`，同时**未**满足 S6 | BY-02、NP-04；ZBR 0.4 参考 2017 日志 ZBR 中位 0.30、p90 0.59（**待校准**） |
| **S3 主升** | `MA3(P1) > 0`，H 创本周期新高（> 前一周期峰值），`ZBR < 0.3`，且 BIG_CYCLE_UP | NP-05、BY-01、YJ#p90；P1 参考 2017 日志中位 +1.6%（**待校准**） |
| 默认 | 上一个状态延续 | — |

**分歧之后怎么走（BY-02 + NP-24）**：S5 当天如果 `HId < 10%`（高位不恐慌），次日偏向次高位，状态多半回到 S3（换龙继续）；如果 `HId ≥ 30%` 或断板龙头跌停（高位恐慌），次日偏向低位补涨；补涨的高度低于原龙头 → 进入 S6 的概率上升（BY-07「高度递减」）。

### 4.4 输出：每个状态的仓位上限（只做上限，不做加仓信号）
| 状态 | 仓位上限 | 动作 | 出处 |
|---|---|---|---|
| S1 冰点候选 | ≤10% | 不新开情绪股；只允许极度超跌的试错 | AK-11、NP-09 |
| S2 启动 | ≤30% | 新题材首板 / 前期强势股的低吸 | NP-27、YJ#p148 |
| S3 主升 | ≤100%（受外层闸门约束） | 做主流核心；龙头持有到断板 | NP-05、BY-01、AK-05 |
| S4 高潮 | 不加仓；次日不接力 | 持仓在高潮日或次日兑现 | NP-17、BY-05 |
| S5 分歧 | ≤50% | 主流内部去弱留强；按 BY-02 在次高位和补涨之间选 | NP-24、BY-02 |
| S6 退潮 / 补跌 | **0~10%** | 空仓，或只做低位板块效应点的首板套利 | NP-06/07、YJ#p173、AK-02 |
| 外层 WEAK_MKT | 上限再乘 0.3 | — | DG-10（「弱市三分」）、AK-01 |

### 4.5 对用户的使用建议
1. 这套状态机是**市场层的 regime 变量**，可以作为 A 股趋势池的**候选负向闸门**：只在 S6 或 WEAK_MKT 时压低新开仓，不用它做正向加仓。这和「只负向剔除，不做正向加权」一致。
2. **上线前必须做的检验**（照搬 波动率入场阀检验 的做法）：在真策略 ST 趋势引擎 上做 ①闸门开 / 关对照，②随机闸门（同样的关闭天数随机分布）作为对照臂，③多组 fit/test 切分的样本外检验。闸门落在随机阀的高分位以上才算有增量。游资们的规则是为 **T+1 隔日超短**设计的，对持有几周的趋势仓未必有效。
3. **阈值校准**：先用 2017 年涅盘的自记读数（96 天）检查分位口径下的方向是否一致，再用 2019-05、2020-02、2024-01 这些已知退潮段做正例回放，不要直接沿用 2017 年的绝对数。
4. 数据依赖：P1、P2、ZB 需要涨停池和盘中最高价（日线 high = 涨停价可近似判定「曾涨停」）；全部可以用日线计算，不需要 L2。

# 龙头接力 / 连板打板流派 · 八人对照

覆盖：赵老哥、令胡冲、退学炒股、作手新一、陈小群、余哥、彭道富、大田连板。规则 id 见各自 `rules.yaml`。
证据标记：**[实]** = trades/ 统计支持；[原] = 本人原帖/直播；[二] = 二手整理；[待核] = 归属存疑。

## 1 "龙头"怎么定义

| 人物 | 几板确认 | 换手 / 爆量 | 题材地位 | 其它限定 |
|---|---|---|---|---|
| 赵老哥（语录期） | **二板定龙头**，"一板能看出来个毛" [二·待核] | **必须爆量**，无量一字不算龙头 [二·待核] | 新题材的"精神领袖"，弃旧题材 [二·待核] | 多点共振：题材派、龙头派、技术派都认同 |
| 赵老哥（2010 交割单） | 实际以**首板**为主（打板的 83%），二板只 17% [实] | 偏好开板后回封的板 [原] | 不做"很疯狂的票" [原] | 与语录期相反，见 §6 |
| 令胡冲 | 不以板数定龙头；说"首板风险大于二三板"，强势 N 板都打 [二] | 不看大单吃货 [二] | "人气股"：近期常涨停、次日不闷杀；龙头有溢价优势 [原] | 被新龙篡位即沦为跟风 [原] |
| 退学炒股 | 不以板数定；次新连续一字后的开板、新龙头卡位 [原/二] | **巨量烂板**是信号本身 [原] | 最热题材的人气股（雄安） [二] | 要"确定性"，不拘形式 [原] |
| 作手新一 | 2017-18 由首板转连板（连板占 90%+），高度 2-3 板抬到 4-6 板 [二] | 连续一字排第三板（获利盘松动易放量） [二] | 围着主线；大资金"承载票"：逻辑绝对主流、成交大 [二] | 非主线封板次日也无接力 [二] |
| 陈小群 | 不以板数定；看"高标/总龙头" [二] | 未强调 | **能带动板块起涨、上板带来跟风赚钱效应**才叫龙头；没地位不做 [二] | 逻辑硬、盘子小、深市 [二]；不博纯消息票 [原] |
| 余哥 | **越高越确定**："涨停越多确定性越高"，5-10 板都接 [二] | 未强调 | 尽量主流，支线少做 [二] | 龙头买不到就放弃 [二] |
| 彭道富 | 不以板数定 | 未强调 | 确定性行情 + 确定性题材里"最安全最暴利"的股 [二] | **反对追高**，要"好位置" [二] |
| 大田连板 | 不以板数定；龙头七阶段（启动→确认→发酵→加速→分歧→反包→龙回头） [二] | **换手龙**（相对一字妖、人人可参与） [二] | 主流板块里"人气最旺的那个仔" [二] | 分换手龙 / 卡位龙 / 补涨龙 [二] |

**共识**：龙头 = 主线题材 + 市场认可（人气/跟风/合力），只有赵老哥语录给了明确的板数门槛（二板）和换手门槛（爆量）。**分歧**：板数——余哥"越高越确定" vs 彭道富"位置太高宁可放弃" vs 令胡冲"首板风险最大"（他的 12 段首板数据反而胜率 83%）。

## 6 说做冲突与时间错位（重点）
1. **赵老哥"二板定龙头" vs 2010 年首板为主**：首板段占全部 49.8%、净利 68%；二板 8.4%、净利 14%；首板 PF 3.27 > 二板 PF 2.32。但语录在本语料中最早见于淘股吧用户 shglb 2013-05-03 的楼层（`text/【赵老哥】交易记录172页_纯图版.md#page-8`），悟道心法编者又称"传自神车时候"（2015），第三方图解明说"很多流传的赵老哥语录并非出自赵老哥之口"（`text/赵老哥交割单图文解读-8年1万倍.md#page-1`）。**结论：2010 交割单与语录分属两个时期（资金 200 万-1000 万 vs 亿级），且语录归属待核——既不能互证，也不能互相否证。** 资金容量改写模式这一点有本人原帖支撑（千万级后"满进满出…次日卖不掉"，`98页#page-82`）。
2. **"一直持有龙头"（赵语录、陈小群、余哥）vs 有交割单的人全是隔日**：赵 1 天 86%、令胡冲 82.5%、退学 91.8%。持有派的"拿到见顶"目前只有二手叙事。
3. **令胡冲"极少半路"**：机械分类半路 47.5%，但这是"5-7 个点预挂涨停价单"被判成半路的口径问题；修正后打板类约 68%。真正失败的是没封住的冲板单（8 段胜率 12.5%）。
4. **令胡冲"首板风险大于二三板"**：数据方向相反（首板 12 段胜率 83%，二板 3 段 33%），样本太小，不下结论。
5. **陈小群"不做 T"**：本人截图里浙江建投同日卖出又买回（做 T）。

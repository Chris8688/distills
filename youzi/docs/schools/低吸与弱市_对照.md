# 低吸流派与弱市生存 · 对照

覆盖七人：乔帮主、林疯狂、瑞鹤仙、明王、糊涂118、御剑飞鱼、rxybgb。各人细节见各自目录下的 `蒸馏笔记.md` 和 `rules.yaml`。本文只做两件事：

1. **低吸的对象、位置、买点、卖点**：七人的说法有什么异同，交割单（有数据的四人）怎么说。
2. **熊市（弱市）生存**：何时空仓、仓位上限，给出能用日线和涨停池算出来的定义。

> 数据口径：
> - 每段首笔买入对照不复权日线。r_buy = 首笔买价 ÷ T-1 收盘 - 1。
> - 日内位置 = (买价 - 日低) ÷ (日高 - 日低)。
> - 强势股 = 近 10 日有涨停，或 10 日涨幅 > 10%。
> - 特征是本次另算的（T-1 至 T-20）。乔帮主、rxybgb、瑞鹤仙是 OCR 展示单，林疯狂以原始 xls 为主。**样本小、有选择偏差，只作方向参考。**

**三条横向结论**：
1. **"低吸"标签可信度低**。四人里两人名实相符，两人不符。林疯狂的标签来自吧友评论（见其笔记 §4）；瑞鹤仙的"擅长低吸"只在 2012 年熊市里大致成立。
2. **四人的利润都集中在"买入当天就收涨停"的少数段**。乔帮主 4/24 段、rxybgb 4/41 段，剔掉这些段，其余段的均值都接近 0。所以，**低吸本质上是赌"日内急跌后当天反包涨停"**，赔率来自少数尾部，不是来自"便宜"。
3. **"日内越低越好"在两位真低吸者身上成立**。乔帮主买在日内低 30% 的 15 段胜率 80%、均值 +6.1%，其余 9 段胜率 44%、均值 -0.3%；rxybgb 低 30% 的 23 段胜率 65%、均值 +3.1%，其余段均值 -0.5%。

## 2 低吸的对象、位置、买点、卖点：异同与可编码定义

### 2.1 对比

| 维度 | 乔帮主（强势股盘中急跌） | rxybgb（人气股深跌） | 糊涂118（龙头首次见顶回撤） | 明王（熊市反弹低吸） | 瑞鹤仙（主升浪滚动） |
|---|---|---|---|---|---|
| **对象** | 最强板块最强个股，"龙回头"（二手）。数据：100% 是强势股，96% 在 MA10 上方 | ≥3 板人气股（行情好时 4-5 板），换手板，不碰连续一字板 | 绝对龙头，只做见顶后第一次回撤 | 最近的热点板块（曾经牛过、自己熟悉的），选其中昔日灵魂股前三甲 | 有业绩、题材逻辑的价值股主升浪 |
| **位置** | 上升途中。距 20 日高点约 -6%，不是"回踩 5 日线"（只有 29% 买在 MA5 下方） | 回调更深。距 20 日高点中位 -16%，二手称"跌 25% 左右" | 见顶后 3-7 日跌 20%-25%；趋势股 12 日线 | 下跌中继第一日；大盘 5 日线下为左侧 | 主升浪非加速段 |
| **日内买点** | 急跌中的日内低点，"越来越便宜时买"，绿盘为主 | 分时"跌不动了"，约一半在尾盘 | 分时低吸，"不用打先手" | 盘中反弹易收上影线，所以"尽量低吸" | 空头衰竭那一刻（右侧），重仓低吸、轻仓高抛 |
| **卖点** | 次日除非涨停必卖；低开即走 | 次日没预期就卖，首次冲高衰竭卖 | 反抽到前高附近 | 反弹获利走、不反弹平仓走；反弹常见 15-22% | 不贪，总资产增值约 25% 止盈；市场恶化卖 |
| **止损** | 破位离场，不低位补仓（但自述也补过） | 开始看错就不拿 | 约 3 点；大资金做 T 自救 | 轻仓被套不补，等下行 20-30% 空间拉开 | 单笔 ≤ 资产 2% |
| **适用环境** | 熊市、震荡市（"极强市改追涨"） | 看量；行情差就提高板数门槛 | 熊市、震荡市大反弹之后 | 熊市反弹 | 熊市起家；弱市只低吸不追 |

**异同小结**：
- **共同点**：对象都是"已被市场证明的强者"，没有一个人低吸弱势股。卖点都很快，T+1 为主。都把"不在低位补仓摊成本"当成纪律，只是执行不一。
- **最大分歧有两处**：
  - **回调深度**：乔帮主 -6% 是浅回调；rxybgb -16%、糊涂118 -20～25% 是深回调。
  - **对象的强度门槛**：乔帮主是近 10 日 1-2 板，rxybgb 是 ≥3 板。
- **另一个分歧是预判与否**：乔帮主"以后再预判就是傻逼"，瑞鹤仙"只需预测 1 天"，糊涂118"激进出击靠预判"。

### 2.2 可编码定义（伪代码，基于日线 + 涨停池；分时条件另标）

```yaml
low_suck:
  universe:                       # 对象（取交集）
    strong_A:                     # 乔帮主型：强势股盘中急跌
      - limit_up_count(T-10..T-1) >= 1 or close[T-1]/close[T-11]-1 >= 0.10
      - close[T-1] > MA10[T-1]
      - close[T-1]/max(high[T-20..T-1]) - 1 >= -0.12      # 浅回调
    popular_B:                    # rxybgb 型：人气股深跌
      - limit_up_count(T-10..T-1) >= 3                   # 行情好时 >= 4
      - yizi_limit_up_count(T-10..T-1) <= 1               # 不碰连续一字
      - close[T-1]/max(high[T-20..T-1]) - 1 in [-0.30, -0.08]
    leader_C:                     # 糊涂118 型：龙头首次见顶回撤
      - is_sector_leader(prior_wave)                      # 前一波板块涨幅第 1
      - pullback_index == 1                               # 见顶后第一次回撤
      - 3 <= days_since_top <= 7 and close/high_top - 1 in [-0.25, -0.20]
  entry:                          # 日内买点
    - price < close[T-1]                                  # 绿盘（乔帮主、rxybgb 80% 满足）
    - (price - low[T]) / (high[T] - low[T]) <= 0.30       # 日内低 30%（事后口径，实盘需改成"当前价 ≤ 日内最低 × 1.01"）
    - intraday: falling_into_price and no_new_low(N=15min)  # 需要分时："越来越便宜 + 跌不动"
    - optional_B: time >= "14:30"                         # rxybgb 尾盘
    - forbid: T-1 is limit_up and price >= open[T]        # 瑞鹤仙：涨停次日不追高
  exit:
    - if T+1 limit_up_sealed: hold to T+2
    - elif open[T+1] < entry_price: sell at open[T+1]     # 四人数据：低开时 ret ≈ 开盘溢价
    - else: sell on first intraday high reversal (below VWAP)
    - leader_C: take_profit at prior_high * 0.95
  stop:
    - no averaging down while position is underwater      # 乔帮主 / 明王
    - per_trade_loss <= 0.02 * equity                     # 瑞鹤仙（实盘中他也没做到）
```

**校验提示**：`entry` 里的"日内低 30%"是事后才知道的日线口径，实盘只能用分时近似。两位真低吸者的优势主要来自这一项，以及"当天反包涨停"的尾部。**用日线回测会高估**。

## 3 熊市（弱市）生存规则：可编码定义

### 3.1 五种"弱"的口径（谁提出的、怎么算）

| 口径 | 来源 | 定义（伪） | 动作 |
|---|---|---|---|
| **指数口径** | 明王 MW-01/02/05 | 左侧 = 上证收盘 < MA5；强 = 收 > MA5 > MA20；弱 = 收 < MA5 < MA20；熊 = MA60 下行 | 左侧时总仓 ≤ 20%；熊市"不强即轻仓" |
| **量能口径** | 明王 MW-03；rxybgb RXY-03（引 asking） | 衰减 = 两市成交额 MA5 < MA20 且 5 日内下降 | 不重仓（本文设 ≤ 40%）；rxybgb 的做法是提高选股门槛 |
| **赚钱效应口径** | 乔帮主 QBZ-07 | 差 = 昨日涨停股今日平均涨幅 < 0 连续 2 日，或 涨停家数 < 跌停家数 | 出局观望，资金做逆回购 |
| **情绪退潮口径** | 御剑飞鱼 YJ-02/05 | 退潮 = 连板 ≥3 的股中当日跌停占比 ≥ 30%，或出现天地板，且次日有一字跌停 | 退潮期不交易；龙头天地板后该方向 10 日不做 |
| **系统性暴跌口径** | 林疯狂 LFK-06；乔帮主 QBZ-08 | 上证连续 ≥2 日跌幅 > 3%，或跌停家数 ≥ 1000（千股跌停） | 林疯狂：空仓。乔帮主：千股跌停次日下午反而是恐慌买点（仅限高手、小仓） |

另有两条账户层熔断：
- 林疯狂 LFK-10：账户回撤超出承受范围就关账户休息。
- 御剑飞鱼 YJ-08：腰斩后休息。

### 3.2 合成的仓位状态机（本文归纳，参数均为先验，未回测）

```yaml
weak_market_overlay:              # 只压低总敞口上限，不替个股挑买点（负向规则）
  inputs: [SH_close, SH_MA5, SH_MA20, SH_MA60, turnover_MA5, turnover_MA20,
           limit_up_n, limit_down_n, yesterday_limit_up_avg_ret, streak3_limit_down_ratio, sky_to_floor_n]
  states:
    FLAT:                         # 空仓（仓位上限 0），任一条成立即进入
      - retreat: streak3_limit_down_ratio >= 0.30 or sky_to_floor_n >= 1      # 御剑飞鱼退潮，持续至 T+1
      - crash: SH_ret[T] < -0.03 and SH_ret[T-1] < -0.03                      # 林疯狂系统性暴跌
      - account_dd: equity / peak_equity_20d - 1 <= -0.20                     # 账户熔断（林疯狂 / 飞鱼），停 5 个交易日
    WEAK:                         # 仓位上限 20%
      - SH_close < SH_MA5 and SH_MA60 slope < 0                               # 明王：熊市左侧
      - or: yesterday_limit_up_avg_ret < 0 for 2 days and limit_up_n < limit_down_n   # 乔帮主：赚钱效应差
      allowed_entries: [low_suck only]        # 瑞鹤仙 RHX-10：只低吸、不追涨，不追熊市拉升
    PROBE:                        # 仓位上限 40%（下跌周期中的首次铺仓）
      - SH_close < SH_MA20 but bottom_signals_count in {1, 2}                 # 明王 MW-07
    NORMAL:                       # 上限 100%
      - bottom_signals_count == 3                                              # 见底三信号齐备
      - or: SH_close > SH_MA5 > SH_MA20
  bottom_signals:                 # 明王 MW-04：三者同时成立才解除弱市
    1: SH_close > SH_MA5
    2: turnover_MA5 / min(turnover_MA5[-20..0]) - 1 >= 0.15 and turnover[T] > turnover_MA20   # 由缩转放
    3: exists sector with 3-day consecutive outperformance and 5d_ret >= SH_5d_ret + 0.05     # 持续走强板块
  bear_regime_check:              # 明王 MW-06：反弹中级差递减 → 熊市反弹，不升级为 NORMAL
    - during rebound (SH from low >= +10%): sector_ret_rank3 / rank1 < 0.65 and rank10 / rank1 < 0.35
  sizing_within_state:            # 乔帮主 QBZ-09（出处待核）
    win_prob: {"<0.6": 0, "0.6-0.7": small, "0.7-0.8": mid, "0.8-0.9": large, ">=0.9": full}
  rebuy_after_loss:               # 明王 MW-08
    - no averaging down unless drawdown_from_entry >= 0.20 and bottom_signals_count >= 1
  same_day_after_stop:            # 瑞鹤仙 RHX-12
    - if realized_loss_today > 0.02 * equity: no new entries today
```

## 4 给用户的落地评估（只建议，不改 生产仓位）

1. **能借的是 §3 的"弱市敞口上限"，不是 §2 的低吸买点**。低吸买点依赖 A 股的涨停反包、T+1 和分时盘感，与用户的日线趋势（ST 趋势引擎）方向相反，周期也不对。§3 的状态机是组合层的负向规则，与用户"只做负向剔除、不做正向加权"的纪律同构。
2. **上线前必须过这几关**（沿用用户已有的尺子）：
   - (a) 以现池为基础，叠加 overlay 后比较 capture、PF、Calmar，并单独计算翻档带来的成本拖累。MA5 级别的开关很可能 whipsaw，所以要同时跑 MA20、MA60 两个对照臂。
   - (b) `selection_power`：多组 fit/test 切分，加反面臂和随机阀对照。波动率入场阀检验 的先例是入场阀在 ST 上落在随机第 0.0 分位，**ST 本身已经按个股趋势降仓，大盘阀很可能没有增量**。
   - (c) 分段看：只在 2008、2015H2、2018、2022 这类真熊段有效的阀，在其余年份的代价是否可以接受。
3. **最值得记住的反面证据**：乔帮主自述"N 个月 3-4 倍，随后腰斩"共 6 次（精华合集#page-11），交割单展示的 PF 却是 20.6。林疯狂没有事前空仓开关，两周回撤 80 多万。这两件事说明：**超短的高胜率展示单不等于可持续；真正的风险在没有被贴出来的那几个月**。这与用户"打脸是行情的属性、不是标的的属性"的纪律一致。
4. **标签纠错**：林疯狂应改归"强势股半路追涨"，御剑飞鱼应改归"情绪周期/龙头"。低吸流派的核心样本只有乔帮主和 rxybgb 两人；熊市生存模块的规则来源是明王（指数和量能）、御剑飞鱼（退潮）、乔帮主（赚钱效应、恐慌买点）、瑞鹤仙（降仓、只低吸、对冲）。

# distills —— 投资思路蒸馏存档

把外部的投资思路（书、博主、私募经理的长期输出）**蒸馏**成结构化笔记，再把其中能量化的规则拿到历史数据上**证伪**。
这里存放的是已经走完这个流程、**检验没有通过或已退出使用**的蒸馏，作为存档和反面教材。

> 本仓库内容**不要用于选股或交易**，也不构成任何投资建议。

## 方法

每个蒸馏都走同一套流程：

1. **精读原始材料**，按阶段 / 主题整理成笔记。
2. **规则按证据等级分档**：原文明确写出的、从作者案例归纳的、我做的推断，三者分开标注；原文引用带日期或小节号。
3. **记录作者改过的观点**。同一个人不同时期的话不能混在一起引用。
4. **能量化的就回测**：
   - **point-in-time**：只用当时已经能看到的数据（财报按报送日或法定截止日）。
   - **随机对照臂**：和同只数随机剔除 / 随机选择、随机平移的时间掩码比，过 90 分位才算有效。
   - **多段切分**：fit / test 两段或多组切分都要同号；只在一段行情里成立的不算。
   - **合适的对照组**：择时规则要赢「同平均仓位、不择时」，而不只是赢买入持有。
5. **主观打分、私有数据的指标标为「不可复现」**，不检验，也不当证据。
6. **写最终报告**：结论、体系概览、检验结果、仍可参考的部分、局限。

两份蒸馏得出的共同教训：

- **逆势规则（跌了加、涨了减）只在震荡市有效**，而是不是震荡市只能事后知道。
- **正向选择几乎都不成立**：强势股、高赔率、过去表现好的行业，换个切分就失效；能做的只有负向剔除。
- **只在一组切分上成立 = 那段行情的特性**，不能外推。
- **作者真正有价值的是风险框架和心法**：截断亏损、入口出口一致、仓位按波动而不是按看好程度定，而不是具体的买卖规则。

## 目录结构

```
<蒸馏>/
  README.md             # 最终报告：结论、体系、检验结果、仍可参考的部分、局限
  docs/01-蒸馏笔记.md    # 完整蒸馏笔记
  docs/02-*.md, 03-*.md # 检验与回测
  docs/notes/           # （可选）分时期原文证据摘录
  *.py, lib/            # （可选）计算器与回测脚本，自包含
  SKILL.md              # （可选）原 Claude Code skill 定义
  DEPRECATED            # （可选）废弃日期与原因
```

- 原书、付费语料等受版权保护的原始材料**不进本仓库**。
- 能公开复现的回测附带脚本；依赖私有引擎或数据的，只保留文字结论，并在报告里注明。
- 各蒸馏的复现方法写在各自报告里。

## 0. 一句话

> **只在已被市场证明的强势方向（主线）里，等「供需逆转/延续的关键点」右侧入场；买前先定好止损价，按止损距离反推仓位；
> 错了第一时间止损，对了让利润奔跑，加速或高潮时兑现；弱势市场少做或空仓。全程机械执行，靠控制回撤吃复利。**

作者口诀：**控制自己，顺应市场**（后记）；**买点来了买入，错了立即止损，对了等待止盈**（3.8）；**止损持盈**（1.2、3.10）。

## 1. 先认清这本书是什么

- **心法书，不是方法书。** 作者自己说「这本书主要讲解思维模式，而不是讲一个具体的交易体系」（4.1）。
  全书 5 章约 40 个小节，大约 80% 篇幅在讲认知偏差和交易心理，可执行的规则是零星嵌在案例和反问里的。
- **没有任何量化参数**：「关键点」「加速」「强势 / 弱势市场」「主线」「支撑位」都没有给出公式或阈值。
  所以这本书**蒸馏不出一个能直接回测的引擎**，只能蒸馏出一套**规则骨架 + 一组待量化、待证伪的假设**（见 §5）。
- 方法论底色是**利弗莫尔（关键点）+ 欧奈尔 / 米勒维尼（强势股、四阶段、只买第二阶段）+ 马克·道格拉斯（概率心理）**，
  再加上 A 股本土化的「主线轮动」和《道德经》式的周期观。原创概念只有一个：**「加速无买点」**（3.2，作者自称原创）。

| 9 | 大部分错误不是方法问题，而是**知行不一** | 1.3、4.7、5.x | 机械执行、信号以外不行动 |

## 3. 可执行规则（四件套 + 环境开关）

作者把交易体系定义为回答四个问题：买什么 / 何时买 / 买多少 / 何时卖（4.1，图 1-3 还列了「风险管理」）。

### 3.1 买什么

| 规则 | 等级 | 出处 |
|---|---|---|
| **先选板块，再选个股**；只在「鱼群聚集」的**主线**里下竿，不做主线外的机会 | [原文] | 3.6、3.14 |
| 主线识别三条：① 弱势环境中**率先创新高**；② 创新高且有持续性，短期内不断向上，一段时间不创新高就要复核趋势、看有没有新主线替代；③ 强势市场多板块都创新高时，找**最强的那个** | [原文] | 3.6 |
| **只做强势股**（已被走势证明的）；逆势下跌的股票默认「可能有我们不知道的利空」，不碰 | [原文] | 3.7、表 3-1 |
| 只买**第二阶段**（脱离底部的上行期），不买第一阶段的「看起来便宜」的低位股 | [原文] | 4.2（引米勒维尼四阶段） |
| 价格发现顺序：龙头先涨 → 打开空间 → 后排补涨 → 二三线都涨一遍、逻辑弱的满天飞 = **板块 / 市场见顶前兆** | [原文] | 4.5 |
| 选股的「变化」逻辑：买**「好→更好」（成长）**或**「差到不能再差→变好」（困境反转 / 周期）**；回避「好到不能再好」（周期顶）和「差且没有变好迹象」 | [原文] | 2.12 |
| 大方向顺应时代 / 政策 / 产业周期（例：当年城镇化下的地产、2015 前后的新能源车；反例：当下的地产） | [原文] | 3.13 |

> [整理] 2.12 的基本面「变化」框架和 4.5 的「走势是最好的选股工具」在书里是**并存**的：
> 基本面用来**解释**与**排除**，最终买不买以走势为准（「再好的公司，股价不涨就是不好」，2.12 末段引欧奈尔）。

### 3.2 何时买（入场）

| 规则 | 等级 | 出处 |
|---|---|---|
| 只在**关键点**下单 = 「供需格局逆转或延续」的位置；关键点是心理点位，来自前高 / 前低的**锚定效应**（支撑压力的自我实现） | [原文] | 2.6、3.15 |
| **右侧**：等趋势确立或反转完成再买，不抄底、不左侧 | [原文] | 3.5 |
| 底部反转型买点：触底反弹 → **回踩不破前低** + 量价确认 → 买；止损设在前低（例：5 元低点、回踩 5.5 元买，止损 5 或 4.9） | [原文] | 3.5 |
| 趋势中继型买点：上升趋势中的**缩量回踩**（美年健康 2021-03-25、韦尔股份 2022-01-13 都叫「趋势回踩买点」） | [案例] | 1.2、2.9 |
| 突破型买点：**放量向上突破 → 缩量回试（两次）→ 买**，止损设在**第一次回试的低点**（中国软件 2022-09-16 突破、09-30 买，图 5-1） | [案例] | 5.5 |
| **加速无买点**：明显加速上涨后不买（加速透支需求、获利盘增加、供需天平倾斜） | [原文] | 3.2、3.12 |
| 不追高：拉升途中已错过关键点，就等下一班「公交车」，不去追 | [原文] | 3.15 |
| 信号出现**第一时间**执行；犹豫错过后再追 = 追涨的根源 | [原文] | 3.11 |
| 宁可错过：没咬钩（没信号）的鱼与你无关；错过不叫「踏空」 | [原文] | 3.14、3.16 |

### 3.3 买多少（仓位）

| 规则 | 等级 | 出处 |
|---|---|---|
| **以损定仓**：买前定止损价，单笔最大亏损 = 总资金 **1%**，`股数 = 1% × 总资金 ÷ (买价 − 止损价)`。例：100 万、10 元买、9.5 止损 → 2 万股 = 20% 仓位 | [原文] | 4.6 |
| 事前「适度分散，不把鸡蛋放在一个篮子里」；事中避免重仓押注 | [原文] | 4.6 |
| 盈亏比优先于胜率：「5 笔里 1 笔 +20%、4 笔各 −5% 也不亏」 | [原文] | 3.8 |
| 顺境时尤其防重仓（「很多大亏源于顺境时心态放松但仓位最重」） | [原文] | 3.12（引《道德经》「持而盈之」） |
| 分仓用于降低心理压力 | [原文] | 1.2「抗压能力差」 |

> [整理] 1% × 止损距离 5% 直接推出单票 20% 上限 → 书中隐含**同时持仓约 5 只**的量级，作者没明说。

### 3.4 何时卖（出场）

| 规则 | 等级 | 出处 |
|---|---|---|
| **止损价买前定死**，盘中只执行不重新决策；「市场会用一个价格证明你错了」 | [原文] | 4.6、1.2 |
| 止损触发条件（案例）：**放量大跌、跌破支撑位**（美年健康 −3%）、跌破回踩低点（通富微电 −6%）；**未触发前不许提前跑**（中国软件反例：盘中 −5% 没破止损就跑，随后半月 +70%） | [案例] | 1.2、5.5 |
| 「试错」立场：在仓位赚钱之前一律假设自己是错的；**市场不能证明你对，就减仓或清仓** | [原文] | 3.8 |
| 趋势单持有条件：「持续趋势上升、没有明显加速迹象，就可以一直持有」 | [原文] | 4.2 |
| **加速 / 高潮时兑现**：「敢于在股价高潮（加速）时逆势卖出」「已经明显加速 → 减仓或清仓」；不吃鱼尾 | [原文] | 3.9、3.10 |
| 趋势末端**放量长阴** = 卖出信号，第一时间走（「高位不减，低位两难」） | [原文] | 3.11 |
| 同一根放量阴 / 阳线，看位置：高位（尤其加速后）是风险，低位或趋势早期是正常波动 / 突破 | [原文] | 3.13 |
| **止盈松紧随市场环境**：强势市场让利润奔跑，弱势市场收紧止盈 | [原文] | 3.2、3.10 |
| **入口出口一致**：趋势进就趋势出，跌破趋势不许改讲估值 / 基本面 | [原文] | 4.2、4.7 |
| 不预设长线 / 短线：信号不出就一直拿（长线），次日破位就走（短线），让市场决定持有期 | [原文] | 3.16 |
| 不为「换更强的」卖掉没出信号的持仓（鱼漂思维反对「为了卖而卖」） | [原文] | 3.14、4.1 |

### 3.5 市场环境开关

| 规则 | 等级 | 出处 |
|---|---|---|
| **弱势市场不用「弱势思维」去抄底，而是减少交易或空仓**；强势市场用强势思维 | [原文] | 3.7 |
| **频繁止损 = 信号**：要么大盘弱、不适合交易，要么买点不对 | [原文] | 3.9 |
| 「主线重置期」（老主线鱼尾、新主线未出）= 成本区：轮动快、大涨大跌、最容易亏，接受摩擦成本、别频繁交易 | [原文] | 3.6 |
| **成交额是市场温度计**：没有放量就只有结构性 / 轮动行情（作者 2022 年口径：低迷约 6000 亿，1~1.2 万亿才走强，2 万亿+ 才有强趋势） | [原文] | 3.6 |
| 强→弱转折时最易大回撤（被强势迷眼）；弱→强第一波总在犹豫中上涨（被熊市洗脑）——都靠「跟随最新事实」解决 | [原文] | 3.7 |
| 「在市场供应衰竭时布局，在市场需求衰竭时退出」 | [原文] | 3.12 |

## 4. 作者明确反对的做法（反向清单）

| 反对 | 理由 | 出处 |
|---|---|---|
| 左侧抄底、「越跌越便宜」 | 最低点无法自证；下跌常有你不知道的原因；时间成本巨大 | 3.5、3.7 |
| 不止损死扛、补仓摊低 | 沉没成本；所有大亏都从小亏开始 | 2.9、3.9 |
| 趋势单破位后改讲估值继续持有 | 入口出口不一致 | 4.2、4.7 |
| 多指标、多周期叠加（PE + 趋势、日线 + 周线） | 信号互相矛盾，「戴两块手表」 | 1.2 #3、3.12 |
| 反复修改参数拟合行情（10 日线 → 20 日线 → 30 日线） | 主观拟合，等于没规则 | 1.1、4.7 |
| 多策略并行 / 风格漂移 | 条件互斥，最终一个也执行不了；「一条路走到黑」 | 4.2 |
| 预设目标价 | 预测思维，会导致等目标价而死扛 | 3.1、3.4 |
| 追加速、追「妖股」、追盘中脉冲 | 加速无买点；没原则的跟随 = 追涨杀跌 | 3.2、3.13 |
| 盯账户盈亏 | 瓦伦达效应，干扰按止损 / 止盈信号执行 | 2.7 |
| 拿「好公司」当「好投资」 | 好已经被定价；周期顶时报表最好（英科医疗 2021Q1 增速 2881%，股价已先见顶 −85%） | 2.12 |

## 5. 量化缺口与可证伪假设（要落地必须先补）

书里所有关键名词都没有定义。若要变成可回测规则，最小的量化化方案（**[整理]，非作者原意，需回测验证**）：

| 书中概念 | 可尝试的定义 | 待验证的问题 |
|---|---|---|
| 主线 | 行业指数 N 日新高 + 横截面相对强度排名第 1~k | 主线轮动能否在 A 股行业层面产生超额？换手成本吃掉多少？ |
| 强势市场 / 弱势市场 | 全市场成交额相对分位、指数位于 EMA 之上、新高家数占比 | 「弱势空仓」开关是否改善 Calmar，还是只是少赚？ |
| 关键点（回踩 / 回试买点） | 突破后 k 日内缩量回调且不破突破前低点 | 与「突破当天买」相比的胜率 / 盈亏比 |
| 加速 | N 日涨幅的 ATR z-score、或偏离 EMA20 的幅度分位 | 「加速无买点」：加速后入场的前瞻收益是否显著更差？ |
| 高潮止盈 | 加速 + 放量 | 见 §6.2，已有反向证据 |
| 补涨扩散见顶 | 板块内成分股上涨广度从龙头扩散到尾部 | 广度见顶是否领先板块指数见顶？ |
| 以损定仓 1% | 止损价 = 回试低点 / 前低 | 与固定档位金额相比，风险是否更均匀？ |

## 6. 与常见趋势跟踪做法的对照

### 6.1 一致的部分

- **右侧趋势跟随、机械执行、不预设持有期**：SuperTrend、均线类趋势引擎本身就是书中「跟随思维 + 右侧思维」的实现，也没有目标价。
- **止损后不在止损线两侧反复**：与书中「不和市场讲道理」同向。
- **入口出口一致**：趋势仓不讲估值、买入持有仓不用趋势尺，同一标的不同时挂两套信号，与 4.2 / 4.7 一致。
- **不多指标叠加、不反复调参**：与反过拟合的做法一致。
- **周期顶识别**：2.12「好到不能再好 = 周期顶」「周期股买在高 PE 卖在低 PE（林奇）」，与「强周期股看 PBR 不看 PE、警惕峰值利润价值陷阱」是同一逻辑。

### 6.2 有冲突、需要单独验证的部分

1. **「加速 / 高潮时止盈」**：在一个 SuperTrend 类趋势引擎上的独立测试（两个样本，不在本仓库）里，加止盈后 Calmar **单调变差**，引擎自带的移动止损已经承担了退出。书里的「加速减仓」是作者的主观波段手法，不应直接叠加到趋势引擎上；要验证只能当成独立的新引擎回测。
2. **「以损定仓（1% 风险）」vs 按档位定金额**：两者不是对错之分，是不同的风险归一方式。
3. **「走势是最好的选股工具」vs 估值扩张纪律**：书把强势当证据；「股价涨幅远超 EPS 涨幅 = 估值扩张 / 情绪主导」的纪律把它当需要打折的线索。可以分层共存：书的规则管「何时进出」，基本面纪律管「能不能买、给多大权重」。
4. **「主线 / 强势股正向选择」vs「只做负向剔除」**：书里的强势是当下横截面动量，不是历史适配性，两者不完全是一回事。但实测（§8）里这类正向选择在个股和 ETF 层都不成立。
5. **「弱势市场空仓」**：逐标的的趋势引擎本身就会在弱势里空仓，再加全市场环境开关是重复信息（§8 H2）。

### 6.3 书里有、常见趋势系统里没有的

- 板块 / 主线轮动层（先选板块再选股）；补涨扩散的见顶预警；成交额温度计；交易日志模板（表 2-1：买入时间 / 个股 / 外部因素 / 内部因素 / 成功失败 / 原因分析 / 改进措施）。

## 7. 心法清单（压缩版）

书的主体。按作者四件套归类（4.1 原文映射）：

- **买什么**：空杯（不预设立场）、跟随（依据事实不依据假设）、主线、强势思维
- **何时买**：右侧、周期（狂热时冷静、恐慌时客观）、击球区（只打最好的格子，放弃平庸机会）
- **买多少**：试错（善输才能赢）、复利（控回撤 > 抓大涨）
- **何时卖**：鱼漂（只看自己的信号）、知止（会卖的是师傅）、第一时间（犹豫是兵家大忌）
- **贯穿始终**：辩证思维（止损 / 让利润奔跑 / 加速无买点都「有对有错」，看环境）、概率思维（51 红 49 绿的箱子）
- **要克服的 11 种偏差**：思维定式、线性思维、证实性偏见、后视偏差、锚定、有限注意力、沉没成本、随机收益、近因效应、好公司≠好投资、自我归因
- **心理层**：交易者三层次（情绪化 → 机械化 → 直觉化）；顺应外部变量、控制内部变量；「无我」——做自己想法的旁观者，不和「另一个我」争辩（对付情绪劫持）；事上练（交易 + 运动 + 阅读）
- **正确 / 错误交易的定义**：按体系做的是正确交易（亏了也对），不按体系做的是错误交易（赚了也错）；「踏空 / 卖飞 / 割肉」这些词不该存在

## 8. 实测结论（2026-10-02，详见 [docs/02](02-假设检验.md)）

# 《交易至"简"》· 投资思路蒸馏 · 最终报告

> 书里能量化的「选什么 / 什么时候进」经验都做了对照实验，没有一条在 A股长样本上有可外推的选择力。
> 不构成任何投资建议。原书不在本仓库（版权）。

## 一、结论

1. **这是一本心法书，不是方法书。** 作者自己说「这本书主要讲解思维模式，而不是讲一个具体的交易体系」。约 80% 篇幅讲认知偏差和交易心理，所有关键概念（关键点、加速、主线、强 / 弱势市场）都没有给出公式或阈值。
2. **「加速无买点」不是可执行规则。** 等回踩再买，在牛市里大幅吃亏（行业 2011-2016 段 −4.1%），在震荡市里占优（2022-2026 段 +1.0%），符号随行情翻转。书里自己也说它「有对有错」。
3. **「弱势市场空仓」没有增量。** 趋势引擎本身就会在弱势里空仓，再加全市场广度开关是重复信息。
4. **「只做强势股 / 走势是最好的选股工具」比随机还差。** 个股层按涨幅或离新高每月选前 100，落在随机臂第 0~12 百分位；ETF 层同样更差。
5. **「主线 = 率先创新高」半成立。** 行业层选离 250 日新高最近的，是所有规则里最好的（9 组切分 4 组过随机臂），但主要是熊市里少亏，牛市里没有选择力。
6. **书的价值在心法**：机械执行、截断亏损、入口出口一致、按事实而不是按预测行动。这些趋势跟踪引擎本身已经在做。

## 三、书的体系

**一句话**：只在已被市场证明的强势方向（主线）里，等「供需逆转 / 延续的关键点」右侧入场；买前先定好止损价，按止损距离反推仓位；错了第一时间止损，对了让利润奔跑，加速或高潮时兑现；弱势市场少做或空仓。

作者口诀：**控制自己，顺应市场**；**买点来了买入，错了立即止损，对了等待止盈**。

方法论底色：利弗莫尔（关键点）+ 欧奈尔 / 米勒维尼（强势股、只买第二阶段）+ 马克·道格拉斯（概率心理），再加 A 股本土的「主线轮动」。唯一的原创概念是「加速无买点」。

| 问题 | 书中规则 |
|---|---|
| 买什么 | 先选板块再选个股；只做主线（弱势中率先创新高、且有持续性）；只做强势股、只买第二阶段；基本面看「好→更好」或「差到不能再差→变好」 |
| 何时买 | 只在关键点下单（前高 / 前低的支撑压力）；右侧，不抄底；回踩不破前低、缩量回踩、突破后缩量回试；**加速无买点**；不追高 |
| 买多少 | **以损定仓**：单笔最大亏损 = 总资金 1%，股数 = 1% × 总资金 ÷ (买价 − 止损价)；盈亏比优先于胜率；顺境时尤其防重仓 |
| 何时卖 | 止损价买前定死、盘中只执行；市场不能证明你对就减仓；加速 / 高潮时兑现；趋势末端放量长阴就走；入口出口一致 |
| 市场环境 | 弱势市场减少交易或空仓；频繁止损本身就是信号；成交额是市场温度计 |

作者明确反对：左侧抄底、补仓摊低、破位后改讲估值、多指标多周期叠加、反复调参、多策略并行、预设目标价、追加速、盯账户盈亏、把好公司当好投资。

## 四、检验结果（[docs/02](docs/02-假设检验.md)）

样本：申万二级 124 个行业（1999 起 26 年，主样本）、A股 1329 只、A股 ETF 51 只。成本 A股往返 11bps。
趋势引擎是一个 SuperTrend + EMA60 类的私有引擎，**不在本仓库，这里只保留文字结论，无法直接复现。**

| 书中经验 | 量化定义 | 结果 |
|---|---|---|
| 加速无买点（3.2） | A=(收盘−EMA20)/ATR14 >2 时等 A≤1 再买 | ❌ 行业四段 −1.6% / −4.1% / +0.5% / +1.0%，随行情翻转 |
| 弱势市场空仓（3.7） | 行业广度 <0.3/0.4/0.5 时不开新仓 | ❌ 无一致方向，变化大多在噪声内 |
| 强势股 / 价格发现（4.5） | 个股每月按涨幅 / 离新高选前 100 | ❌ 随机臂第 0~12 百分位，比随机还差 |
| 主线 = 率先创新高（3.6） | 行业离 250 日新高最近选前 1/3 | ⚠️ 9 组切分 4 组过随机臂，其中 3 组基准为负；基准为正的只 1/5 |

顺带发现：「按过去 3 年趋势表现（capture / Calmar / PF）选行业」这条常见做法，单组切分上看起来有效，换成 26 年 9 组切分后过随机臂只有 0/6、1/9、2/9。**单组切分成立 = 那段行情的特性。**

## 五、仍可参考的部分

这些是心法，不是可回测的规则：

- **正确交易的定义**：按体系做的是正确交易（亏了也对），不按体系做的是错误交易（赚了也错）。
- **试错立场**：在仓位赚钱之前，一律假设自己是错的；止损价买前定死，盘中只执行。
- **入口出口一致**：趋势进就趋势出，跌破趋势不许改讲估值。
- **复利靠控回撤**：翻倍后回撤 40% = 1.2 倍，不如两年各赚 10% = 1.21 倍。
- **好公司 ≠ 好投资**：周期顶时报表最好（英科医疗 2021Q1 增速 2881%，股价已先见顶，之后跌 85%）。
- **11 种认知偏差**：思维定式、线性思维、证实性偏见、后视偏差、锚定、有限注意力、沉没成本、随机收益、近因效应、好公司≠好投资、自我归因。
- **交易日志模板**（表 2-1）：买入时间 / 个股 / 外部因素 / 内部因素 / 成功失败 / 原因分析 / 改进措施。

**要小心的**：「加速 / 高潮时止盈」在一个 SuperTrend 类趋势引擎上的独立测试（不在本仓库）里让 Calmar 单调变差，不应直接叠加到趋势引擎上。

## 六、局限

- 书中概念没有量化定义，检验用的是**我给的最小定义**，不是作者原意；换一种定义，结论可能不同。
- **幸存者偏差**：个股样本是当前大市值股。
- **样本年份**：个股和 ETF 只有约 6 年；行业指数有 26 年，但行业不是个股。
- **未测**：「补涨扩散 = 板块见顶前兆」需要历史成分股，akshare 只有当前成分。
- 作者没有公开可追溯的交割记录，无法用实盘反推校准。

# 思想钢印 · 投资逻辑蒸馏

> 可量化的选股规则与交易规则都经 PIT 回测证伪：跑不赢随机 / 同仓位不择时（docs/02、docs/03）。

这是一个投资思路蒸馏，只作研究，不作交易依据。

使用前**先读** `docs/01-蒸馏笔记.md`，里面有四阶段演化、三原则、量化赔率、机械规则、市场观、改过的观点、方向判断记录，以及与常见交易纪律的对照。
要查具体时期的原文证据，读 `docs/notes/`：B 操作计划、C 个股跟踪、D1–D4 每日感悟、W 周回顾和精华。原始语料是付费内容，不进 git。

## 计算器

```bash
# 长线波段：20/60 日乖离率落在哪个区（缺省熊市口径 −15%/+10%，--bull 为 −10%/+15%）
python3 sixiang-gangyin/bands.py wave --market CN --codes 510300,512480
# ETF 均线网格：成长策略（60 日线 = 半仓，每档 5%，上下各 5 档）
python3 sixiang-gangyin/bands.py grid --market CN --codes 159863 --max-pos 30
# 超跌反弹策略（年线 = 0 仓，年线下 7 档，上穿年线清仓）
python3 sixiang-gangyin/bands.py grid --market CN --codes 512480 --mode rebound --n-dn 7 --max-pos 21
# 极限赔率 + 预期收益率（上下极限价需要自己按他的口径估）
python3 sixiang-gangyin/bands.py odds --price 12 --up 18 --down 8 --win 0.5
```

行情走 `lib/prices.py`（市场：CN / HK / US）。`--json` 输出原始结果。

## 怎么回答

1. **问框架**：按笔记作答，引用原文要带日期。**必须说明那条观点处在哪个阶段、后来有没有被他改掉**（见笔记 §6）。不要把 2020 年的「不止损、不择时」和 2026 年的「A股需要择时」混成一个人说的话。
2. **按他的框架体检某只标的**（三原则版本）：
   - 确定性：商业模式、竞争格局、行业空间，评高 / 中 / 低，并给出仓位系数 1 / 0.6 / 0.3。
   - 景气度：机构盈利预测 30 天 vs 180 天的上调幅度、最近一期财报是否超预期。
   - 赔率：用 `odds` 算 2:1 和 3:1 的价位；必要时补充估值中枢（一致预期 EPS × PE 中枢 × 吻合度 ÷ 1.15~1.2）。
   - 最后给出「胜率标的买在赔率 / 赔率标的买在胜率拐点」的归类。基本面数字要查一手财报，**不要编数字**。
3. **问当前看法**：只能引用笔记 §7 截至 2026-10-02 的立场，并标明「他的方向判断命中率一般，价值在风险框架」。不要当成买卖建议。
4. **周期股 / 卖铲人**：他的观点与常见的周期股纪律基本一致（看 PB、把周期当成长是最大的错、看供给弹性），见笔记 §8。
5. **想用网格或波段交易**：先说明回测结论（`docs/02`：跑不赢同仓位不择时）；这两种方法都是逆势的（低位加、高位减），只在震荡市有效，而是不是震荡市只能事后知道。

## 哪些规则经得起检验

他的可量化选股规则做过 PIT 检验，见 `docs/03-选股规则检验.md`：
结论是**没有值得用的选股规则**：两条勉强通过的（高 ROE 均值回归、营收增速见顶）效应太弱且不稳，已不作工具；
**极限赔率选股显著差于随机**；估值扩张、PBR 分位随行情翻转，不能作剔除或卖出依据。
回答「他的规则有没有用」时以 docs/03 为准。

## 局限

- 震荡&趋势指数和散户净持仓指数都是作者的主观或私有指标，**无法复现**，计算器里没有。
- 乖离率波段、均线网格、超跌网格**已回测，全部无效**（跑不赢同仓位不择时，见 `docs/02-交易规则回测.md`）。`bands.py` 只作「看他会怎么操作」的参考，不作交易依据。
- 语料只覆盖星主本人的帖子，不含评论区；2021 春节、2022 熊市、2024-09-24 等关键时点部分缺少当期帖子，只能靠他事后的回述。

# 思想钢印 · 投资思路蒸馏 · 最终报告

> **状态：已废弃（2026-10-04）。** 能量化的选股规则和交易规则都做了 point-in-time 回测，没有一条值得使用。
> 本目录只作历史存档，**不要用于选股或交易**，也不构成任何投资建议。

## 一、结论

1. **选股规则：没有可用的。** 13 条可量化规则（11 条出自他，2 条是常见的估值纪律）只有 2 条勉强通过（高 ROE 均值回归、营收增速见顶），而且效应很弱（组合年化 +0.5~1pp），换市场、换子样本就不稳。
2. **极限赔率选股显著差于随机。** 按 2:1 / 3:1 赔率选出的多是「便宜且一直便宜」的标的。赔率最多用来给已经决定买的标的定价位。
3. **机械交易规则（长线波段、均线网格、超跌反弹网格）跑不赢「同平均仓位、不择时」。** 只在下跌震荡段有效（如 2021 ~ 2023H1）；申万二级 124 个行业 26 年的长样本里全部输。
4. **根本原因在方向，不在参数。** 这些规则都是逆势的：跌了加、涨了减。单边下跌时越跌越加，单边上涨时提前卖光。规则有没有用取决于未来是不是震荡市，这只能事后知道。
5. **有参考价值的是他的风险框架**，不是规则：看利弊不看对错、仓位按波动而不是按看好程度定、周期股看 PB、别把周期当成长、同属性标的起不到分散作用。

## 三、他的体系（四个阶段）

| 阶段 | 核心框架 | 标志性表述 |
|---|---|---|
| 2020–21 白马价投 | 确定性 × 景气度 × 赔率三原则；估值中枢；约 100 只分档股池；常年九成仓，不止损 | 「确定性决定最高仓位，景气度决定现在的仓位，赔率决定买点」 |
| 2022–23 量化赔率 | 预期收益率公式；极限赔率 2:1 先买一半、3:1 加满；凯利仓位；ETF 均线网格；长线波段（乖离率） | 「长线靠赔率，中短线靠胜率」 |
| 2024–25H1 宏观对冲 | 红利主仓 + 期指对冲；杠铃（红利 + 小盘科技）；自建震荡&趋势指数、散户净持仓、七因子；困境股池 | 「从常见的个股多头策略，变成宏观对冲策略」 |
| 2025H2–26 资金面 + AI | 业绩 / 估值归因；八因子；「炒瓶颈」；永久组合与炒股分开 | 「A股需要择时，是因为波动相对收益更大」 |

六年里没变的只有三条：看利弊不看对错（赔率优先）；体系高于看法；A 股的核心问题是波动。
估值方法、红利、科技股、择时这些立场他**都改过不止一次**，引用时必须带日期（[笔记 §6](docs/01-蒸馏笔记.md)）。

## 四、检验结果

### 选股规则（[docs/03](docs/03-选股规则检验.md)）

方法：每个月末按当时已披露的财报给标的打标，剔掉被标的后，比较剩余等权组合未来 12 个月的 Calmar，和 300 次同只数随机剔除比较。fit、test 两段都要 ≥90 分位才算通过。
样本：美股 206 只（2016-01 ~ 2025-09，SEC XBRL），A股 696 只（2020-03 ~ 2025-09）。

| 规则 | 结果 |
|---|---|
| ROE >30% 且非薄权益 → 剔除 | 美股两段过、A股 test 只到 70 分位；与学术「质量因子」方向相反 → 勉强通过，不用 |
| 营收增速峰值 ≥100% 回落到 ≤30% → 剔除 | A股两段过、美股样本太少 → 勉强通过，不用 |
| 净利版增速见顶 | 不过（基数效应太大） |
| 极限赔率 ≥2 / ≥3 正向选择 | 两段都 0 分位，**显著差于随机** |
| 估值扩张、PBR 历史 90 分位 | 随行情翻转（2016–20 有效，2021–25 等于剔掉主升浪） |
| 3 年净利下降、ROE 长期 <10%、净现比、应计、盈余波动、「股价新高估值不新高」 | 全部不过 |

### 交易规则（[docs/02](docs/02-交易规则回测.md)）

对照组是「恒定同仓位」：每只标的按该规则的平均仓位一直持有，不择时。择时有没有用，就看能不能赢它。

| 规则 | 16 只宽基与行业 ETF，2021–2026 | 申万二级 124 个行业，2001–2026 |
|---|---|---|
| 长线波段（熊市口径） | 全期赢，但只赢在 2021 ~ 2023H1，之后输 | 输（Calmar −0.01 vs 0.08） |
| 长线波段（牛市口径） | 输 | 输 |
| 均线网格 | 全期赢，但只赢在 2021 ~ 2023H1 | 输（0.02 vs 0.08） |
| 均线网格 + 止损 | 输 | 输 |
| 超跌反弹网格 | 全期赢，但只赢在 2021 ~ 2023H1 | 输（0.01 vs 0.07） |

他自己说网格「唯一失败的情形是均线由多转空」，回测里正是这种行情让它们输掉；加了止损的版本也没赢，因为止损卖在了底部。

## 五、仍可参考的部分

这些是框架和态度，不是可回测的规则：

- **赔率思维**：「看对了你能赚多少，看错了你要亏多少？」先算下行，再谈上行。
- **仓位**：「回撤风险决定仓位，而不是看好程度」；「急跌中加仓的仓位是情绪的钱」，要及时减回原仓位。
- **卖出**：「贵了、逻辑变了、有更好的」，不包括套牢；「A 逻辑进，A 逻辑出」。
- **周期股**：看 PB 不看 PE；「上行期估值没有顶，下行期估值没有底」；「真正值得警惕的是把周期当成长」。
- **供给弹性**：沿产业链找供给最难扩张的环节，那里才有定价权。
- **分散**：属性相似的标的「起不到分散仓位的作用」。

他的方向判断（大盘点位、风格切换）多以「区间 + 条件」的形式给出，事后容易自洽、难以证伪，命中率一般（[笔记 §7](docs/01-蒸馏笔记.md)）。不要拿来当买卖依据。

## 六、局限

- **震荡&趋势指数、散户净持仓指数**是他的主观打分或私有数据，无法复现，没有检验。
- **幸存者偏差**：选股样本都是现在还在的大中盘股。
- **样本年份**：美股 10 年里有两轮科技主升浪；A股选股样本只有 5.5 年。
- **语料范围**：只有星主本人的帖子，不含评论区；2021 春节、2022 熊市、2024-09-24 等关键时点部分缺少当期帖子，只能靠他事后的回述。

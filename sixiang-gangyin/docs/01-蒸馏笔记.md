## 0. 一句话画像

**一个从「白马价值投资」一路演化到「宏观对冲 + 风格配置 + 自建情绪指标择时」的 A 股私募经理。** 六年没变的只有三条：

1. **看利弊不看对错（赔率优先）。**「小孩子才看对错，大人只看利弊」（2024-12-02）；「看对了你能赚多少，看错了你要亏多少？」（2024-11-09）
2. **体系高于看法，有预测、有应对。**「保留自己的看法，但操作上还是要尊敬体系，因为看法的错误都是一次性的」（2024-03-12）
3. **A 股的核心问题是波动，散户要求稳、求慢、去人少的地方。**「A股的问题在于，波动性相对于收益不匹配」（2024-12-28）；「比'快'，你永远不是机构的对手」（2025-05-17）

估值方法、红利操作、科技股态度、择时立场都**改过不止一次**，见 §6。引用他的结论时必须带上日期。

## 2. 核心框架一：三原则（2020–21，体系地基，后续阶段都没推翻）

### 2.1 确定性：长线胜率，决定**仓位上限**

- **三维度评级**：商业模式、竞争格局、行业空间，管理层可以作为补充。
  - **高**：三维全优，且至少有一项特别亮眼。
  - **中**：三维中有一项明显偏弱。
  - **低**：有致命缺陷，或者自己研究有死角。
  - 三维都平庸，或看不懂：放弃。
- 竞争格局最重要，检验方法是：「对手敢不敢降价竞争？」「要么比别人卖得贵，要么比别人卖得快」。
- 定级前先问自己：「这个公司跌30%，我还能拿得住吗？」（2020-10-04）
- **仓位系数**：高 / 中 / 低 = 1 / 0.6 / 0.3（2020-10-15），学员转述为单只上限 10% / 6% / 3%。2023 年改用凯利公式，单只上限「两成到4成」。
- 「高确定性的公司不是优点更多，而是弱点更少」。确定性是**比较出来的**：抬高一只的评级，就要压低同行业另一只（2021-01-21）。
- 后来的修正（2021-10）：确定性就是公司能否维持「中端（3–15 年）和远端」的盈利能力。
  - 对远端的影响：商业模式 > 竞争格局 > 行业空间。
  - 行业确定性排序：必选消费 > 可选消费 > 一般制造 > TMT > 上游资源。
  - 价格变动越快、固定资产占比越高、越依赖高端人才、下游客户越少，确定性越低。

### 2.2 景气度：中短期胜率，决定**当前仓位**

- 「景气度指标……可以说是价值投资中的趋势指标」。「长线布局看确定性，中线加仓更重要的是看景气度」。
- 景气度的来源：
  - 客观：涨价或需求、产能或爆款、预期新品 / 新客户。
  - 主观：风格、线性外推、图形。
  - 「景气度管的是三个月以内的涨跌」。
- 怎么跟踪：
  - 长期盯同一家卖方团队，看推荐顺序和用词的变化。
  - 看机构 30 天 vs 180 天的盈利预测上调幅度，≥5% 才算显著，消费股 ≥3%。
  - 看财报是否超预期，以及之后几天的走势（「净利润断层」）。
- **2021-06 自我否定**：景气度对散户「变化比较快」，于是改为「仓位水平只考虑确定性，将景气度作为验证确定性的指标」。2021-11 起明说「一般的散户很难用景气度投资」。

### 2.3 赔率（估值中枢）：决定**买点**

- **估值中枢公式**（2021-01-07 / 03-10）：

  `中枢价 = 一致预期 EPS × PE中枢 × 业绩吻合度 ÷ (1 + 预期收益率)`

  - PE 中枢：过去一年 TTM PE 的中位数。经验值是「两个极值的平均数再低一点」，例如极值 20 / 40 时取 25–28。
  - 业绩吻合度：机构预测的历史兑现率。年初给 85–90%，季报符合后上调到 95–100%，「不能超过100%」。80% 的公司实际低于机构一年内的预测。
  - 预期收益率：他自己用年化 20%，即「到年底除以 1.2」。高确定性公司要用低贴现率（10%），否则「几乎没有机会买到」。
- **七个价位阵型**：情绪高点 / 情绪低点（一年 TTM PE 极值）、中枢、上限 / 下限。
  - 「只在极限值附近交易」。
  - 「通常下限尽量要买，上限不一定要卖」（这种不对称是因为「我们主要还是赚业绩增长的钱」）。
  - 卖出要「太离谱」，通常超过上限 10% 以上。
- **建仓与加仓**：
  - 第一笔在中枢附近；板块逻辑很顺时也「不能超过中枢以上5%」，高确定性可以放宽到 10%。
  - 「估值中枢代表实现预期收益率的概率为50%」。
  - 跌到情绪低点：优秀公司加满，不错的公司重仓。
  - 「建仓条件：逻辑非常好且价格合理；加仓条件：逻辑成立且价格非常便宜」。
- **PE 中枢只上调、不下调**。成长股要下调中枢说明逻辑变了，应该「回避，至少停止补仓」。周期股、困境反转、业绩异常的公司不受此限。「要么业绩基数不变，调PE，要么PE不变，调业绩基数，最好不要同时调」。
- 适用范围：「只适合用对机构有定价权的股票」。周期股要回到上一轮周期去找情绪极值；困境反转用远期 EPS 加贴现。
- **2021-06 起他自己弱化估值**：「历史估值法已经不讲了」（2024-06-01），只保留一句：「如果你想持有一家公司三年以上，那就不要看任何25倍以上的公司」。

### 2.4 三原则的组合规则

- 建仓门槛：「确定性、景气度和赔率，只要有两样，就可以先买一笔」（2021-05-11）。「标配只需要景气度，超配需要景气度和赔率双重因素」。
- 左侧加仓基于确定性（越跌赔率越高），右侧加仓基于景气度（上涨验证判断）。闭环是：「基于确定性选股 → 赔率初步加仓 → 景气度验证后加到重仓」。
- 「**胜率标的买在赔率，赔率标的买在胜率拐点**」（2021-07-22）：
  - 白马跌出赔率就可以买。
  - 便宜但不确定的标的，要等景气度或催化剂拐点出现才买。
  - 「便宜的公司不会因为更便宜而出现投资机会」。「只有有长线逻辑的公司才能越跌越买」。
- **不可能三角**：景气度、长逻辑、估值只能三选二（2021-09-17）。
  - 景气度 + 估值 = 行业轮动。
  - 长逻辑 + 估值 = 深度价投。
  - 景气度 + 长逻辑 = 公募赛道配置。

### 2.5 卖出规则

- 卖出三原则：「**贵了、逻辑变了、有更好的**」，**不包括套牢**。他最常用的是「有更好的」。
- 「A逻辑进，A逻辑出，不能A逻辑进，用B逻辑留着」（2020-12-30）。「何时卖股票，跟你赚了多少没有关系」。「'等涨到成本价我就卖'是最最糟糕的策略」。
- 必须卖的两种情况：
  - 「所有跌下去后你无法判断该不该加仓的公司」。
  - 「所有你需要抱团取暖才能安心持有的股票」（2021-06-20）。
- 利空分级：影响逻辑、影响业绩、影响情绪，「影响力依次降低」。实质利空就在开盘集合竞价时卖掉。「需求的逻辑被破坏，跌一时，供给的逻辑被破坏，跌一世」。
- 长期成长股出问题的顺序：「先是赔率出问题，再是景气度出问题，最后才会影响到确定性」。
- 止损要和持仓结构配套：「集中持仓与止损是配套，分散持仓才能不止损」。2023 年后改为：不是「关键投资」的仓位，「盈利及时兑现，亏损及时止损」。
- **平台破位**（2022-01-15，对价值派也成立）：高位平台震荡一个月以上，开盘半小时放量跌超 5%、击穿平台下沿时，「卖出的胜算要高于继续持有」。「要么当机立断，要么死杠到底」。这和止损不同：一个月内要买回来。

## 3. 核心框架二：赔率 / 胜率的量化（2022–23）

- **预期收益率** = 盈利幅度 × 胜率 + 亏损幅度 × (1 − 胜率)（2022-03-26）
  - 胜率基准 50%：新手 45%、高手 60%；白马 50%、黑马 40%、能力圈内 60%。
  - 「买入估值不会改变胜率」：下跌代表分歧加大，所以亏损幅度 B 不能因为估值低就取正数。
  - 例子：增速 20%、胜率 50%、看错保平，得到 10%。平均仓位 80% 时，单笔要求 12.5%。
  - 茅五泸案例（2022-04）：先对合理 PE 问四个问题（估值趋势、行业 PEG 历史位置、景气方向、增速趋势），算出一年后目标价，再按预期收益反推计划买入价。
- **极限赔率建仓**（2023-02 / 03）：
  - 向上极限 = 乐观 EPS × 近三年持续两三个月的最高估值。
  - 向下极限 = 利好全部不兑现时的 EPS × 历史最差估值。
  - 档位：
    - 1:1 以上：不能买，持有的考虑减。
    - **2:1**：先买一半。
    - **3:1**：加满，作为最佳成本。
    - 观察仓跌到 3:1 时，可以卖掉手上高于 2:1 的同等确定性品种来换。
  - 这一版的预期收益率**两端都取极限价**：预期收益率 = 上行空间 × 胜率 + 下行空间 × (1 − 胜率)。作者给的校验例：高点 30、低点 15，在 2:1 买点 20 买入，预期收益率为 12.5%；高点 45、低点 15，预期收益率为 20%（2023-03-18）。2022 版的 B 是「看错时的平均亏损，取 0 到 −10%」，口径更宽松。`bands.py odds` 用的是 2023 版。
  - 长线底线是三倍赔率：三年 +100% 对应最大 −33%，年化约 10%（2025-11-24）。
  - 「成本最重要，仓位其次」。「牛股是涨出来的，但投资机会是跌出来的」。
- **长线靠赔率，中短线靠胜率**：时间越长，下跌越有底、上涨越无顶，赔率随持有期变大。短线的赔率约等于 1，只能靠胜率，所以短线要「见好就收 + 止损」。
- **止损会提高赔率，但同时降低胜率**（2023-03-11）。中短线用止损，前提是方法本身胜率足够高。
- **胜负手 / 关键投资**：全年盈亏取决于一两笔。每笔都按关键投资的标准开仓。出现以下证伪信号就转为普通仓：业绩不及预期且解释力不足、出现未预料的危机、行业拐点提前、风格巨变、估值判断失误。「看不清就要减仓，要温度不要风度」（举巴菲特 2020 年西方石油、航空股为例）。
- **仓位按波动定，不按看好程度定**（2023-07）：AI「配20个点就是重仓了」。「下跌时集中仓位，上涨时分散」。「急跌中加仓的仓位，是情绪的钱，过几天无论赚不赚钱都要减到原先的仓位」。

## 4. 核心框架三：机械化交易规则

这部分是他自己设计的**规则化方法**，有明确的参数，可以直接回测。

### 4.1 ETF 均线网格（2022-07 起，2023-04 增强）

| | 成长策略 | 超跌反弹策略 |
|---|---|---|
| 适用 | 长期或阶段性成长的行业 ETF（消费、消费属性的医药、科技 ETF），**必须是自己最看好的** | 任何在**年线以下**的 ETF，最好偏离 5% 以上 |
| 基准线 | **60 日均线**，持「最大仓位的一半」 | **年线**，基准仓位为 0，**上穿年线就清仓** |
| 档位 | 每档 5%，档数按该指数历史最大乖离率定。光伏 ETF 例子：向上 5 档（1.05⁵ ≈ +27%）、向下 5 档（0.95⁵ ≈ −23%），每档加减 3%，最大仓位 30% | 每档 5%，最多约 7 档（−30% 封底），每档加 3% |
| 收益来源 | 均线上行 + 来回波动 + 低开仓点 | 「用 N 层仓赚一档的钱」，接近必胜，代价是时间和浮亏 |
| 失败情形 | **均线由多头转空头，又亏比例又亏仓位**，这是唯一需要止损的场景 | 跌穿最后一档后继续下跌 |

- 增强（2023-04）：
  - 20 日线高于 60 日线一个网格以上时，基准换成 20 日线，主升浪再换成 10 日线，以免过早丢失筹码。
  - 长期上涨后**首次跌破年线**时，反手减掉一部分仓位，切换成年线超跌反弹策略。
- 原则：「网格交易是被动策略，千万不要主动去判断顶和底」。「择股与择时是相背的，强化择股就可以弱化择时」。
- **微盘股网格**（2023-11-25）：市值 17–25 亿的 400 只股票，分四个市值档；上穿一档减一份，下穿一档加一份。前提是「市值硬底」。**这个前提在 2024 年初微盘崩盘时被证伪**，他自评「对雪球敲入连带微盘股危机的发现有点晚」。

### 4.2 长线波段操作（2023-07 / 08）

- 公理：「股价90%的时间都在均值回归，10%的时间在趋势运行」。均线缠绕对应均值回归，均线发散对应趋势。
- **高 / 低位的定义**：20 / 60 日均线乖离率。高位为 +10%（熊市）~ +15%（牛市）以上，低位为 −10%（牛市）~ −15%（熊市）以下，约等于乖离率的 1–2 个标准差。
- **四原则**（括号内是执行概率）：
  1. 低位第一优先买入或加仓（90%）。
  2. 高位第二优先卖出或减仓（80%）。
  3. 高位反向操作（不减，回落到 +5% 时加），必须有基本面的强理由（≤20%）。
  4. 低位反向操作（不加，或反弹到 −5% 时清仓），同样要有强理由（≤10%）。
- 正确概率排序：**低位买入 > 高位卖出 > 高位买入 > 低位卖出**（与霍华德·马克斯的结论一致）。
- 最适合的标的：业绩向上、估值合理、持续上涨不超过一年、非热门的机构白马，或自己研究很深、暂无催化剂的潜力股。不适合：题材股、走主升浪的股票、多年连涨的抱团白马、超跌反弹股。
- 「高位没有利好就是利空」被他量化为：乖离率超过阈值，且没有催化剂事件，同时基本面没有变坏，就减掉一部分。
- 天敌：「长达3年以上的长期估值调整」，例如 2021 年以后的白马，在操作层面无解。
- 定位：「波段操作不是为了高抛低吸，而为了仓位合理利用」。这是一个牛市轻仓、熊市重仓的方法，需要融资账户作为大跌时的备用额度。

### 4.3 台阶式成长股（2021-07，形态 + 基本面）

- 成长股的形态是「中枢震荡 + 向上趋势」交替。「盘整行情对应的是市场意见分歧，趋势行情对应的是分歧消除」。周 K 级别看。
- 收益分三段：下平台的成本（交易能力）、台阶间距（研究能力，最核心）、上平台的卖出（交易能力）。结论是「在下面成本段坐过山车」。
- 「一段趋势如果被之后的反向趋势否定，那就构成了一个更大的盘整行情」。趋势结束并出现反向趋势后，合理估值区间才算确定。
- 「股价创新高而估值不能创新高，往往意味着它从成长走向成熟」，此时估值中枢要下移一个台阶。

### 4.4 2024 年后的择时指标（主观打分，**非公式**）

| 指标 | 定义 | 用法 |
|---|---|---|
| **震荡&趋势指数**（原「兴奋恐慌指数」，2021-09 首发） | 0–100，主观打分 | 25 和 75 之间用均值回归（30–70 向上减、向下加；25–30 只卖不买；70–75 只买不卖）；**跌破 25 迅速降仓，涨破 75 迅速加仓**。只适用于指数 |
| **散户净持仓指数**（独家） | 散户为主的期货席位在 4 个股指期货上的净多头，按两年极值归一到 0–100 | 「指数慢慢跌破60天均线，同时散户仓位长时间在80以上」为中期顶部信号；「均线多头排列，散户仓位持续在60以下」为安全上涨。周线级，确认顶部有效、判断底部一般，中线是反指 |
| **七因子 → 八因子** | 宏观 / 政策 / 流动性（因）+ 技术 / 量价 / 筹码 / 板块（果），2025-09 加入 IV + 偏度 | 「顶部的判断，市场交易因子更重要，底部的判断，基本面因子更重要」。IV 与偏度（看跌 IV / 看涨 IV）同时上升时偏空 |
| 择时级别原则 | — | 「**日线级别的择时策略以逆势为主，周线级别的择时策略以顺势为主**」（2024-06-08） |
| 美股减仓法 | — | 距上次创新高两周以上减一部分，跌破前一次下跌低点再减一部分（2024-03-14） |

## 5. 市场观与配置观

- **A 股本质**：
  - 「A股是一个赔率高胜率低的市场，择时的作用大于择股」（2024-06-17）。
  - 长期看是净资产增长线加超涨超跌，「七亏二平一赚」。
  - 封闭市场里是「主线 + 血包」：有主线时做存量博弈，没主线时做减量博弈。「避开'血包'，你基本上不会落后」。
- **风格与贝塔优先**：「大部分投资者以为是凭本事赚的钱，其实大部分是风格的钱，包括巴菲特」（2023-05-03）。「新增资金决定市场风格」。「风格切换是靠下跌来实现的」。
- **杠铃**：一端核心红利，一端预期引导的科技，「两头都要极端」（2024-10-12）。适用于「强预期弱现实」或「弱基本面强流动性」，「只要不是宏观经济有明确的复苏，基本上都适用」。
- **红利**：
  - 2023-05 他还说高分红「无法成为长期投资模式」。
  - 2024-04 改为「不是一个周期，这是一个时代」。
  - 2024 年要「涨多了就要卖」，按股息率轮动。2025-06 改为「关于红利类资产，不要择时」，红利低波逢低慢慢买。
  - 红利四要素：ROE 稳定是核心。
- **困境股池**（2024-06）：只选消费龙头。离历史最高价跌幅 ≥50% 入池（最好跌到三折），回到最高价的八成左右出池，最长持有两年。「先定有优势的赔率，再去努力提高胜率」。
- **周期观**：
  - 周期股「股价永远在商品价格到顶之前见顶」。
  - 「上行期估值没有顶，下行期估值没有底」。
  - 低 PE「就是预支未来亏损时的高估值」。
  - 出清要用「全行业亏损」来确认。
  - 「真正值得警惕的是把周期当成长」。
  - 2026 年用同一套逻辑判断光模块到了大周期顶：增速「从三位数以上下降到百分之三十」，且没有二次加速。
- **底与顶**：
  - 「A股的历史大底都是超跌形成而不是宏观基本面的反转」。底部看成交额，不看点位。
  - 「顶都是事后确认的……有了一些信号，就要动手一部分」。
  - 「腰部风险比顶部风险更需要避免」：跌到「估值已经很合理」的前期平台时，人以为安全，亏的却是真金白银。
  - 估值三年律：「连续两年估值扩张，第三年无论涨跌，都在压缩估值」。
- **散户边界**：
  - 不做题材、事件驱动、景气度投资。
  - 「投资赚的是你的认知范围内的钱」。
  - 「计划你的交易，交易你的计划」，绝大部分散户不适合盘中临时决策。

## 7. 方向判断的记录（只当背景，**不当规则**）

【推断】他的判断多以「区间 + 条件」的形式给出（3200–3550、3300–3800、「如果……就……」），事后容易自洽，也难以证伪。明确认错的多是局部判断：国企分红意愿（一周内自己更正）、微盘危机发现得晚、反内卷、存款搬家叙事。大势判断落空时，他更常说「被偶然事件打断」或「超预期」。

| 时点 | 当时 | 结果 |
|---|---|---|
| 2021 春节核心资产见顶 | 节前减仓，节后很快加回，「等于白减了」 | 他事后判定这次择时无效 |
| 2022 熊市 | 年初判断「今年不会像2018年那样的熊市」；3 月还在给茅台 1640 的计划买入价；11 月说「新一轮牛市已经来临」 | 方向错。但 2-07 按预设阈值机械减仓，熊市里自称没跌太多 |
| 2024 年初微盘崩盘 | 2023-11 刚推出微盘网格 | 认错：「小看了趋势的力量」 |
| 2024 年中性策略 + 红利主仓 | 自评「非常正确」 | 红利主仓加做空小盘，「到现在都是持续盈利」（2024-08） |
| 2024-09-24 | 开盘减空单，定性为熊市反弹，给出 3200–3550 的区间 | 区间基本命中；他强调自己「从来没有用'牛市'去定位」 |
| 2025-01 | 「震荡的出口是向下」 | 被 DeepSeek 行情打断（实际判错，但没有明说） |
| 2025-11 → 2026 | 「明年上4200点，然后结束本轮行情」，同时说「高点纯粹是瞎猜」 | 2026-06 高点 4258。但 2025-11 到 2026-06 他中线偏谨慎，AI 硬件大涨期间多数时候踏空 |
| 2026-07 / 08 | Meta 出租算力是「AI叙事第一次大变化」；确认牛市结束；光模块到大周期顶 | 待验证 |

**当前（2026-09 / 10）立场**：
- 「牛市走向尾声熊市还没开始」，宽货币、紧财政，指数在 3700–4100/4200 区间震荡。
- 配置上，A 股和港股的红利、标普 500 ETF、可转债至少占一半，其余仓位找进攻性标的。
- AI 方面回避上半年大涨、机构筹码集中的硬件，看好应用层、Computer Use 和港股，自称「周期派」。

## 8. 与常见交易纪律的对照

| 常见纪律 | 思想钢印 | 关系 |
|---|---|---|
| **强周期股看 PBR 不看 PE；卖在基本面拐点，不卖在高估值本身** | 「周期股……看PB更合理」（2021-04-08）；「上行期估值没有顶，下行期估值没有底」；「把周期当成长」是最大的错；2026-08 用增速回落判断光模块周期顶 | **高度一致**。他的「增速从三位数回落到 30% 且无二次加速」相当于「价格二阶导见顶」的单票营收版 |
| 卖铲人要验证利润是否真的传导下来（上游可能把利润留给自己） | 「供给弹性」框架：分析产业链每个环节的供给弹性，供给是根本，需求是导火索；短期供给弹性小、长期大，就是强周期；2026 年的「炒瓶颈」是 GPU → 服务器 → 机房 → 电 → HBM → 光通信 | **互补**。他用供给弹性找能提价的环节，利润传导检验负责证伪 |
| 趋势跟踪：顺势、不抄底 | 「日线级别逆势、周线级别顺势」；台阶式和长线波段**都在均线下方加仓、上方减仓**，属于均值回归；只在区间突破时切换为趋势操作 | **哲学相反**。两者可以作为不同仓位共存，但**不要混进同一个标的的同一套信号**（他自己的话：「价值投资进，趋势投资出……这才是稳定亏钱的方法」） |
| 历史回测出的「适配性」不能外推 | 「策略需要在某些情况下失效，且何时失效只能事后确定」；「赚钱的方法都有生命周期」；量化涨跌比策略「几个月就会失效」 | **一致** |
| 同一因子的多只标的是加杠杆，不是分散 | 「平安、招行、万科属性太相似……起不到分散仓位的作用」；「回撤风险决定仓位，而不是看好程度」 | **一致** |
| 定投（无条件、只买不卖） | 超跌反弹网格 = 年线下分档加仓，上穿年线清仓；成长网格 = 60 日线上下对称加减 | 网格是「有条件、可卖出」的定投变体 |

## 9. 已验证 / 未验证

> **2026-10-04 已做**：他的**可量化选股规则**（ROE 质量、净现比、应计、盈余波动、增速见顶、新高估值不新高、极限赔率）
> 与「估值扩张」「PBR 分位」两条常见纪律一起做了 PIT 检验 → [docs/03](03-选股规则检验.md)。
> 结论：**没有值得用的选股规则**（两条勉强通过的效应太弱且不稳）；**极限赔率 ≥2/≥3 选股显著差于随机**。
> 机械交易规则（波段 / 网格 / 超跌网格）也已回测：**跑不赢同仓位不择时**，见 [docs/02](02-交易规则回测.md)。
> 复现：`backtest.py` / `backtest_cn.py` / `backtest_trading.py`。

还没做的：
1. **散户净持仓指数**无法复现（他用的是私有席位数据）。可以试着用公开的期货公司持仓排名（中金所每日前 20 名会员）近似构造，验证「跌破 60 日线 + 散户仓位 >80 时是顶部」。
2. **震荡&趋势指数**是主观打分，不可复现。可以尝试用 ADX 或布林带宽度做一个 25 / 75 双临界的客观代理，检验「区间内均值回归、区间外趋势」的切换是否有增量。

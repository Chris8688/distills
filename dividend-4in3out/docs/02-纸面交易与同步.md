# 纸面交易与雪球同步

2026-10-02 立。纸面账户跑**蒸馏出的筛选器**（`screen.py`，observed 档），雪球作者的持仓只同步到本地作对照。
纸面账户的账本放在仓库外（`DISTILL_STATE`，缺省 `~/.local/share/distills/dividend-4in3out/`），**不在本仓库**。

## 1. 纸面账户

| 项 | 口径 |
|---|---|
| 初始资金 | 10,000,000 元人民币 |
| 规则 | observed：股息率 ≥4% 且扣非 ≥ -10% 才买；≤3% 卖；扣非 < -30% 卖；扣非 < -10% 且扣非口径预期股息率 < 4% 卖；其余扣非 < -10% 复核持有 |
| 排序 | 可持续股息率 = min(股息率, TTM 盈利收益率) 降序；分红率 >100% 连续 ≥2 年不买 |
| 买入过滤（2026-10-05 起） | 不接飞刀（相对版）：过去一年前复权涨跌比全部长期分红股中位数多跌 25% 以上不买；不买利润暴增：TTM 归母净利同比 >+70% 不买（docs/04）。只挡买入，已有持仓不卖 |
| 结构 | **30 只**等权，目标 = 总资产 / 30；单行业 ≤ 6 只（20%）；随时满仓「不出则不进」；不再平衡。选 30 的依据见 docs/01 §3.4 |
| 成交价 | 最近一个已收盘交易日（`lib/calendar.last_completed_session`）的收盘价，TickFlow 不复权日线 |
| 频率 | 每天定时跑 `daily.sh`（北京时间 17:00 后）；同一交易日只交易一次，周末/节假日自动跳过 |
| 停牌 / 涨跌停 | 当日无 K 线不交易；收盘涨停不买、跌停不卖（主板 ±10%，300/301/688 ±20%），顺延到下次运行 |
| 手数 | 100 股向下取整，科创板至少 200 股 |
| 费用 | 佣金 0.025%（最低 5 元）+ 过户费 0.001%（双边）+ 印花税 0.05%（卖出） |
| 分红 | 除息日现金入账；股权登记日前已持有才享有；红利税按除息日持有天数近似（≤30 天 20%，≤1 年 10%，>1 年 0；实际是卖出时补扣） |
| 送转 | 除权日按比例加股、摊薄成本 |
| 分红再投入 | 税后分红买回派息的那只（一手取整）；该股本轮被卖 / 停牌 / 涨停 / 不足一手 → 留现金等补位。股息约占收益 1/4，闲置会拖累净值（docs/01 §3.3） |
| 对照 | `nav.csv` 的 `cube_nav` = 作者组合净值按纸面账户起始日归一 |

已知局限：
- 收盘价成交是理想化的（小市值股 50 万的单子有冲击成本）；没有模拟部分成交。
- 预期股息率用新浪财务摘要的扣非 TTM，数据偶有缺漏 → 缺数据时按「预期股息率未知」处理（observed 下等同 < 4%，会卖）。

## 2. 雪球同步

| 数据 | 方式 | 落地 |
|---|---|---|
| 净值、组合行情 | 匿名（`/hq` 种下 xq_a_token） | `data/xueqiu/nav.csv` |
| 调仓历史 | **需要登录**（匿名返回 10022） | `data/xueqiu/rebalancing.csv` |
| 当前持仓 | 组合页 `SNB.cubeInfo`，页面有阿里云 WAF 滑块 | `data/xueqiu/holdings/<日期>.csv` |

流程：用浏览器打开组合页 → 遇到滑块 / 未登录就**自己手动完成**（自动化工具不替人过验证、不输密码）→ 执行 `sync_xueqiu.py js`
→ 返回行 `ingest`。去重键 (日期, 代码, 目标权重, 价格)，早期存档没有 rb_id 也能对上。

## 3. Notion（可选）

可以把纸面账户镜像到 Notion：方法论页 + 交易流水 / 当前持仓 / 每日净值三张表。
本地账本是唯一事实源，Notion 是镜像；同步进度记在账本目录的 `paper/notion.json`（数据库 id、已同步的流水号、净值日期、持仓行 page id）。

## 3.1 定时任务

`daily.sh`：作者净值 → 纸面账户 → 持仓体检与买入清单；日志 `$DISTILL_STATE/logs/<日期>.log`、状态 `logs/last_run.json`，失败弹 macOS 通知。
雪球持仓/调仓（要登录）与 Notion 不在定时任务里，下次调用 skill 时补齐（`notion-pending` 会列出积压）。
用 cron 或 launchd 每天北京时间 17:00 后调用即可。

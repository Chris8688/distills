# 买入过滤探索：保留大涨股的前提下降低买错（2026-10-04 探索，2026-10-05 落地）

脚本：`research/buy_filters.py`（缺省 = 诊断 + 单路径；`--robust` 多起点；`--robust --grid` 阈值扫描；`--windows` 两段独立窗口）。
回测框架同 docs/03（`research/backtest_exits.py`）：30 只等权、单行业 ≤6、月底调仓、单边 0.15%、分红再投入；
卖出规则全部用现行 V0（三出 + 业绩卖出），**只改买入过滤**（上一轮已证明动卖出规则会砍掉大赢家）。

指标：**买错率** = 单笔亏超 10% 的交易占比；**陷阱率** = 因业绩卖出且亏损的占比；**大赢家** = 单笔涨超 50% 的笔数。

## 1. 诊断：买错的票在买入那一刻长什么样

V0 的 129 笔交易：买错 34、大赢家 31、其余 64。买入时特征的中位数：

| 特征 | 买错 | 其余 | 大赢家 |
|---|---|---|---|
| EPS 同比 | **+42%** | +30% | +12% |
| 上年分红变化 | **+115%** | +75% | +67% |
| 过去一年股价 | -3% | -5% | -2% |
| 股息率 / 可持续股息率 / PE / 分红率 / 相对 PE | 几乎相同 | | |

买错的多半是**利润和分红刚刚暴增之后买进**的 —— 峰值利润、峰值分红（周期顶形态），之后业绩回落、股价跟着回落。
股息率、PE、分红率这些「便宜程度」指标在三组之间几乎没有区别 —— **区分买错的不是贵不贵，是利润在不在峰值**。

## 2. 单路径初筛（2018-06 起一条路径）

被否掉的方向：
- 「EPS 同比 ≥0」（只买业绩增长的）：反而更差（年化 10.1%），因为它偏爱的正是利润暴增的票。
- 「上年分红没翻倍」「峰值利润 + 峰值分红都不买」：买错率降了，但**大赢家被砍掉 40%**（保留 60%）——
  分红大幅提升常常是大赢家的前兆，不能一刀切。
- 「强周期行业一律不买」「分红率 ≤80%」「刚到 6% 不买」：大赢家损失大于买错减少。

## 3. 多起点稳健性（17 个起点，2018-06 ~ 2022-06 每季度一个，都跑到 2026-09）

单一路径受「哪个月开始」影响很大（30 只，换几只就差 ±1pp），所以每个方案跑 17 条路径取平均。

| 方案 | 比现行年化 | 跑赢现行的起点 | 买错率 | 陷阱率 | 大赢家笔数 |
|---|---|---|---|---|---|
| 现行 | — | — | 26.4% | 30.4% | 24.9 |
| 不接飞刀 -25%（过去一年股价跌幅 <25%） | +0.45pp | 13/17 | 25.1% | 28.2% | 24.7 |
| 不接飞刀 -30% | +0.29pp | 12/17 | 25.4% | 28.9% | 24.6 |
| EPS 同比 ≤+70% | +0.45pp | 13/17 | 24.6% | 28.5% | 25.9 |
| EPS 同比 ≤+80% | +0.38pp | 13/17 | 24.8% | 28.4% | 25.6 |
| EPS 同比 ≤+60% | -0.12pp | 6/17 | 24.7% | 28.4% | 25.0 |
| EPS 同比 ≤+50% | -0.27pp | 6/17 | 22.9% | 27.1% | 24.5 |
| **飞刀 -25% + EPS ≤+70%** | +0.18pp | 11/17 | **23.2%** | **27.7%** | **25.5** |

阈值：「不接飞刀」在 -25%~-30% 是平台；「EPS 上限」在 +70%~+80% 是平台，+60% 以下开始砍大赢家。

## 4. 两段独立窗口（阈值是在全期挑的，必须两段都成立）

| 方案 | 前段 2018-06~2022-06（9 起点） | 后段 2022-07~2026-09（9 起点） |
|---|---|---|
| | 年化差 / 买错率 / 陷阱率 / 大赢家 | 年化差 / 买错率 / 陷阱率 / 大赢家 |
| 现行 | — / 28.8% / 23.8% / 11.3 | — / 17.9% / 23.4% / 10.6 |
| 不接飞刀 -25% | +0.84 / 26.6% / 21.2% / 12.0 | **-0.10** / 16.8% / 20.3% / 10.2 |
| EPS ≤+70% | +0.70 / 24.5% / 22.6% / 11.0 | +0.37 / **19.0%** / 20.0% / 11.8 |
| **飞刀 -25% + EPS ≤+70%** | **+0.39 / 23.6% / 22.0% / 11.1** | **+0.10 / 16.7% / 18.9% / 11.1** |

只有组合规则在两段里**同时**做到：买错率更低、陷阱率更低、大赢家不少、年化不差。
单用「不接飞刀」后段年化略负；单用「EPS 上限」后段买错率反而略高。

## 5. 结论（探索）

**更有效的买入规则 = 现行四进 + 两条过滤**：
1. **不接飞刀**：过去一年股价跌超 25% 的不买 —— 高股息加暴跌，多半是市场在定价分红/业绩出问题。
2. **不买利润暴增**：最新 TTM 每股收益同比超过 +70% 的不买 —— 峰值利润分红，之后大概率回落（与「强周期股周期顶看 PBR、警惕峰值利润」的纪律一致）。

效果（17 起点平均）：买错率 26.4% → 23.2%（相对降 12%），陷阱率 30.4% → 27.7%，大赢家 24.9 → 25.5 笔，年化 +0.18pp；两段独立窗口都成立。
卖出规则不动（四进三出 + 业绩退出）。

**诚实的保留**：
- 改善幅度是「几个百分点的买错率、零点几个点的年化」，不是质变；同一时期的路径之间相关，17/9 个起点不是独立样本。
- EPS 用基本每股收益近似扣非；退市股不在样本；行业用今天的分类。
- 被过滤掉的大赢家（现行规则大赢家里约 14% 不再买到）由其他大赢家补上，笔数不减，但具体是哪几只会变。

## 6. 已落地（2026-10-05）

`screen.py` 加 `KNIFE_DROP = -0.25`、`PROFIT_SURGE = 0.70`，三档规则都生效，只挡买入。生产口径与回测的差别：
- 一年涨跌：TickFlow 前复权（含分红）最近收盘 vs 365 天前，与回测一致；缓存 20 小时（`px1y.json`）。
- 利润暴增：用新浪逐期**归母净利润**的 TTM 同比（回测用基本每股收益），只差股本变化。

落地当日（2026-10-05，数据截至 09-30）：买入清单 178 → 132 只（飞刀挡 64 只）。

## 7. 相对飞刀验证（2026-10-05，`research/buy_filters.py --relknife`）

**问题**：已落地的绝对飞刀（一年跌超 25%）错过的大涨股，多半是全市场暴跌后的反弹（2018-12、2020-03）。
在 17 个起点里，它挡掉的 146 笔中有 18 笔大涨、51 笔买错；「利润暴增」那条更有效（中位 -6.3%，错过 7 笔大涨、躲过 37 笔买错），
「飞刀」较弱（中位 +1.4%，错过 11 笔、躲过 20 笔）。

**改法**：飞刀按**相对**跌幅算 —— 过去一年涨跌减去当月全部长期分红股的中位数，比中位数多跌 25% 以上才算飞刀。

| 方案（都含利润暴增 ≤+70%） | 比现行年化 | 跑赢起点 | 买错率 | 陷阱率 | 大赢家 | 前段年化差 / 买错率 | 后段年化差 / 买错率 / 陷阱率 |
|---|---|---|---|---|---|---|---|
| 现行 V0（无过滤） | — | — | 26.4% | 30.4% | 24.9 | — / 28.8% | — / 17.9% / 23.4% |
| C 已落地：绝对飞刀 -25% | +0.18pp | 11/17 | 23.2% | 27.7% | 25.5 | +0.39 / 23.6% | +0.10 / 16.7% / 18.9% |
| R1 相对 -20% | +0.90pp | 16/17 | 22.0% | 26.4% | 24.4 | +1.58 / 22.9% | +0.78 / 15.2% / 18.4% |
| **R2 相对 -25%** | **+0.88pp** | **16/17** | **22.3%** | 27.3% | **25.6** | +0.94 / 23.5% | **+1.13 / 14.1% / 16.6%** |
| R3 相对 -30% | +0.42pp | 13/17 | 23.2% | 26.8% | 25.6 | +1.82 / 23.8% | -0.01 / 17.3% / 18.5% |
| R4 绝对 -25% 且相对 -15% | +0.25pp | 12/17 | 23.2% | 27.7% | 25.7 | +0.85 / 23.9% | -0.04 / 16.8% / 18.9% |

R2 在全期和两段独立窗口里**每一项都优于已落地的 C**：年化多 0.7pp、买错率再降约 1pp、后段陷阱率 18.9% → 16.6%、大赢家不减。
R1 错过的大涨更多（38 笔），R3 后段不稳，-25% 最稳。

换成相对版后，两边各约 28 笔交易互换，方向都对：
- **放行**（绝对版挡、相对版放）27 笔：大涨 6、买错 4 —— 2018-12 底部反弹为主：兖矿能源 +91%、中国重汽 +75%、滨化股份 +58%、淮北矿业 +107%（一年跌 30% 多，但和大盘差不多）。
- **新挡**（绝对版放、相对版挡）29 笔：大涨 7、买错 10 —— 大盘没事、**自己在跌**的：金科股份 -48%/-43%（2021 地产暴雷前期）、索菲亚 -40%（2025 年一年 +7% 但落后中位 37%）、浦发银行、招商蛇口。

结论：**相对飞刀 -25% 优于绝对飞刀** —— **2026-10-05 替换**。`screen.py` 用 `KNIFE_REL = -0.25`，基准 = 全部连续分红 ≥4 年的可交易 A 股（当日 2,722 只，一年涨跌中位 -9.6%）。
买入清单 132 → 136 只，飞刀挡 64 → 25 只。

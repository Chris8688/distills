# 股息率模式「四进三出」· 投资思路蒸馏 · 报告

> 规则可执行，已做历史回放，附筛选器与纸面账户脚本。
> 不构成任何投资建议；数据源偶有缺漏，下单前请核对公司公告的分红方案。

## 一、结论

1. **规则简单、能执行**：静态股息率 ≥4% 买、≤3% 卖；连续分红 ≥4 年；保底分红率 ≤100%；季报扣非恶化就走；15 只等权（2026-10-06 由 30 只改为 15 只，见 docs/06）、单行业 ≤20%；随时满仓，「不出则不进」。
2. **长期回放稳**：2018-06 起 40 个滚动 5 年窗口，年化平均 **+14.1%**（最差 +9.9%），5 年内最大回撤中位 -11.8%；任意 12 个月只有 3% 亏损，没有亏超 5% 的。
3. **但超额主要来自「高股息风格」本身**：对沪深300 和上证红利ETF 都是 40/40 跑赢；对最接近的中证红利ETF，6.8 年年化只多 1.2pp，回撤几乎一样。扣掉回测没算的红利税和幸存者偏差，**真实超额可能只有 0~1pp/年**。只想要这部分收益，买中证红利ETF 更省事。
4. **它的价值在于可控**：可以按自己的规则排雷（飞刀、利润暴增、分红高于利润），控制行业集中度，也方便做后续优化实验。
5. **「三出」很少触发**：100 次卖出里，业绩卖出 82 次，股息率 ≤3% 只有 13 次。更准确的说法是「四进 + 业绩出，偶尔三出」。
6. **作者的 16% 不能当基准**：同区间比，作者净值和回放几乎一样；多出来的几乎全靠 2021 年 +54.5%，那一年他高频轮动小盘股，大量破了自己的规则。规则化复制不了。
7. **熊市在长样本上也站得住**：拉长到 2007-06 起（30 只回放），全程年化 **+13.1%**、月末回撤 −15%；
   2007-10 顶 → 2008-10 底 −12.7%（同期长期分红股等权 −65.5%、上证红利ETF −72.9%），2009 年 +43.7%，2015 股灾 −3.3%，2018 年 −6.8%。
   机制是**股息率门槛本身就是估值闸门**：牛市顶部买不到 ≥4% 的票，组合自动空仓。相对飞刀在 2007~2017 这段没用过的数据上得到确认。
8. **稳妥预期：5 年年化 10%~14%、回撤 15% 左右。** 熊市少亏，牛市少赚（2019、2020 各跑输沪深300 约 20pp）。

## 二、来源与方法

- **源头**：雪球组合「股息率组合」ZH1027925：<https://www.xueqiu.com/P/ZH1027925>。主理人「高股息之家」（老杜）。2017-02 创建，至 2026-09 雪球模拟净值年化 14.1%、最大回撤 -17.6%。
- **语料**：作者公开文章（《股息率模式"六大原则"》《如何计算股息率》等），以及组合全部 466 次调仓（633 笔成交），存档在 `data/xueqiu/`。
- **蒸馏**：规则分三档：一手原文（作者公开的「1.0」）、二手转述（已被他的实盘证伪）、实盘反推（他的「2.0」，规则没公开）。
- **校准**：每个阈值都对作者 2021 年以来 111 笔真实买入逐笔回算，看「会误挡多少笔作者的真实买入」，不拍脑袋。
- **检验**：月度历史回放，2015~2026 全部连续分红 ≥4 年的 A 股，财报按披露截止日才算可见，单边成本 0.15%。

## 三、规则

| 项 | 规则 | 出处 |
|---|---|---|
| 买入 | 静态股息率 ≥4%（上年全年现金分红 ÷ 当前市值） | 作者原文 |
| 卖出 | 股息率 ≤3%；或季报累计扣非同比恶化（见规则档） | 作者原文 + 实盘反推 |
| 连续分红 | ≥4 年（原文写 5 年，按作者实盘校准为 4 年） | 原文 + 校准 |
| 保底分红率 | 4% × TTM 市盈率 ≤100%（= TTM PE ≤25） | 作者原文 |
| 分红怪异 | 分红突增 >10× 前 4 年中位，或分红率 >100% 连续 ≥2 年，不买 | 作者原文 |
| 不接飞刀 | 过去一年跌幅比全部长期分红股中位数多 25% 以上，不买 | 回放验证后加入（docs/04） |
| 不买利润暴增 | TTM 归母净利同比 >+70%，不买（峰值利润分红） | 回放验证后加入（docs/04） |
| 排序 | 按「可持续股息率」= min(股息率, TTM 盈利收益率)，不按静态股息率 | 蒸馏时加的，防一次性超额分红 |
| 组合 | 30 只等权；单行业 ≤6 只；随时满仓「不出则不进」；不再平衡 | 作者原文 + 分散度分析 |

扣非规则有三档（脚本 `--rules`）：

| 档 | 卖出 | 买入额外条件 |
|---|---|---|
| `1.0` | 累计扣非同比 < -10% | 扣非 ≥ -10% |
| `observed`（纸面账户用） | 扣非 < -30%；或扣非 < -10% **且**扣非口径预期股息率 < 4%；其余扣非 < -10% 只标「复核」继续持有 | 扣非 ≥ -10% |
| `strict` | 同 1.0 | 扣非 > 0、现金流 / 净利 > 0.6（金融业豁免） |

`observed` 是用作者 2023 年起 27 次「扣非 < -10%」的真实决策拟合的：命中他卖出的 12/18，误卖他留着的 1/9。

## 四、回放与研究

| 研究 | 结论 | 文档 |
|---|---|---|
| 长期战绩与基准 | 滚动 5 年年化 +14.1%；对中证红利ETF 超额约 0~1pp/年 | [docs/05](docs/05-长期战绩与基准.md) |

| 相对估值（自身历史 PE / 股息率分位） | 单信号更准，但组合层面每年少赚 0.3~1.6pp：在估值扩张途中卖掉了大赢家 → **不采用** | [docs/03](docs/03-相对估值探索.md) |
| 高股息陷阱 | 股息率 >6% 事前分不清低估还是陷阱；赚钱靠不对称：陷阱被扣非规则早砍（亏小），低估拿到估值修复（赚大） | [docs/01 §3.5](docs/01-蒸馏笔记.md) |

## 五、要注意的

- **强周期股**：高股息常是周期顶的峰值利润分红（作者持有航运、煤炭，2018 年买过一串钢铁）。脚本会标「强周期·看PBR」，但**不剔除**，剔除就不是这个策略了；要另外做周期顶检查。
- **单因子、轮动**：持有期中位 162 天，不是买入持有；持仓全是「高股息 / 价值」一个因子，内部不构成分散。
- **与红利低波均线（同仓库 dividend-lowvol-ma）押的是同一个风格**，同时用不是分散；两者对比见那边的 docs/03。
- **纸面账户不是回测**：运行时间短的纸面账户没有统计意义，判断规则好坏看历史回放。

## 六、局限

- **幸存者偏差**：退市股不在回放样本里，真实收益更低。
- **回放没扣红利税**（约 -0.3~-0.5pp/年）；收盘价成交没算冲击成本，作者持仓里大量是 30~80 亿的小市值股。
- **样本年份**：这 8 年价值 / 红利风格占优；多个起点的路径相关，不是独立样本。
- **作者业绩是雪球模拟组合**：瞬时成交、无红利税；而且它是从大量组合里事后「出名」的那个。
- 作者「2.0」的具体规则已转入付费内容，只能从实盘反推。

## 八、运行

在本目录下：

```bash
pip install akshare requests
python3 screen.py --rules observed --top 30          # 买入清单（首次全量约 8~10 分钟，之后走缓存）
python3 screen.py --codes 600900                     # 单只明细与判定理由
python3 paper.py init && python3 paper.py run        # 建纸面账户并落账
python3 sync_xueqiu.py nav                           # 拉作者组合净值
```

- 缓存：`~/.cache/distill/dividend-4in3out/`（环境变量 `DISTILL_CACHE`）。
- 纸面账户账本、Notion 同步进度、日志：`~/.local/share/distills/dividend-4in3out/`（环境变量 `DISTILL_STATE`），**不在仓库里**。

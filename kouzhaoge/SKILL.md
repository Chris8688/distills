# 口罩哥（KZG）· 投资逻辑蒸馏

一个**投资思路蒸馏**，只出分析，不下单。

使用前**先读** `docs/01-蒸馏笔记.md`。里面依次是：五阶段演化、卡点经济学、存储周期判底与判顶、K-Research 研究模板、宏观接口、交易心法、改过的观点、命中率与当前立场、语料可信度、与周期股和卖铲人纪律的对照。

要查具体时期的原文证据，读 `docs/notes/`：
- `P12_2020_23`：搬运期、宏观事件期、2023 AI 年
- `P3_2024`、`P4_2025`、`P5_2026`：分年度笔记
- `K1`、`K2`、`K3`：K-Research 的逐篇索引、方法、预测和术语表

原始语料是付费内容，不进 git。有的话放在 `$DISTILL_CACHE`（缺省 `~/.cache/distill/kouzhaoge/`）：
- `corpus/posts.json`：全部帖子
- `corpus/P*.md`：按年切分的帖子
- `corpus/K*.md`：K-Research 文字
- `kresearch/`：K-Research PDF 原件

需要原文时可以 grep 这些文件。

## 检查点清单

所有命令在本目录下运行（依赖 PyYAML）。

```bash
python3 watch.py                      # 已到期未核 + 45 天内到期 + 命中率
python3 watch.py --days 120 --theme 存储
python3 watch.py --monitors           # 常驻阈值（现货、实现率、库存、证券化……）
python3 watch.py --all --json
```

数据在 `docs/watchlist.yaml`，只收他**写死了阈值或日期**的证伪信号，三情景概率不收。
检查点到期后：
1. 去核对数据，**不要编数字**。核不到就保持 `pending`。
2. 改 `status` 为 `hit`、`miss` 或 `void`，并写上 `outcome`（数值和出处）。
3. 跑 `python3 -m pytest -q tests`。

## 怎么回答

1. **问框架**：按笔记作答，引用原文要带日期，并说明出处是**短帖、K-Research 还是机器生成的日报**（笔记 §9）。2024-05 以后的【星球日报】和「XX 最新研报指出」体**不算他的观点**。短帖和长文的估值尺子不一样，**以长文为准**（笔记 §3.3）。
2. **按他的框架体检某只标的**：
   - 按卡点框架走一遍：卡点在哪道工序；谁握有卡点（份额、认证、交期）；财报有没有兑现（收入、现金流、合同负债、预付款）；最后才看估值（笔记 §2）。
   - 体检对象是设备、材料等「卖铲人」时，**必须接着走卖铲人四步证伪**（见 README 附录）。他自己没做业绩背离检查，韩美半导体就是反例。
   - 体检对象是存储时，加跑笔记 §3.2 的读数表，并用 PBR 而不是 forward PE 判断估值。
3. **问他现在怎么看**：只引用笔记 §8 截至 2026-10-02 的立场，并标明「他的方向和点位判断命中率一般，价值在研究方法和证伪清单」。**不要当作买卖建议**。新闻语气和他的多空标签只作待核实线索。
4. **周期股和卖铲人**：冲突时以 README 附录里的纪律为准，并指出差异（笔记 §10）。他的「证券化密度」「实现率」「绿地占比」「DDR4 金丝雀」「70% 利润率天花板」可以作为**补充读数**，不能替代纪律里的三条卖出信号。
5. 蒸馏本身不提供可回测的交易规则。

## 局限

- 六年里**没有任何账户收益披露**，零星的持仓线索存在幸存者偏差。
- 2024 年以后有大量 LLM 或 agent 生成的内容，其中有编造的数据。K-Research 的三情景概率是模板化的（BASE ≈ 55%）。
- 只抓了星主本人的帖子和 25 条问答，没抓评论区。K-Research 只用了 PDF 的文字层，图表没读。
- 检查点的命中率要等到期后逐条回填才有意义。截至 2026-10-06 只回填了 1 条（美光 FQ4，hit）。

# 口罩哥（KZG）· 投资思路蒸馏 · 报告

> 他的方向和点位判断命中率一般，真正可复用的是 2026 年 K-Research 那套研究写法：卡点识别、口径法医、证据分级、带时间窗的证伪清单。
> 不构成任何投资建议。

## 一、结论

1. **他是信息加工者，不是可以跟单的交易者。** 六年里没有仓位规则、止损线，也没有任何账户收益披露；风控只有事件前降杠杆和用反向 / 波动率 ETF 对冲。
2. **方向判断：大结构常对，点位和时点常错。** 对的有 2023 年 AI 主线与存储判底、2024-06「日元套息交易结束」、2025 年看多黄金；错的集中在点位类宏观预测（美元指数 85、油价破百、人民币「不轻易破 7」）、衰退预警，以及对自己持有标的的短线判断（2026-06-23 海力士暴跌当天说「小震荡」）。
3. **存储估值上，短帖和长文用的是两把尺子。** 短帖用 forward PE，说「存储周期股已死」；长文用 P/B 历史分位，承认「便宜的是今年的 P/E，贵的是顶点的 P/B」。**只采用长文的尺子**，短帖的论证正是周期顶价值陷阱的典型形态。
4. **卖铲人结论停在份额和订单，没有检查业绩是否传导。** 他两次把韩美半导体列为 HBM「最确定的卖铲人」，而它正是 HBM 超周期里营业利润倒退的反例。他列的设备、材料、电力设备标的，用之前都要先走四步证伪（见附录）。
5. **最有价值的是 K-Research 的研究模板**：每篇都写「我们错了的信号」，阈值和截止日期写死。蒸馏把这些信号收进了 `docs/watchlist.yaml`（22 个带日期的检查点 + 11 个常驻阈值），到期逐条回填，就能实测这套方法的命中率。截至 2026-10-06 已回填 1 条：美光 FQ4'26 毛利率 87.0%、库存天数 129 天，「中继」成立。

## 四、可复用的部分

### K-Research 的研究写法（[笔记 §2、§4](docs/01-蒸馏笔记.md)）

- **卡点识别**：价格由最紧的那个卡点定价；越上游、越窄、越受管制，议价权越硬。判断卡点看四个硬指标：交期、认证周期、CR3 / 单一来源、链主是否下场锁料。
- **判定顺序**：先找卡点 → 看谁握有卡点（份额 + 认证）→ 看财报有没有兑现（收入、现金流、合同负债、预付款）→ 最后才看估值。
- **口径法医**：每篇都追溯一个流行数字并纠正它，例如「NAND 一年十倍」只在某个固定价口径下成立；「凡引用份额必须先问口径」。
- **证据三级**：事实（一手财报 / 官方）> 估计（机构建模）> 传闻；同一位分析师的同一套模型不算两个独立验证点。
- **证伪清单**：每个情景写触发条件和时间窗，被证伪的假说留在正文里。注意他的三情景**概率是模板化的**（BASE 几乎总是 50~55%），只用触发条件，不用概率。

### 存储判顶的补充读数（[笔记 §3.2](docs/01-蒸馏笔记.md)）

合约价二阶导、现货与合约的裂口、「业绩好股价跌」、顶部融资和证券化密度、70% 利润率天花板、绿地新厂占比、长协实现率（公司 ASP 环比 ÷ 合约指数环比）、DDR4 金丝雀、需求破坏计量。这些可以补充、不能替代附录里的三条卖出信号。

他截至 2026-09 的结论是「存储两座时钟」：HBM 挤占把通用产能锁到 2027H2，中国和韩美的新产能在 2027H2 ~ 2028 集中到达；以 2027Q2 合约价环比为裁决点。

## 五、引用前要注意

- **语料可信度**（[笔记 §9](docs/01-蒸馏笔记.md)）：2024-05 以后的【星球日报】有相当部分是 LLM 直接生成，里面有编造的数据；2026-08 以后的帖子明显是 agent 代写。这些不算他的观点。
- **改过的观点**（[笔记 §7](docs/01-蒸馏笔记.md)）：「存储是不是周期股」两周内改口；长协一年里改了三次口径；DRAM 见顶时点一直在往前挪。他极少明确认错。
- **幸存者偏差**：没有账户收益，零星持仓线索只能看出他 2026 年长期持有 SK 海力士（上半年用 2 倍杠杆 ETF，回撤后改成无杠杆）。

## 附：用来对照的纪律

笔记里「纪律」指下面两条，是蒸馏时拿来对照的标尺，不是口罩哥的观点。

**卖铲人四步证伪**：上游靠控产能和涨价获取超额利润时，不假设设备、材料厂等比例受益。
1. 业绩背离：卖铲人营收 / 营业利润同比 vs 上游利润同比（锚点：HBM 超周期里韩美半导体营业利润倒退）。
2. 传导路径：绑的是上游 capex（弱），还是终端 AI 算力（硬）。
3. 股价 vs 业绩：股价涨幅远大于 EPS 涨幅 = 估值扩张、情绪主导。
4. 叙事打折：份额和订单不等于利润；市占率多为券商估算，用一手分部数据核对。

**强周期股（存储）周期顶识别**：
1. 看 PBR 自身历史分位，不看 PE；PBR = PER × ROE，要分解。「forward PE 很低 + PBR 历史最高」是典型价值陷阱。
2. 「这次不一样 / 周期转成长」是每轮周期顶的标配叙事；长协削减的是斜率，不是下行本身。
3. 卖出信号是拐点：① AI capex 指引下修 ② 合约价环比见顶（只认实际值）③ 库存回到 8 周以上。
4. 同主线多只是同一因子的杠杆，不是分散。

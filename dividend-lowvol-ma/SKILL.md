# 红利低波均线（稳我才）

报告在 `README.md`；细节在 `docs/01-蒸馏笔记.md`（规则、复现、稳健性）、`docs/02-修补检验.md`（v2 修补与跨 5 只 ETF 检验）、
`docs/03-与四进三出对比.md`；原始截图与转录在 `data/`。回答前先读报告，不要凭记忆。

## 命令（在本目录下运行）

```bash
python3 improve.py signal       # 今日：6 只红利 ETF 的乖离、原规则状态、v2 目标仓位（重抓行情）
python3 improve.py compare      # 5 只 × 买持 / 原规则 / v2 各目标波动
python3 improve.py oos          # 2018 前 / 2019 后 分段
python3 improve.py year 510880  # 逐年对比
python3 backtest.py replicate   # 与作者 25 笔调仓逐笔对照
python3 backtest.py grid        # MA 长度 × 卖出乖离 网格
python3 backtest.py split       # 前半 / 后半 / 发布后 分段
python3 backtest.py cross       # 原规则搬到 510880/159905/515080/515180
python3 -m pytest tests/        # 不连网的单元测试
```

依赖：Python 3.11+；PE 历史首次运行时取蛋卷（`danjuanfunds.com`），上证红利 2016 年前的 PE 需要 `akshare`。
缓存：`~/.cache/distill/dividend-lowvol-ma/`（环境变量 `DISTILL_CACHE`，删掉即重抓）。

## 回答口径

- 给信号时写清数据日期、乖离、60 日波动、原规则状态和 **v2 目标仓位**，以及「信号次日开盘执行」。
- 缺省推荐 v2 12% + PE≤20；目标波动是风险偏好（10% 稳 / 15% 接近原规则），由使用者定。
- 159905 深证红利：按报告结论不适用这条规则。
- 引用作者的 20% 年化时，**同时**给出打折后的预期和熊市回撤。
- 与四进三出比较时提醒两者回撤口径不同（月末 vs 日频），且都押同一个高股息风格。

正文要点（转述；引号内为原文短引）：
- 原理：锚定股息率 +「均线乖离择时买入卖出」；为普通人定投前设计，持有时间长、好落地。
- 回测用 512890 是因为「不分红，方便观察」；实盘可用 563020（易方达，费率更低）。
- 年化 19.99%、最大回撤 −13.04%、累计 253.99%；一年调仓 3 次；「今年的表现一般，仅盈利1.7%」。
- 买入：收盘价低于 182 日均线且市盈率低于 20 倍；卖出：收盘价高于 182 日均线 7%。
- 大原则「下跌建仓持有，盈利才卖出」；自称「每笔平均持有时间8个月」。
- 优点：非主观、频率低、对比红利低波指数胜率 85.71%；缺点：大牛市会卖飞踏空、耐心不足易半途而废。
- 买入方式：可定投，也可在持有期随时买入；极限低估（如「6月30日」）建仓更好。
- 作者自己说参数可以反复调试、担心大家都用会失灵。

# 红利低波均线（稳我才）· 投资思路蒸馏 · 报告

> 作者回测已逐笔复现；原规则在熊市有缺陷，附修补版（v2）与跨 5 只红利 ETF 的检验，以及今日信号脚本。
> 不构成任何投资建议。

## 一、结论

1. **规则极简，作者的回测是真的**：512890 红利低波 ETF，收盘价 ≤ 182 日均线且指数 PE ≤ 20 买入，收盘价 > 均线 ×1.07 卖出，全仓进出。
   作者 2019-10 ~ 2026-09 年化 19.97%、回撤 −13.04%；本地用公开行情**逐笔复现 25/25 笔调仓日期**（信号按收盘、次日成交），回撤分毫不差。
2. **原文有两处说法和数据不符**：「PE ≤ 20」在红利低波上从未起作用（2019 年后指数 PE 4.6~8.6，去掉它交易一笔不变）；
   「每笔平均持有 8 个月」实际是 **73 天**。
3. **参数是挑过的**：MA 60~250 × 卖出乖离 3%~15% 的 48 组里，多数年化 13%~19%，182 / 7% 接近最高。**合理预期按 ~15% 打折。**
4. **原规则有一个 bug：熊市里满仓到底**。仓位只有 0/100%，卖出只有「涨过均线 7%」一条。
   搬到经历过熊市的红利 ETF：510880 上证红利 2008 年 **−64%**、全程回撤 −70%；159905 深证红利 2021~2022 年最深 −41%。
   作者回测期（2019~2026）红利慢牛 + 低波动，bug 没有暴露；发布后半年一直持仓，表现等于买入持有。
5. **修补版 v2：信号不变，仓位按波动率缩放**（持有时仓位 = min(1, 12% ÷ 近 60 日年化波动)）。
   同一套参数在 5 只红利 ETF 上**最大回撤都 ≤ −29%**（原规则最深 −70%），510880 的 2008 年从 −64% 变成 −14%。
   代价是好行情少赚 3~5pp/年（512890：20.5% → 15.7%）。试过的 8 类开关式修补（止损、均线方向、长均线、相对 PE、超时、波动开关、回撤止盈）都不稳，不采用。
6. **v2 是把亏损变小，不是把亏钱变赚钱**：2018 年以前（只有 510880 / 159905 有数据）任何版本都没跑赢买入持有的收益回撤比。
   规则赚钱的前提是标的处在「低波动、慢涨、会回到均线」的状态。
7. **159905 深证红利不适用**：成分偏消费、会走趋势，涨 7% 就卖在牛市里卖飞、下跌时被套；不为它单独调参，直接排除。
8. **与股息率「四进三出」比，长期是四进三出更稳**：两者都回放到 2007 年后，四进三出 19 年年化 +13.1%、月末回撤 −15%，2008 年 −4.5%
   （股息率 ≥4% 才买，牛市顶部自动空仓）；本策略放在上证红利上修补后也只有 +4.5% / −24%。
   本策略的优势只在 2019 年后的红利慢牛：近 5 年原规则年化 +19.5%、v2 +13.9%，四进三出 +12.0%。
   见第五节与 [`docs/03-与四进三出对比.md`](docs/03-与四进三出对比.md)。

## 二、来源与方法

- **源头**：雪球 稳我才《低波均线—雪球（红利稳定盈利的策略及核心参数）》，2026-09-30，<https://xueqiu.com/7734995747/411110630>。
  雪球「择时策略」发布于 2026-03-18。正文约 1000 字，**规则、绩效、调仓记录都在 4 张截图里**（存档与转录见 [`data/article/`](data/article/README.md)，调仓转录为 [`data/trades.csv`](data/trades.csv)）。
- **复现**：前复权日线（TickFlow），按截图配置逐笔对照作者 25 笔调仓。
- **检验**：参数网格、前后两段、发布后样本外、搬到 4 只其他红利 ETF（510880 自 2007、159905 自 2011、515080、515180）。
- **修补**：每种修补对 5 只 ETF 用**同一套参数**、从同一天起算；开关式阈值要在参数邻域内结论不翻才算稳。
- **PE 数据**：蛋卷指数估值（周频，2016 起）；上证红利 2016 年前用乐咕乐股月度 PE（2005 起）。

## 三、规则

| 项 | 原规则（作者，图 3） | v2（修补） |
|---|---|---|
| 标的 | 512890 红利低波 ETF（实盘作者建议 563020，费率更低） | 同左；也可用于 515080 / 515180 / 510880 |
| 买入 | 收盘 / MA182 ≤ 1 **且** 指数 PE(TTM) ≤ 20 | 同左 |
| 卖出 | 收盘 / MA182 > 1.07 | 同左 |
| 仓位 | 0 或 100% | 持有时 min(1, 12% ÷ 近 60 日年化波动)；偏离 >10pp 或每 5 日偏离 >2pp 再平衡 |
| 执行 | 收盘出信号、次日成交 | 同左 |
| 止损 | 无 | 无（靠缩仓控回撤） |

## 四、检验结果

### 复现（`backtest.py replicate`）

| | 作者截图 | 本地复现（次日开盘成交） |
|---|---|---|
| 调仓日期 | 25 笔 | **25/25 完全一致** |
| 累计 / 年化 | 253.99% / 19.97% | 263.0% / 20.42% |
| 最大回撤 | −13.04% | −13.04% |
| 基准（512890 买持） | 105.75% / −16.53% | 105.6% / −16.58% |

截图里 2021-11 起成交价腰斩是 512890 在 2021-10-25 份额拆分（截图为不复权价）。

### 原文说法核对

| 原文 | 实测 |
|---|---|
| 买入要 PE ≤ 20 | 红利低波 PE 2019 后 4.6~8.6，从不触发；只有 2007 年的上证红利（PE 24~33）上起过作用：把买点推迟 2 个月，挡不住崩盘 |
| 每笔平均持有 8 个月 | 平均 73 天，最长 153 天；在场时间约 35% |
| 一年调仓 3 次 | 约 3.6 次 |
| 下跌建仓、盈利才卖 | 12 笔已平仓全部盈利（+8.1%~+21.1%，中位约 +10%），但规则里没有「亏损不卖」的机制，只是样本期没遇到跌下去不回来 |

### 分段（512890，`backtest.py split`）

| 区间 | 策略 | 买持 |
|---|---|---|
| 2019-10 ~ 2023-03 | +27.4% / −13.0% | +13.5% / −16.6% |
| 2023-04 ~ 2026-09 | +12.1% / −11.8% | +8.2% / −14.2% |
| 发布后 2026-03-18 ~ | −3.7% / −11.4% | −3.7% / −11.4% |

### 跨 5 只红利 ETF（`improve.py compare`，年化 / 最大回撤，日频，单边费用 0.03%）

| | 512890 | 515080 | 515180 | 510880（2007~） | 159905（2011~） |
|---|---|---|---|---|---|
| 买入持有 | +11.2% / −17% | +10.1% / −18% | +7.8% / −18% | +1.4% / −74% | +5.7% / −50% |
| 原规则 | +20.5% / −13% | +12.3% / −13% | +12.3% / −12% | +2.8% / **−70%** | +3.0% / −41% |
| **v2 12% + PE≤20** | +15.7% / −12% | +9.8% / −11% | +9.9% / −11% | +4.5% / **−24%** | +1.5% / −29% |

目标波动是风险偏好：10% 最深回撤约 −25%，15% 收益接近原规则、回撤到 −36%。逐年对比见 `improve.py year <代码>`；
510880 关键年份：2008 买持 −68% / 原规则 −64% / v2 −14%；2009 买持 +97% / 原规则 +39% / v2 +9%（牛市卖飞）。

### 不采用的修补（`docs/02-修补检验.md`）

相对 PE、MA182 方向、MA250/500 方向、跌破均线 10% 止损、持仓回撤 15% 止损、超时止损、波动率开关、涨过 7% 后改回撤止盈 ——
要么挡不住 510880 的崩盘，要么在 159905 上来回打脸、阈值一挪结论就翻，要么是把「均值回归」换成了「趋势」（换资产类型而不是修 bug）。

## 五、与股息率「四进三出」对比

| | 四进三出 | 红利低波均线 |
|---|---|---|
| 收益来源 | 高股息风格 + 选股排雷；对中证红利 ETF 超额约 0~1pp/年 | 高股息风格 + 择时；2019 后在 4 只红利 ETF 上比买持多 2~9pp/年 |
| 仓位 | 有票就满仓（不出则不进）；高估值时买不到 ≥4% 的票，被动拿现金（2007~2008、2010~2011 大部分时间） | 平均约 35% 时间在场 |
| 牛市 | 跟涨、少于大盘 | 涨 7% 就卖，大牛市卖飞 |
| 熊市 | 2008 年 −4.5%、2015 股灾 −3.3%、2018 年 −6.8%（高估值时买不到 ≥4% 股息率的票，自动空仓） | 原规则满仓到底；v2 靠缩仓把 2008 年控制在 −14% |
| 操作 | 30 只个股，每月调仓、看季报 | 一只 ETF，一年进出 3~4 次 |

| 区间 | 四进三出（现行，月末口径） | 本策略原规则 · 510880 | 本策略 v2 · 510880 |
|---|---|---|---|
| 近 5 年（2021-09 ~ 2026-09） | +12.0% / −13.0% | +20.2% / −10.1% | +14.4% / −8.8% |
| 2018-06 ~ 2026-09 | +11.9% / −12.7% | +15.7% / −17.0% | +12.1% / −14.9% |
| 2008 全年 | **−4.5%** | −64.3% | −14.2% |
| 2009 全年 | +43.7% | +39.1% | +9.3% |
| 2007 起全程 | **+13.1% / −15%** | +2.8% / −70% | +4.5% / −24% |

近 8 年本策略收益更高，但那是它最舒服的行情；拉长到 2007 年，四进三出明显更稳。
**红利因子只留一个策略的话选四进三出**；只想要一只 ETF、不管个股时才用本策略 v2（563020 / 512890），预期按年化 10%~12%。详见 docs/03「如果红利因子只留一个策略」。
它在 2008 年不亏的机制（股息率门槛 = 估值闸门）正是本策略缺的。**两者同时用不是分散**，押的是同一个风格。

## 六、仍可参考的部分

- 「跌破长均线买、涨离均线卖」在**低波动、慢涨**的资产上是一个普遍有效的结构（参数高原），不依赖 182 / 7% 这个具体值。
- 逆势规则一定要配一个**不靠开关的**风险控制；按波动率缩仓比止损线稳定。
- 判断规则是否可用，要拿到**有熊市的同类资产**上看，而不是只看作者给的那一段。
- 可借鉴四进三出：用「指数股息率 ≥ 某水平才买」做估值闸门，替代从不触发的 PE ≤ 20（需要指数股息率历史，未检验）。

## 七、局限

- 红利低波 ETF 本身只有 2019 年后的数据，熊市检验靠的是其他红利 ETF，资产不完全相同。
- 2016 年前除上证红利外没有指数 PE，159905 早期的 PE 条件未检验。
- 563020 在 2023-12 才上市，结论借用 512890。
- 回测不含申赎溢价、盘口冲击；ETF 场内成交按次日开盘价。

## 八、复现

```bash
python3 backtest.py replicate   # 与作者 25 笔调仓逐笔对照
python3 backtest.py grid        # 参数网格
python3 backtest.py split       # 分段
python3 backtest.py cross       # 原规则搬到其他红利 ETF
python3 improve.py compare      # 5 只 × 买持 / 原规则 / v2
python3 improve.py oos          # 2018 前 / 2019 后
python3 improve.py year 510880  # 逐年
python3 improve.py signal       # 今日信号与 v2 目标仓位
python3 -m pytest tests/        # 单元测试（不连网）
```

依赖 Python 3.11+；行情 TickFlow（免费无 key）、PE 蛋卷（首次运行自动抓），上证红利 2016 年前的 PE 需要 `akshare`。

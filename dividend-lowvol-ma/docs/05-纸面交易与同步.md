# 纸面交易与同步

2026-10-06 立，与股息率「四进三出」的纸面账户对齐（同样 1000 万人民币、每日定时落账、Notion 镜像）。

## 1. 账户

| 项 | 设定 |
|---|---|
| 初始资金 | 10,000,000 元 |
| 标的 | 512890 红利低波ETF华泰柏瑞（作者回测原标的；信号用它自己的前复权 K 线，PE 用红利低波指数 H30269） |
| 规则 | v3：收盘 / MA182 ≤ 1 且 PE ≤ 20 且「上证 A 股股息率 − 10 年国债」≥ −1.0pp → 持有；收盘 / MA182 > 1.07 → 空仓 |
| 仓位 | 持有时目标 = min(1, 18% ÷ 近 60 日年化波动)；空仓 0 |
| 调仓 | 新建 / 清仓立即；偏离 >10pp 立即；距上次成交 ≥5 个交易日且偏离 >2pp 再调（近似 `improve.run` 的每 5 日再平衡） |
| 成交价 | **下一个交易日开盘价**（不复权）—— 与回测一致；四进三出按当天收盘价成交，两者口径不同 |
| 费用 | 佣金 0.025%（最低 5 元）；ETF 免印花税、过户费 |
| 手数 | 100 股向下取整；现金不够一手就少买一手 |
| 份额拆分 / 分红 | 前复权 ÷ 不复权的比值变动 → 持仓折算成等价份额（分红视为再投入；ETF 分红个人免税），记一笔 ADJ |
| 频率 | 每个交易日北京时间收盘后跑一次；同一交易日重跑只打印 |
| 起始 | 2026-09-30 收盘出第一个信号（持有、目标 100%），2026-10-08 开盘建仓 |

## 3. Notion

私有页「红利低波均线 v3 纸面交易」：方法论页 + 交易流水 / 当前持仓 / 每日净值三张表。
本地账本是唯一事实源，Notion 是镜像；同步流程见 SKILL.md ④。

## 3.1 定时任务

`daily.sh`：纸面账户 → 今日信号面板；日志 `logs/<日期>.log`、状态 `logs/last_run.json`，失败弹 macOS 通知。
本机用 launchd 在伦敦时间 10:10（北京 17:10 / 18:10）调用，比四进三出晚 10 分钟。Notion 不在定时任务里，下次调用 skill 时补齐。

## 4. 与回测的差别

- 手数取整、最低佣金 5 元：回测按比例连续仓位、单边 0.03%。
- 调仓节奏：回测按日历序号每 5 个交易日检查，纸面按「距上次成交 ≥5 个交易日」。
- 起点：回测里策略 2025-12 就已持仓；纸面账户 2026-09-30 才开始，按当天信号直接建仓到目标。

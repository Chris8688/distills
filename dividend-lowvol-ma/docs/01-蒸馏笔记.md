# 红利低波均线（稳我才）—— 蒸馏笔记

出处：雪球 稳我才《低波均线—雪球（红利稳定盈利的策略及核心参数）》2026-09-30，
原始证据（4 张截图 + 转录）见 `data/article/`，调仓记录转录在 `data/trades.csv`。
复现与检验脚本：`backtest.py`。数据：512890 等 ETF 日 K（TickFlow 前复权）、指数 PE（蛋卷，周频，2016 起；上证红利另有乐咕乐股月度，2005 起）。
撰写：2026-10-06。

## 一、规则（原文，图3 雪球择时策略配置 —— 证据等级：原文）

| 项 | 规则 |
|---|---|
| 标的 | 512890 红利低波ETF华泰柏瑞（回测）；实盘建议 563020 红利低波ETF易方达 |
| 买入 | 收盘价 / MA(182) ≤ 1 **且** PE ≤ 20（两条全部满足） |
| 卖出 | 收盘价 / MA(182) > 1.07 |
| 仓位 | 全仓进出；空仓时不持替代资产（现金） |
| 止损 | 无 |
| 执行 | 收盘出信号、**次日**成交（复现确认，见下） |

## 二、复现（`backtest.py replicate`）

- **25 笔调仓日期 25/25 完全一致**：信号按当日收盘价算（前复权），成交在下一交易日。
- 用次日开盘价成交：总收益 +263.0% / 年化 20.42% / 最大回撤 −13.04%；作者 253.99% / 19.97% / −13.04%。
  差几个点来自成交价口径（作者截图价与次日开盘/收盘都不完全相同），回撤一模一样。
- 同期买入持有：+105.6% / 年化 10.95% / 回撤 −16.58%，与作者基准 105.75% / 10.95% / −16.53% 一致。
- 截图里 2021-11-03 起成交价腰斩（1.4 → 0.74）是 **512890 在 2021-10-25 份额拆分**，截图显示未复权价；信号用复权价算。

结论：作者的回测数字是真的，规则也说全了，没有隐藏条件。

## 三、原文说法 vs 数据（证据等级：实测）

| 原文 | 实测 | 判定 |
|---|---|---|
| 买入要求「市盈率低于 20 倍」 | 红利低波指数（H30269）2019 年后 PE 在 **4.6 ~ 8.6** 之间，从未接近 20；去掉 PE 条件，25 笔交易**完全不变** | **PE 条件在样本内从未起作用**，是装饰。指数有史以来最高约 14（2018-02） |
| 「每笔平均持有时间 8 个月」 | 12 笔已平仓平均 **73 天（约 2.4 个月）**，最长 153 天；在场时间约占 35% | **与原文不符** |
| 「一年调仓 3 次」 | 7 年 25 笔 ≈ 3.6 次/年 | 基本相符 |
| 「下跌建仓持有，盈利才卖出」 | 12 笔已平仓 **全部盈利**（+8.1% ~ +21.1%）；但这是样本期的结果，规则里没有任何"亏损不卖"的机制，只是没遇到跌破后不回头的行情 | 样本内成立，见第四节 |
| 「对比红利低波指数胜率 85.71%」 | 年度胜率 = 7 年里 6 年跑赢 512890 本身 | 相符，但只有 7 个样本 |

## 四、稳健性检验（证据等级：实测）

### 1. 参数：182 / 7% 是高原上的高点，不是孤峰（`backtest.py grid`）

MA 60~250 × 卖出乖离 3%~15% 共 48 格：几乎全部跑赢买入持有（年化 11.0%），
多数在 13% ~ 19%；182/7% 的 19.4% 接近最高（182/9% 19.6%、170/7% 18.8%）。
→ 「跌破长均线买、涨离均线卖」在这只 ETF 上普遍有效，具体参数是挑过的（作者也说「参数可以反复调试」）。
**预期收益应按高原中位（约 15%）而不是 20% 打折。**

### 2. 时间：后半段明显变弱，发布后等于买入持有（`backtest.py split`）

| 区间 | 策略年化 / 回撤 | 买持年化 / 回撤 |
|---|---|---|
| 2019-10 ~ 2023-03 | +27.4% / −13.0% | +13.5% / −16.6% |
| 2023-04 ~ 2026-09 | +12.1% / −11.8% | +8.2% / −14.2% |
| 发布后 2026-03-18 ~ 09-29 | −3.7% / −11.4% | −3.7% / −11.4% |

发布后它一直拿着 2025-12-12 买入的仓位（乖离没到 1.07），所以和买持完全一样 —— **真正的样本外只有这半年，而且什么也没证明**。

### 3. 资产：换到有熊市的红利 ETF，优势消失、回撤巨大（`backtest.py cross`，次日开盘成交）

| 标的 | 区间 | 策略年化 / 最大回撤 | 买持年化 / 最大回撤 | 单笔最大浮亏 |
|---|---|---|---|---|
| 512890 红利低波 | 2019-10 ~ | +20.7% / −13.0% | +11.2% / −16.6% | −9.1% |
| 515080 中证红利 | 2020-09 ~ | +12.4% / −12.9% | +10.1% / −18.2% | −8.8% |
| 515180 红利（易方达） | 2020-09 ~ | +12.4% / −12.3% | +7.8% / −18.5% | −8.6% |
| 159905 深红利 | 2011-10 ~ | +3.0% / **−40.6%** | +5.7% / −49.9% | −40.6% |
| 510880 上证红利 | 2007-10 ~ | +2.9% / **−70.2%** | +1.4% / −74.1% | **−68.4%** |

- 510880：2008-01-23 跌破均线买入，**一路拿到 2009-03，期间最深 −68.4%，最终 −50.3% 卖出**。
- 159905：2021-06 买入拿了 580 天，最深 −40.6%，最终 −23.4%。这段深红利 PE 一度超过 20，
  但**加上 PE ≤ 20 条件后交易完全不变**（买入时 PE 低于 20）—— PE 闸门挡不住这种下跌。
- 2020 年后的红利 ETF 都表现好，是因为 2020-2026 红利整体是慢牛 + 低波动；
  **规则的本质是「上升趋势里的均值回归」，在单边下跌里没有出口**（卖出只有涨过均线 7% 一条）。

## 五、方法论上的提醒

- **好成绩不能外推**：这条规则的成绩几乎全部来自 2019-2026 红利低波这一段行情本身（慢牛 + 低波动）。
  「某个标的上某条规则历史表现好」不能当成「这条规则能赚 20%」。
- **这是逆势规则**：跌破均线买、涨离均线卖。和顺势的趋势系统（涨了拿、跌破走）在同一标的上的方向经常相反，
  两者同时用时要分开记仓、分别评估，不要混在一起。
- **没有止损 = 回撤上限取决于标的本身**。512890 在样本内最深回撤 −16.6%，但成分股是高股息低波动的银行/公用/煤炭，
  系统性下跌时（如 2008、2015）同样会跌 40%+，那时本规则会全程满仓。

## 六、可以怎么用（建议，未实施）

> 2026-10-06 已做修补检验，**用 v2（波动率缩放仓位）代替原规则**，见 `02-修补检验.md`。下面是修补前的建议，保留作对照。

1. 只在 512890/563020（红利低波）上用，**不要搬到其他红利指数或宽基**。
2. 预期按 12% ~ 15% 年化、回撤按买持（−17% ~ −40%）准备，不按 20% / −13%。
3. 想补一个出口：可以加「持有期回撤 X% 止损」或「MA 本身向下」过滤 —— **未测试**，要做的话先在 510880 / 159905 的熊市段检验。
4. 定投语义（原文「可以定投，也可以在持有期随时买入」）与全仓进出的回测不是同一个策略，回测数字不适用于定投。

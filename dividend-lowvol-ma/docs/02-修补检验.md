# 修补检验：给原规则补下跌出口，跨 5 只红利 ETF 同参数验证

撰写 2026-10-06。脚本 `improve.py`（`compare` / `oos` / `year` / `signal`）。
标的：512890 红利低波、515080 中证红利、515180 红利（易方达）、510880 上证红利（2007 起）、159905 深证红利（2011 起）。
口径：信号按收盘、次日开盘成交；费用 0.03%/单边换手；**所有标的同一套参数，不按标的调**。

## 一、先补完 01 笔记里的 TODO：PE ≤ 20 在 2008 年挡没挡住

数据：乐咕乐股「上证红利」月度 PE（akshare `stock_index_pe_lg`，2005 起）。

| 月末 | 上证红利 PE(TTM) |
|---|---|
| 2007-10 | 33.0（最高） |
| 2007-12 | 31.0 |
| 2008-01 | 24.7 |
| 2008-03 | 18.8 ← 首次 ≤ 20 |
| 2008-10 | 12.1 |

- 原规则 2008-01-23 以 2.253 买入；加 PE ≤ 20 后推迟到 **2008-04-01 以 1.706 买入**，两者都在 2009-03-24 以 1.119 卖出。
- 结论：PE 闸门**挡住了最贵的那段，但挡不住后面的崩盘**（单笔 −50% → −34%）；全样本 510880 回撤 −70% → −62%。
- 在红利低波（PE 常年 5~9）和 2019 年后的其他红利指数上，这个条件从未触发。

## 二、原规则的 bug 是什么

1. **仓位只有 0 / 100%**，**卖出只有「涨过均线 7%」一条**。跌破均线后如果不回来，就满仓一直拿着。
   - 510880：2008 全年 −64%（买持 −68%）
   - 159905：2021-06 买入，拿了 580 天，最深 −41%
2. 2019~2026 红利整体是慢牛 + 低波动，这条 bug 在作者的回测里没有暴露。

## 三、试过但不采用的修补

所有变体都从同一天起算（早期一版用长均线时起点被推后、恰好躲过 2008，结论是假的，已纠正）。

| 修补 | 结果 | 不采用的原因 |
|---|---|---|
| 相对 PE（≤ 自身 3 年 50%/70% 分位） | 低波三只年化掉 5~8pp；510880 回撤仍 −62%~−70% | 代价大、没挡住 |
| MA182 方向过滤（20 日不走低才买，走低 + 跌破 5% 卖） | 510880 回撤 −48%；515080 年化 12.4% → 6.6% | 伤低波三只 |
| MA250/500 方向 / 跌破长均线卖 | 510880 回撤 −57%~−70% | 没挡住 |
| 跌破均线 10% 止损（收回均线后再武装） | 510880 −47%；159905 年化 +3.0% → −3.6% | 159905 反复被打 |
| 持仓自高点回撤 15% 止损 | 510880 −48%；159905 +0.1% | 同上 |
| 超时止损（持有 120/180/250 天仍在均线下） | 120 天 510880 −62%；180 天反而 −76% | 阈值一挪结论就翻 |
| 波动率开关（60 日波动 > 20/25/30% 不买且卖） | 510880 −32%~−37%；159905 在 25% 时转负 | 开关阈值不稳 |
| 涨过 7% 后改回撤 3/5/8% 止盈（「别卖飞」） | 159905 改善（8% 时 +7.5%）；512890 20.7% → 10.2% | 是把「均值回归」换成「趋势」，换资产类型而不是修 bug |

共同点：**开关式阈值**在 159905 这种来回震荡的下跌里会反复进出，参数一挪结论就翻。

## 四、采用的修补 v2：信号不变，仓位按波动率缩放

```
持有时仓位 = min(1, 目标波动 / 近 60 日年化波动)        目标波动缺省 12%
买卖信号、PE ≤ 20 条件、次日开盘执行：全部沿用原规则
再平衡：仓位偏离 > 10pp 立即调；否则每 5 个交易日偏离 > 2pp 才调（年换手约 3.5 倍，费用约 0.1%/年）
```

原理：崩盘时波动率先升，仓位自动降下来；平静时接近满仓。没有开关，参数是单调的（目标越低越保守）。

### 样本外（`improve.py oos`）

- **2018 年底以前**（只有 510880/159905）：**没有任何变体跑赢买持的 Calmar**。510880 原规则 −6.2%/年、回撤 −70%；

- **2019 年起**（5 只）：原规则 5/5 跑赢买持（510880 +17.8% vs +8.6%）；v2 12% 收益低 3~5pp，回撤也低。

## 五、结论

1. **原规则有效的前提是标的处在低波动、慢涨、会回到均线的状态**。2019 年后的红利指数都满足；
   2008、2010~2013、2018 的上证红利和 2021~2022 的深证红利不满足，这时任何开关式出口都救不回来。
2. **v2 修的是「坏状态下满仓到底」这个 bug**：同一套参数下，5 只的最大回撤都 ≤ −29%（原规则最深 −70%）。
   代价是好状态下每年少赚 3~5pp（512890：20.5% → 15.7%）。
3. **159905 深证红利不适合这条规则**：它的成分偏消费、会走趋势，「涨 7% 就卖」在牛市里卖飞，下跌时又反复被套；
   2019 年后原规则也只和买持打平。v2 能把它的回撤从 −41% 压到 −29%，但收益仍低于买持。
   按「只做负向剔除、不为个别标的调参」的原则，**建议不在 159905 上用**。
4. 目标波动的选择是风险偏好问题：10% 最稳（最深 −25%）、12% 折中、15% 接近原规则收益但回撤到 −36%。

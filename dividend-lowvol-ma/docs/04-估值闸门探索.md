# 估值闸门探索：「股息率够高才买」能不能修好熊市入场（→ v3）

撰写 2026-10-06。脚本 `improve.py gate`（网格）、`improve.py compare` / `oos`（含 v3）。
口径同 docs/02：5 只红利 ETF 同一套参数、次日开盘成交、单边 0.03%、日频回撤。

## 一、动机

v2（波动率缩仓）把熊市回撤压下来了，但没解决病根：**原规则在泡沫顶部照样买**（510880 2008-01 跌破均线就买，当时上证红利 PE 31）。
作者原文的 PE ≤ 20 只把买点推迟了 2 个月。四进三出在 2007 年顶部空仓，靠的是「股息率 ≥4% 才买」—— 想借这个机制。

## 二、数据

- **红利指数自身的股息率历史没有免费来源**（蛋卷要登录；中证官网只给近 20 个交易日）。
- 用「长期分红股里股息率最高的 100 只」自建代理不可行：样本池从 2007 年 314 只涨到 2026 年 2508 只，前 100 名的股息率被机械抬高
  （代理值 6.7% vs 中证红利官方 4.28%），跨年不可比。
- 采用**全市场口径**：乐咕乐股「上证 A 股股息率」（akshare `stock_a_gxl_lg`，2005 起日频）与中国 10 年国债收益率（`bond_zh_us_rate`）。
  关键时点：2007-10 0.57%、2008-04 0.77%、2008-10 底 2.50%、2015-06 1.77%、2024-02 3.87%、2026-09 2.71%（中位 2.59%）。
  所以闸门量的是「整个 A 股贵不贵」（股债性价比），不是红利指数本身。

## 四、读法

1. **闸门只在泡沫期关**：股债差 ≥ −1.0 在 2007 年全年、2008~2011 年大部分时间、2015 年一半、2017 年大部分时间关闭，
   **2019 年后从未关闭**（国债利率降到 2% 附近，股息率 2.5%~3.9%）。所以它**不花近年的任何收益**（2019 后结果与无闸门完全相同）。
2. **逐年只帮不伤**：510880 改善的年份 2008（v2 −14.2% → −1.9%；原规则 −52.9% → −9.2%）、2010、2011、2015、2018，没有一年变差；
   159905 只有 2012 年差 0.1pp。不是靠某一年。
3. **参数是高原**：股债差 −2.0 → −1.0 单调改善，−0.5 开始伤 512890 / 515180；股息率绝对值 1.5%~2.0% 也有效、2.5% 起开始伤。选 −1.0。
4. **相对口径（自身 3 年中位）无效**，与 docs/02 的相对 PE 结论一致：相对阈值在长期慢涨的序列里会频繁关门。
5. **股债差优于股息率绝对值**：股息率水平随时代漂移（2005 年 2.0%，2024 年 3.9%），减去国债利率后跨年可比性更好。

## 五、闸门之后，缩仓还要多少

| 原规则 + PE + 闸门 | +20.5% / −13% | +12.3% / −13% | +12.3% / −12% | +10.3% / −25% | −25% | +15.7% | +19.5% / −12% |
| **v3：闸门 + 缩仓 18%** | **+19.5% / −12%** | **+11.9% / −13%** | **+12.0% / −12%** | **+7.8% / −19%** | **−19%** | **+15.1%** | **+18.3% / −12%** |
| 闸门 + 缩仓 15% | +18.3% / −12% | +11.5% / −12% | +11.4% / −12% | +7.3% / −18% | −18% | +14.3% | +16.9% / −12% |
| 闸门 + 缩仓 12% | +15.7% / −12% | +9.8% / −11% | +9.9% / −11% | +6.3% / −15% | −15% | +12.2% | +13.9% / −12% |

（4 只 = 去掉不适用的 159905。）

- 闸门挡住了泡沫期入场，「原规则 + 闸门」剩下的最深回撤是 510880 在 2015-11 → 2016-01 熔断（−25%）—— 持仓中的急跌，闸门管不到。
- 缩仓 18% 把它压到 −19%，2019 后只少 0.6pp/年；12% 压到 −15%，但少 3.5pp/年。
- **采用 v3 = 原规则 + PE ≤20 + 股债差 ≥ −1.0 + 缩仓 18%**（`TV3`、`SPREAD_MIN`）。更在意回撤可以把缩仓调到 12%~15%。

样本外（`improve.py oos`）：2018 年以前（510880 / 159905）v3 年化 **+2.0% / +2.0%**、回撤 −19% / −21%，
**第一次在熊市样本上转正**（v2 是 −1.2% / +1.3%，原规则 −6.2% / +1.7%），510880 的收益回撤比也第一次超过买持。

## 六、与四进三出（实际运行口径 15 只·每日）的对比变化

| | 四进三出 | v3（510880 / 512890） |
|---|---|---|
| 2007 起全程 | +14.5% / −30% | 510880 +7.8% / −19% |
| 2008 全年 | −25.8% | 510880 −3.3% |
| 2019-12 起 | +18.2% / −10% | 512890 +18.7% / −12% |
| 近 5 年 | +15.0% / −10% | 512890 +18.3% / −12% |

v3 以后，两者从「四进三出全面占优」变成**真正的取舍**：四进三出长期收益更高（但长样本里本策略只能用上证红利代替红利低波，
上证红利自身同期买持只有 +1.4%/年），本策略回撤明显更浅、近年收益相当或更高、只有一只 ETF。

## 七、局限

- 闸门用的是**全市场**股债差，不是红利指数自身股息率；红利风格与大盘背离时（例如大盘贵、红利便宜）会误关。
- 2019 年后闸门从未关闭，**近年数据对它没有检验力**；它的价值全部来自 2007~2018 的两只 ETF。
- −1.0 是 4 个候选里挑的（在高原上），仍属样本内选择。
- 股息率 / 国债数据按当日收盘可得、次日开盘执行，无未来数据；但乐咕乐股的股息率口径（静态、全市场加权方式）未逐项核对。
